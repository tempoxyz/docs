# Privacy

A Zone keeps balances and account activity in a private ledger that its operator can read.

## Overview

Four parties see different Zone data:

- **Account Holder:** Reads its own balances and activity through the Zone RPC.
- **Operator:** Runs the deployment and can read the whole private ledger.
- **Public Observers:** See deposits and withdrawals on Tempo, but not activity inside the Zone.
- **Your Application:** Reads only the accounts whose authorization tokens it holds.

<span id="understand-who-can-read-the-data" />

## Who Can See What

| Data | Visibility |
| --- | --- |
| Private balances and account activity | The Zone RPC limits each account to its own data. The operator can inspect the ledger. |
| Deposit recipient and memo | Encrypted to the operator when submitted on Tempo. |
| Deposit token, amount, depositor, and refund recipient | Public on Tempo. |
| Withdrawal token, amount, destination, and settlement commitments | Public on Tempo. |

## Public Deposits and Withdrawals

Deposit and withdrawal amounts and timing stay public on Tempo. A Zone doesn't hide them, and its operator can read the private ledger.

<span id="keep-application-access-scoped" />

## Scope Application Access

The Zone RPC authenticates each caller with an [authorization token](/docs/zones/connect#authorize-access). It scopes results to that account and redacts shared data. If your application uses a hosted provider instead, confirm which accounts its credentials can read.

Enforce customer access in your backend, caches, logs, and user interface. A public Tempo explorer doesn't show private Zone activity.

Read access is separate from transaction-signing authority and from the portal's funding rules.

<span id="check-settlement-assumptions" />

## Trust Assumptions

Each Zone has a portal (`ZonePortal`) on Tempo that holds its backing assets. Execution-proof enforcement depends on the deployed verifier and network configuration. Forced exits aren't a generally available recovery path.

Review [proving and settlement](/docs/protocol/zones/proving) with the operator before you integrate.
