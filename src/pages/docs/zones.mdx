# Tempo Zones

Keep stablecoin balances and account activity in a private ledger connected to Tempo. Deposit funds from Tempo, read private balances, and withdraw to the public network.

[Read the privacy model →](/docs/zones/privacy)

</DocsProductOverview>

:::warning
Zones is in limited preview. [Contact Tempo](https://tempo.xyz/contact) to discuss access and the deployment your application needs.
:::

<span id="understand-the-privacy-boundary" />

## How Zones work

Each Zone has its own network and a portal on Tempo that holds its backing assets. Account-scoped access lets your application read private balances and activity. The operator can read the ledger; deposit and withdrawal amounts remain public. Read [Privacy](/docs/zones/privacy) before choosing a deployment.

<span id="check-the-capabilities-of-your-deployment" />

## Supported features

The current permissioned runtime supports funding through the inbox and outbox. General TIP-20 transfers and user contract deployment are disabled. Confirm the operator's supported assets, signing tools, read access, and funding rules before integrating.

Execution-proof enforcement depends on the deployed verifier and network configuration. Review [proving and settlement](/docs/protocol/zones/proving) with the operator; forced exits are not a generally available recovery path.
