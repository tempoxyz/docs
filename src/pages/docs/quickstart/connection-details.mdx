# Network details

Use Tempo Mainnet for production and Moderato testnet for development. Both support EVM tools and SDKs; each has its own RPC endpoint, chain ID, assets, and transaction history.

<span id="direct-connection-details" />

## Mainnet

| Property | Value |
| --- | --- |
| Network | Tempo Mainnet |
| Chain ID | `4217` |
| Currency symbol | `USD` |
| HTTP RPC | `https://rpc.tempo.xyz` |
| WebSocket RPC | `wss://rpc.tempo.xyz` |
| Explorer | [Tempo Explorer](https://explore.tempo.xyz) |

Use [Fund an account](/docs/guide/getting-funds) for supported funding paths.

<span id="tempo-testnet" />

## Testnet

| Property | Value |
| --- | --- |
| Network | Tempo Testnet (Moderato) |
| Chain ID | `42431` |
| Currency symbol | `USD` |
| HTTP RPC | `https://rpc.moderato.tempo.xyz` |
| WebSocket RPC | `wss://rpc.moderato.tempo.xyz` |
| Explorer | [Testnet Explorer](https://explore.testnet.tempo.xyz) |

Use the [faucet](/docs/quickstart/faucet) to get test stablecoins. Testnet funds are separate from mainnet funds.

## RPC endpoints and explorers

Read the current block number to check the connection. These examples use Moderato; use `https://rpc.tempo.xyz` (or omit `testnet: true` in Viem) for mainnet. Use the [Network example setup](/docs/network/examples) for the SDK dependencies and Wagmi `config`.

::::code-group

```ts [Viem]
import { createClient } from 'viem/tempo'

const client = createClient({ testnet: true })
console.log(await client.getBlockNumber())
```

```bash [CLI]
cast block-number --rpc-url https://rpc.moderato.tempo.xyz
```

```ts [Wagmi]
import { getBlockNumber } from 'wagmi/actions'

console.log(await getBlockNumber(config))
```

```python [Python]
from web3 import Web3

w3 = Web3(Web3.HTTPProvider("https://rpc.moderato.tempo.xyz"))
print(w3.eth.block_number)
```

```bash [API (RPC)]
curl https://rpc.moderato.tempo.xyz -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"eth_blockNumber","params":[]}'
```

::::

Use the matching explorer to inspect transactions. For application integration, choose an [SDK](/docs/sdk) or read the [JSON-RPC reference](/docs/protocol/rpc). Use the [Tempo API](/docs/api) for indexed data and hosted services.
