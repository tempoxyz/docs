# Predeployed contracts on Tempo

Call Tempo's protocol contracts and common Ethereum utilities at fixed addresses, without deploying them.

Each address links to the Tempo mainnet explorer. [TIP-20 tokens](/docs/protocol/tip20/overview) are Tempo's native token standard for stablecoins, and most system contracts act on them.

## System contracts

These protocol contracts run Tempo's tokens, network fees, stablecoin exchange, and transfer rules.

| Contract | Address | Description |
|----------|---------|-------------|
| [**TIP-20 Factory**](/docs/protocol/tip20/overview) | [`0x20fc000000000000000000000000000000000000`](https://explore.tempo.xyz/address/0x20fc000000000000000000000000000000000000) | Create new TIP-20 tokens |
| [**Fee Manager**](/docs/protocol/fees/spec-fee-amm#2-feemanager-contract) | [`0xfeec000000000000000000000000000000000000`](https://explore.tempo.xyz/address/0xfeec000000000000000000000000000000000000) | Collect network fees in the payer's stablecoin and convert them to the validator's preferred token through the [Fee AMM](/docs/protocol/fees/fee-amm) |
| [**Stablecoin DEX**](/docs/protocol/exchange) | [`0xdec0000000000000000000000000000000000000`](https://explore.tempo.xyz/address/0xdec0000000000000000000000000000000000000) | Onchain orderbook, built into the protocol, for swapping stablecoins |
| [**TIP-403 Registry**](/docs/protocol/tip403/spec) | [`0x403c000000000000000000000000000000000000`](https://explore.tempo.xyz/address/0x403c000000000000000000000000000000000000) | Stores transfer policies that TIP-20 tokens share to control who can send and receive them |
| [**ReceivePolicyGuard**](/docs/accounts/policies/receive-policies) | [`0xB10C000000000000000000000000000000000000`](https://explore.tempo.xyz/address/0xB10C000000000000000000000000000000000000) | Holds TIP-20 transfers and mints that the recipient's receive policy blocks. A receive policy sets which stablecoins and senders an account accepts. |
| [**Signature Verifier**](/docs/protocol/tips/tip-1020) | [`0x5165300000000000000000000000000000000000`](https://explore.tempo.xyz/address/0x5165300000000000000000000000000000000000) | Verify secp256k1, P256, and WebAuthn signatures onchain |
| [**Address Registry**](/docs/protocol/tips/tip-1022) | [`0xFDC0000000000000000000000000000000000000`](https://explore.tempo.xyz/address/0xFDC0000000000000000000000000000000000000) | Resolve [virtual addresses](/docs/accounts/virtual-addresses), per-customer deposit addresses, to the registered account they pay into |
| [**pathUSD**](/docs/protocol/exchange/quote-tokens#pathusd) | [`0x20c0000000000000000000000000000000000000`](https://explore.tempo.xyz/address/0x20c0000000000000000000000000000000000000) | USD stablecoin that serves as the DEX's root quote token and the fallback fee token. It was the first stablecoin deployed. |

## Zone contracts

A [Zone](/docs/protocol/zones) is a private stablecoin ledger that uses Tempo for deposits, withdrawals, and settlement. Each Zone has a portal (`ZonePortal`), a contract on Tempo that holds the Zone's backing assets. Each portal is a proxy that points to the shared implementation listed here.

Onchain checks of Zone execution proofs aren't fully enforced yet ([settlement verification limits](/docs/protocol/zones/proving#implementation-status)). Confirm a Zone's deployed runtime, verifier, and configuration before integrating.

| Contract | Address | Description |
|----------|---------|-------------|
| [ZoneFactory](/docs/protocol/zones/architecture#creating-a-zone) | [`0x5AF2000000000000000000000000000000000000`](https://explore.tempo.xyz/address/0x5AF2000000000000000000000000000000000000) | Create Zones and install a portal for each one |
| [ZonePortal implementation](/docs/protocol/zones/architecture#contract-architecture) | [`0x5AD1000000000000000000000000000000000000`](https://explore.tempo.xyz/address/0x5AD1000000000000000000000000000000000000) | Shared deposit and withdrawal logic behind each Zone's portal proxy |
| [Zone verifier](/docs/protocol/zones/architecture#contract-architecture) | [`0x5a56000000000000000000000000000000000000`](https://explore.tempo.xyz/address/0x5a56000000000000000000000000000000000000) | Protocol-managed verifier that portals use to check Zone batches |
| [ZoneMessenger](/docs/protocol/zones/architecture#contract-architecture) | [`0x5A4d000000000000000000000000000000000000`](https://explore.tempo.xyz/address/0x5A4d000000000000000000000000000000000000) | Runs withdrawal callbacks, which let a withdrawal call a Tempo contract |

## Contract ABIs

Viem's Tempo module, `viem/tempo`, exports the system contract ABIs as `Abis`. `Abis.feeAmm` covers the Fee AMM functions, which the Fee Manager contract implements.

```typescript
import { Abis } from 'viem/tempo'

const tip20Abi = Abis.tip20
const tip20FactoryAbi = Abis.tip20Factory
const stablecoinDexAbi = Abis.stablecoinDex
const feeManagerAbi = Abis.feeManager
const feeAmmAbi = Abis.feeAmm
// ...
```
