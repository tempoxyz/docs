# Integrate Tempo

Connect an application, wallet, or service to Tempo. Start with network configuration, then review the EVM and transaction behavior your integration depends on.

For an application that needs user accounts and stablecoin payments, start with [Accounts](/docs/accounts) and the [account integration guide](/docs/accounts/integrate).

<span id="connect-and-fund" />

## Connect to the network

Use Tempo Mainnet for production and the separate Moderato testnet for development with faucet funds.

## Deploy and inspect contracts

- [Verify contracts](/docs/quickstart/verify-contracts) to publish source for deployed contracts.
- Find protocol addresses in [system contracts and predeploys](/docs/quickstart/predeployed-contracts).
- Use [token lists](/docs/quickstart/tokenlist) to display stablecoin metadata in your application.

## Connect other networks

Use the guide for your bridge or routing integration:

- [LayerZero](/docs/guide/bridge-layerzero)
- [Relay](/docs/guide/bridge-relay)
- [Bungee](/docs/guide/bridge-bungee)
- [Tempo Routes](/docs/api/routes/transfers)

For an existing token, [choose an ERC-20 to TIP-20 integration path](/docs/guide/issuance/migrate-erc20-to-tip20). Browse [ecosystem partners](/docs/partners/join) for wallets, infrastructure, and other integration providers.
