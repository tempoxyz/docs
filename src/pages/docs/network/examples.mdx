# Network examples

Set up the clients used in the Network guides. These examples use a funded test account on Moderato and AlphaUSD for transaction fees. Keep private keys on your server.

For Viem and Python, set `TEMPO_PRIVATE_KEY` to the account's private key. Set `TEMPO_RECIPIENT` to another test address you control for the CLI and server examples. Use the [faucet](/docs/quickstart/faucet) to fund the sender. The examples use 1,000,000 base units for one AlphaUSD.

## CLI setup

Install the latest [Foundry](/docs/sdk/foundry#get-started-with-foundry) with Tempo support. The snippets use `cast` for contract calls and transactions; `--interactive` prompts for the test account's signing key. The Exchange quote command also uses `jq` to read the JSON result.

Set the account and recipient addresses to test accounts you control, then configure the shared values:

```bash
export RPC_URL=https://rpc.moderato.tempo.xyz
export SENDER="$TEMPO_SENDER_ADDRESS"
export TOKEN=0x20c0000000000000000000000000000000000001
export BETA_TOKEN=0x20c0000000000000000000000000000000000002
export FACTORY=0x20fc000000000000000000000000000000000000
export DEX=0xdec0000000000000000000000000000000000000
```

Fund `SENDER` with the [faucet](/docs/quickstart/faucet). `TOKEN` is AlphaUSD for these examples; token issuance saves its new address separately as `DEMO_TOKEN`. The [Foundry Tempo guide](https://www.getfoundry.sh/guides/tempo) documents current CLI options, including fee tokens and remote sponsorship.

## HTTP requests

JSON-RPC reads use the same endpoint as SDKs. Set `RPC_URL=https://rpc.moderato.tempo.xyz`. Requests below do not use an API key.

For gas estimation, set `TEMPO_SENDER_ADDRESS` to the funded account address, then set `SENDER` and `CALL_DATA` below. You can generate the calldata with [Cast](/docs/sdk/foundry):

```bash
export RPC_URL=https://rpc.moderato.tempo.xyz
export SENDER="$TEMPO_SENDER_ADDRESS"
export TOKEN=0x20c0000000000000000000000000000000000001
export CALL_DATA=$(cast calldata 'transfer(address,uint256)' "$TEMPO_RECIPIENT" 1000000)
```

For transaction submission, set `SIGNED_TX` to the hex-encoded signed transaction from the TypeScript or Python signing step. For receipt lookup, set `TX_HASH` to the returned transaction hash. JSON-RPC broadcasts signed transactions; the signing key stays in your application or wallet.

The [JSON-RPC reference](/docs/protocol/rpc) documents method behavior. The [hosted API](/docs/api) is a separate interface for indexed data and services.
