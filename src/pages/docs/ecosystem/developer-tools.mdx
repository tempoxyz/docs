# Developer tools

Inspect transactions and contracts with an explorer, or use debugging and simulation tools to investigate execution. Choose a tool below for the task you are working on.

Use the [testnet explorer](https://explore.testnet.tempo.xyz) for Moderato transactions. Read the [explorers and debugging guide](/docs/ecosystem/block-explorers) for more about these tools, or follow [payment verification](/docs/guide/payments/accept-a-payment#verify-stablecoin-payments) when checking that a recipient received funds.

## Build account integrations

[Smart account libraries](/docs/ecosystem/smart-contract-libraries) provide account abstraction and programmable wallet integrations. Find wallet providers and account infrastructure in [Wallets](/docs/ecosystem/wallets).

For Tempo's own client libraries, command-line tools, and API references, use [Developer Resources](/docs/development).
