# Connect a wallet

Let users connect Tempo Wallet to your application with the Accounts SDK. The wallet handles signing; your application uses the selected account address for balances and transaction requests.

This browser example uses Moderato testnet.

## Choose a provider

Use the Accounts SDK below for Tempo Wallet. If customers already use another wallet or your app embeds a provider, follow that [provider’s Tempo integration](/docs/accounts/providers). The wallet handles signing; connecting it does not replace your application’s customer login.

```bash
pnpm add --save-exact accounts@0.18.4 viem
```

### Connect the provider

Create a provider for Moderato and request the selected address from a **Connect wallet** button:

::::code-group

```ts [TypeScript (Accounts SDK)]
import { Provider } from 'accounts'
import { tempoModerato } from 'viem/chains'

const provider = Provider.create({ chains: [tempoModerato], testnet: true })
const [address] = await provider.request({ method: 'eth_requestAccounts' })
if (!address) throw new Error('No account was selected')
```

```tsx [Wagmi]
import { useConnect, useConnectors } from 'wagmi'
const { mutate: connect } = useConnect()
const connector = useConnectors().find((item) => item.id === 'xyz.tempo')
const connectWallet = () => connector && connect({ connector })
```

::::

The [complete browser setup](/docs/accounts/examples#browser-wallet-setup) creates `walletClient` and `publicClient` from this provider and exports `connectAccount()`. For Wagmi, use the [Tempo Wallet connector setup](/docs/accounts/examples#wagmi-client), place the hooks in your React component, and call `connectWallet` from a button. Browser wallet authorization requires the user's wallet; CLI or API requests cannot authorize that browser session. Keep this connection separate from your application's authenticated customer session.

### Read the connected account

Use `publicClient` to [read balances and activity](/docs/accounts/balances), and `walletClient` to request transaction authorization.

On `accountsChanged`, update the selected address or clear it when the wallet disconnects. On `chainChanged`, refresh network-dependent state before enabling transactions.

## Sign a transaction

Request payments from the connected wallet using the [CLI, Viem, and Wagmi payment examples](/docs/guide/payments/send-a-payment#send-a-payment). For Viem, pass `account: address` to `walletClient.token.transferSync`; Wagmi uses the connected account. Show the recipient and amount before requesting authorization.

Use [Send payments](/docs/guide/payments/send-a-payment#confirm-delivery) to verify delivery before updating your application records. The [Accounts SDK documentation](https://accounts.tempo.xyz/docs) covers framework integration and connection options. To let your application sign within explicit limits, use [access keys](/docs/accounts/access-keys).
