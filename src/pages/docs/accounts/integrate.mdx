# Connect a wallet

Let users connect Tempo Wallet to your application with the Accounts SDK. The wallet handles signing; your application uses the selected account address for balances and transaction requests.

This browser example uses Moderato testnet.

### Install the Accounts SDK

Run this in your application's project directory:

```bash
pnpm add --save-exact accounts@0.18.4 viem
```

<span id="connect-tempo-wallet-from-your-application" />

### Create a provider and clients

Use the same network for the provider, wallet client, and public client:

```ts [connection.ts]
import { Provider } from 'accounts'
import { tempoModerato } from 'viem/chains'
import { createClient, custom } from 'viem/tempo'

export const provider = Provider.create({
  chains: [tempoModerato],
  testnet: true,
})

export const walletClient = createClient({
  chain: tempoModerato,
  transport: custom(provider),
})

export const publicClient = createClient({
  chain: tempoModerato,
})

export async function connectAccount() {
  const [address] = await provider.request({
    method: 'eth_requestAccounts',
  })
  if (!address) throw new Error('No account was selected')
  return address
}
```

Call `connectAccount` from a **Connect wallet** button and save the returned address in your application's connection state. The address identifies the selected wallet account; connecting it does not authenticate a customer in your application. Keep wallet connection state separate from your customer's authenticated session.

### Read the connected account

Use `publicClient` to [read balances and activity](/docs/accounts/balances), and `walletClient` to request transaction authorization.

On `accountsChanged`, update the selected address or clear it when the wallet disconnects. On `chainChanged`, refresh network-dependent state before enabling transactions.
