# Key rotation

:::warning
**Not live yet.** Key rotation ([TIP-1107](https://tips.sh/1107)) is in early development and runs only on Tempo devnet. We're seeking feedback; behavior may change.
:::

Rotating a key, replacing a lost one, and removing a compromised one are the same operation: a signer update that the account's other signers approve, at the same address. Tempo has no override, so set up the account to survive losing any one signer before you need to.

## One signer update, same address

A signer update replaces the account's list of signers and its threshold in one transaction. Signers whose weights reach the current threshold approve it, and the address, balances, token approvals, and history stay the same. Once it lands, a removed signer can't approve, and approvals collected for the old configuration stop verifying.

What changes between situations is who approves. When you rotate a key on schedule, the old key can still sign. When a key is lost or compromised, the other signers must reach the threshold without it.

## Plan for recovery

Recovery works only when the account can lose any one signer and still reach the threshold with the rest. After a key is lost, only the remaining signers can change the configuration, so set this up when you create the account.

The rule: for every signer, the total weight minus that signer's weight must be at least the threshold.

For example, give a passkey weight 2, and a backup key and a recovery provider's key weight 1 each, at threshold 2. The passkey replaces a lost key alone, and the two keys together replace a lost passkey. [Signing thresholds](/docs/accounts/policies/signing-thresholds) lists setups that pass, and [Add a backup signer](/docs/accounts/guides/self-custody#add-a-backup-signer) adds one to an existing account.

## Key rotation limits

- Tempo can't recover an account whose remaining signers can't reach the threshold.
- Signer updates don't touch access keys. A device key on a lost phone keeps paying within its limits until you [revoke it](/docs/accounts/access-keys/revocation).
- Recovery signers can also approve payments at their weight. Keep each one below the threshold on its own.
- Tempo can't tell whether a signer still holds its key. Have each new signer approve once before you rely on it.

Specification: [configurable accounts](https://tips.sh/1107).
