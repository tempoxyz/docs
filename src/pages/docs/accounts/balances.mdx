# Balances and activity

Read stablecoin balances from their token contracts and use account activity to show deposits, payments, and other changes.

## Read a stablecoin balance

This example reads AlphaUSD on Moderato testnet. Set `TEMPO_ACCOUNT_ADDRESS` to the address you want to inspect.

```bash
pnpm add viem
```

```ts [balance.ts]
import { getAddress } from 'viem'
import { tempoModerato } from 'viem/chains'
import { createClient } from 'viem/tempo'

const accountAddress = process.env.TEMPO_ACCOUNT_ADDRESS
if (!accountAddress) throw new Error('Set TEMPO_ACCOUNT_ADDRESS')

const account = getAddress(accountAddress)
const token = '0x20c0000000000000000000000000000000000001'
const client = createClient({ chain: tempoModerato })

const [balance, { symbol }] = await Promise.all([
  client.token.getBalance({ account, token }),
  client.token.getMetadata({ token }),
])

console.log(`${balance.formatted} ${symbol}`)
```

Identify the token by its network and contract address. `balance.amount` contains integer base units; `balance.formatted` is the decimal string for display.

## Explain changes in a balance

Use [account activity](/docs/api/activities) for history and [transfers](/docs/api/transfers) for individual token movements. One transaction can produce several transfers.

Keep the token, amount, sender, recipient, and transaction hash together in your application records. Link activity to the [transaction](/docs/api/transactions) when a user needs its status or execution details.

For payment confirmation and reconciliation, follow [Receive a payment](/docs/guide/payments/accept-a-payment#verify-stablecoin-payments).

## Show balances that users can spend

Use TIP-20 balances for spendable stablecoins. Tempo's `eth_getBalance` response is a [compatibility value](/docs/quickstart/evm-compatibility#handling-eth-native-token-balance-checks). Show [Earn positions](/docs/earn) and [Zone balances](/docs/zones) separately.
