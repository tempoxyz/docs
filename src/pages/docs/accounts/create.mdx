# Create an account

Creating a Tempo account takes no API call and no transaction.

Your app computes a Tempo account's address from its first signer, the passkey, device key, or private key that approves its transactions, and the address can receive stablecoins right away. Pick a first signer below to create an account on the Tempo Accounts devnet.

:::warning
**Configurable accounts aren't live yet.** Accounts with several signers and a threshold ([TIP-1107](https://tips.sh/1107)) work only on the [Tempo Accounts devnet](/docs/accounts/create#connect-to-the-devnet), not on mainnet or testnet, and may still change. The sandbox and the first code example create configurable accounts, even with one signer. To build on mainnet or testnet today, [create a single-key account](#create-a-single-key-account).
:::

## How account creation works

1. You choose the first signer: a passkey, a device key, or a private key. It approves alone: its weight is 1, and so is the account's threshold, the total weight an approval needs.
2. Your app computes the address from that signer. The address can receive stablecoins right away and stays the same when you change signers or add [access keys](/docs/accounts/access-keys).
3. The account's first transaction, such as a payment, registers it on the [Tempo Accounts devnet](#connect-to-the-devnet). That transaction pays a network fee in a stablecoin, so fund the address first or [sponsor the fee](/docs/accounts/fees/fee-sponsorship).

## Create an account in code

```ts [account.ts]
import { generatePrivateKey } from 'viem/accounts'
import { Account } from 'viem/tempo'

const privateKey = generatePrivateKey() // Keep this secret: it approves the account's transactions.
const signer = Account.fromSecp256k1(privateKey) // [!code hl]
export const account = Account.fromConfig({ address: 'infer', owners: [signer] }) // [!code hl]

// Save account.address and account.config with your user record.
```

`address: 'infer'` tells [`Account.fromConfig`](https://viem.sh/tempo/accounts/account.fromConfig) to compute the address from the signer, which viem calls an owner. You need the saved `account.config` to [add signers](/docs/accounts/key-management/add-signers) later. Its `version` is a bigint, so store `AccountConfig.toRpc(account.config)` and read it back with `AccountConfig.fromRpc` ([Keep the current configuration](/docs/development/configurable-accounts#keep-the-current-configuration)).

For a passkey or device key, use that signer instead: [signing methods](/docs/accounts/authentication) shows each one. To create a second account from the same key, pass a different 32-byte `salt`. If you already have a single-key account, [upgrade it in place](/docs/accounts/key-management/account-upgrade) on the devnet to keep its address.

## Create a single-key account

On mainnet and testnet today, an account is a [single-key account](/docs/development/single-key-accounts) (EOA): one key, such as a passkey, approves its payments and authorizes its [access keys](/docs/accounts/access-keys), and its address comes from that key. This example creates a passkey account on Moderato testnet and funds it from the testnet faucet:

```ts [passkey-account.ts]
import { tempoModerato } from 'viem/chains'
import { Account, createClient, WebAuthnP256 } from 'viem/tempo'

const credential = await WebAuthnP256.createCredential({ label: 'My Tempo account' }) // [!code hl]
export const account = Account.fromWebAuthnP256(credential) // [!code hl]
// Save credential.id and credential.publicKey with your user record.

const client = createClient({ chain: tempoModerato })
await client.faucet.fundSync({ account: account.address }) // test stablecoins
```

For a private key, use `Account.fromSecp256k1(privateKey)` instead. For mainnet, use the `tempo` chain from `viem/chains` and fund the address with real stablecoins: [Network details](/docs/quickstart/connection-details) lists both networks. A single-key account can't change its key, so losing the key loses the account: see [Passkeys](/docs/accounts/authentication/passkeys#passkey-limits) before customers fund one.

## Connect to the devnet

The Accounts examples connect to the Tempo Accounts devnet, a test network that runs configurable accounts. Its RPC, the endpoint your app sends requests and transactions to, needs a key: [contact Tempo](https://tempo.xyz/contact) for one and set it as the `TEMPO_DEVNET_RPC_KEY` environment variable. The key is a test credential for the devnet, so keep it out of code you commit and out of production apps. In a browser app, read it from your bundler's environment variables instead of `process.env`.
