# Create an account

An account's address comes from its first signer. Nothing to deploy: the address is ready immediately, and the first approved transaction registers the account.

<AccountSandbox />

Every step runs on Tempo devnet, with a passkey on this device or a generated private key.

<span id="try-a-passkey-account" />

## How account creation works

- The first signer (a passkey, a device key, or a private key) starts at weight 1 and threshold 1.
- Later signer, weight, and threshold changes keep the same address and balance.
- The address can receive stablecoins before its first transaction.
- The registering transaction is usually a payment that also authorizes the device's [access key](/docs/accounts/access-keys). [Sponsor the fee](/docs/guide/payments/sponsor-user-fees) so a new account needs no balance.

## Create an account in code

::::code-group

```ts [TypeScript]
import { generatePrivateKey } from 'viem/accounts'
import { Account } from 'viem/tempo'

const signer = Account.fromSecp256k1(generatePrivateKey())
const account = Account.fromConfig({ address: 'infer', owners: [signer] })
```

```bash [CLI]
cast wallet new
```

::::

The CLI creates a private key, whose address is a single-key account. To give it signers and a threshold, [upgrade it](/docs/accounts/key-rotation/account-upgrade). For passkeys and device keys, see [signing methods](/docs/accounts/authentication). Reference: [`Account.fromConfig`](https://viem.sh/tempo/accounts/account.fromConfig) and viem's [configurable accounts guide](https://viem.sh/tempo/guides/configurable-accounts).
