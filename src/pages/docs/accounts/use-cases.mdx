# Use Cases

Find the setup and guides for what you're building.

## Overview

Each use case is a Tempo account setup for one kind of product. The setups differ in who holds which key, such as a customer's passkey, a provider's key, your backend's access key, or an approver's signer.

<span id="consumer-wallets" />

## Apps

For teams building a consumer app, such as a remittance or savings app, on embedded wallets from a provider such as Privy or Turnkey.
