# Agents

These guides let an AI agent pay from an account with its own access key, limited to a budget, an expiry, and scopes, the calls it may make. Tempo rejects any transaction outside those bounds, whatever the agent decides to do. [Access keys](/docs/accounts/access-keys) explains the model.

None of these guides needs a configurable account: access keys are live on mainnet and testnet with a single-key account.

## Choose a guide

| Your agent needs to | Guide |
| --- | --- |
| Pay from an account within a budget, until you revoke its key | [Give an agent a wallet](/docs/accounts/guides/agents/give-an-agent-a-wallet) |
| Pay per request for APIs that use MPP, the Machine Payments Protocol | [Let an agent pay for APIs](/docs/accounts/guides/agents/pay-for-apis) |
| Pay for services from a terminal with the Tempo Wallet CLI | [Let an agent pay for services](/docs/wallet/recipes#let-an-agent-pay-for-services) |
