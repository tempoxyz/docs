# Agents

These guides let an AI agent pay from an account with its own access key: a key with a budget, an expiry, and only the calls its payments use. The account's signers stay with the customer or your approvers, and Tempo rejects any payment outside the key's bounds, whatever the agent decides to do.

An account's signers are the keys allowed to approve for it. An [access key](/docs/accounts/access-keys) signs transactions for the account without them, within bounds they set once. Give each agent its own key, so you can cut one off without touching the others.

## Choose a guide

| Scenario | Guide |
| --- | --- |
| An agent needs to pay from an account, and you want to cap and revoke its access | [Give an agent a wallet](/docs/accounts/guides/agents/give-an-agent-a-wallet) |
| An agent calls paid APIs that charge per request with MPP | [Let an agent pay for APIs](/docs/accounts/guides/agents/pay-for-apis) |

For an agent that pays from a terminal, start with [Tempo Wallet with agents](/docs/wallet/recipes#let-an-agent-pay-for-services).
