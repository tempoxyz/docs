# Users

These guides give each of your users a Tempo account that survives a lost phone and can move to their own wallet, keeping the same address. [How it works](/docs/accounts/how-it-works) explains signers and thresholds.

Every guide here uses a configurable account, which works only on the [Tempo Accounts devnet](/docs/accounts/create#connect-to-the-devnet), not on mainnet or testnet. [Connecting a wallet the user already has](/docs/accounts/guides/users/embed-wallets#connect-a-self-custodial-wallet-instead), such as Tempo Wallet, doesn't need one.

## Choose a guide

| Scenario | Guide |
| --- | --- |
| You embed wallets with Privy or Turnkey, or let users connect Tempo Wallet | [Embed wallets with a provider](/docs/accounts/guides/users/embed-wallets) |
| Users already sign in with your login or your company's SSO | [Sign users in with your login](/docs/accounts/guides/users/sign-in-with-your-login) |
| A user has one signer, so losing it locks the account | [Add a recovery signer](/docs/accounts/guides/users/add-a-recovery-signer) |
| A user lost their phone or passkey | [Recover a user's account](/docs/accounts/guides/users/recover-an-account) |
| A user wants to hold the account in their own wallet | [Hand off to a self-custodial wallet](/docs/accounts/guides/users/hand-off) |
| Your existing wallets each have one private key, and you want them recoverable | [Migrate existing wallets](/docs/accounts/guides/users/migrate-existing-wallets) |
