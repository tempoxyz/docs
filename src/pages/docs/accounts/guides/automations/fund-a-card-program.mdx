# Fund a card program

Your backend funds a customer's card from their Tempo account with an access key the customer's signers approve once. The key pays only the card program's funding address, up to a daily limit that renews on its own, so card spend needs no prompt and Tempo rejects anything over the limit.

<span id="fund-a-card-with-a-daily-limit" />

The examples use Moderato testnet, a Tempo test network whose stablecoins have no value, with AlphaUSD, a test stablecoin.

:::::steps

### Authorize a card-funding key

Choose a [card issuing partner](/docs/partners/cards) and get the address that funds the customer's card. Create a secp256k1 key in your KMS and wrap it as in [Keep the key in your KMS](/docs/accounts/guides/automations/pay-out-from-a-backend#keep-the-key-in-your-kms). Then have the customer's signers authorize its address in your app:

```ts [app/enable-card.ts]
import { parseUnits } from 'viem'
import { Expiry } from 'viem/tempo'

const alphaUsd = '0x20c0000000000000000000000000000000000001'

await client.accessKey.authorizeSync({
  accessKey: { accessKeyAddress: cardKeyAddress, keyType: 'secp256k1' },
  account, // the customer's account, signed by its signers
  expiry: Expiry.days(30),
  limits: [{ token: alphaUsd, limit: parseUnits('500', 6), period: 86_400 }], // 500 AlphaUSD a day
  scopes: [{ address: alphaUsd, selector: 'transfer(address,uint256)', recipients: [cardFundingAddress] }],
})
```

Match the limit to the card's daily spend limit. Show the limit, the card program, and the expiry before the customer approves.

### Fund the program

When the card program reports spend, or before it settles, send the amount to the funding address:

```ts [backend/fund-card.ts]
import { parseUnits } from 'viem'
import { tempoModerato } from 'viem/chains'
import { createClient } from 'viem/tempo'

const backend = createClient({ account: cardKey, chain: tempoModerato, feeToken: alphaUsd })

await backend.token.transferSync({ amount: parseUnits('42.50', 6), to: cardFundingAddress, token: alphaUsd })
```

Tempo rejects a transfer over what's left today, to any other address, or after the expiry. Fees for the key's transactions count against the limit.

### Renew the limit

The limit resets to its full amount every 86,400 seconds. Show what's left next to the card:

```ts [app/card-settings.ts]
const { remaining, periodEnd } = await client.accessKey.getRemainingLimit({ account, accessKey: cardKeyAddress, token: alphaUsd })
```

To raise or lower the limit, the signers [update it](/docs/accounts/access-keys/spending-limits#change-a-spending-limit) with `client.accessKey.updateLimitSync`. To pause the card, they [revoke the key](/docs/accounts/access-keys/revocation#revoke-an-access-key). An expiry can't be extended, so authorize a new key before the 30 days end. See [Renew an expiring key](/docs/accounts/access-keys/expiry#renew-an-expiring-key).
