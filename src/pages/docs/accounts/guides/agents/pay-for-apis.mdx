# Let an agent pay for APIs

Your agent pays for API requests from an account, within a daily budget Tempo enforces.

In this guide, the account's signers authorize an [access key](/docs/accounts/access-keys) that your agent holds, with a budget of 20 OUSD a day, so the agent pays without holding the account's signers. APIs that use the [Machine Payments Protocol (MPP)](/docs/guide/machine-payments) answer `402 Payment Required` with a price; the agent pays and retries, and Tempo rejects any payment past the budget. The examples run on the Tempo Accounts devnet and pay in a test stablecoin.

`client.ts` connects to the Tempo Accounts devnet ([set up the devnet key](/docs/accounts/create#connect-to-the-devnet)). On mainnet and testnet, an agent key works the same from a single-key account; on the devnet, a configurable account can authorize one too.

:::::steps

### Give the agent a budget

The agent holds the key. The account's signers authorize its address with a daily budget and only the calls a one-time MPP payment makes. [Give an agent a wallet](/docs/accounts/guides/agents/give-an-agent-a-wallet) explains each bound.

::::code-group

```ts [authorize-agent.ts]
import { parseUnits } from 'viem'
import { Expiry } from 'viem/tempo'
import { client } from './client'

// A test stablecoin on the devnet
const stablecoin = '0x20c0000000000000000000000000000000000001'

await client.accessKey.authorizeSync({
  accessKey: { accessKeyAddress: agentKeyAddress, keyType: 'p256' }, // the agent's key
  account, // the account, signed by its signers
  expiry: Expiry.days(30),
  // 20 of the stablecoin a day
  limits: [{ token: stablecoin, limit: parseUnits('20', 6), period: 86_400 }], // [!code hl]
  scopes: [ // [!code hl]
    { address: stablecoin, selector: 'transferWithMemo(address,uint256,bytes32)' }, // [!code hl]
    { address: stablecoin, selector: 'transfer(address,uint256)' }, // [!code hl]
  ], // [!code hl]
})
```

```ts [client.ts]
// [!include ~/snippets/accounts-devnet.ts:client]
```

::::

A one-time payment (`charge`) is a transfer to the service with a memo that ties it to the request, so these two scopes cover it. They leave the recipient open so the agent can pay any service; the budget bounds the total. For a [payment session](/docs/guide/machine-payments/pay-as-you-go), also scope its payment-channel calls.

### Pay with MPP

In the agent, pass the key and the devnet `client` to the [MPP client](/docs/guide/machine-payments/client). `Mppx.create` patches `fetch` to pay each `402` and retry the request:

```ts [agent.ts]
import { Mppx, tempo } from 'mppx/client'
import { Account } from 'viem/tempo'
import { client } from './client'

const agentKey = Account.fromP256(privateKey, { access: address }) // the account's address

// pays on the devnet
Mppx.create({ methods: [tempo({ account: agentKey, getClient: () => client })] }) // [!code hl]

const response = await fetch(paidUrl) // [!code hl]
```

Without `getClient`, mppx has no RPC for the devnet and the request fails. Tempo rejects a payment outside the scopes, over the remaining budget, or after the expiry, and the request fails without paying. A terminal agent can use [`tempo request`](/docs/guide/machine-payments/agent) instead.

The paid APIs in [Find services](/docs/guide/machine-payments/discover-services) charge real funds, so to test, run your own [MPP server](/docs/guide/machine-payments/server) on the devnet: in its `tempo()` method, set `currency` to the `stablecoin` address and pass `chainId: 31318` and `getClient: () => client`.

### Watch spending

The agent reads each payment's receipt from the response. Your app reads how much of the budget is left:

```ts [watch-spending.ts]
import { Receipt } from 'mppx'
import { client } from './client'

const receipt = Receipt.fromResponse(response) // [!code hl]
// receipt.reference is the payment's transaction hash

const { remaining, periodEnd } = await client.accessKey.getRemainingLimit({ // [!code hl]
  account: address, // [!code hl]
  accessKey: agentKeyAddress, // [!code hl]
  token: stablecoin, // [!code hl]
}) // [!code hl]
// remaining is in base units; periodEnd is when the budget renews
```

Log each receipt with its request, alert when `remaining` runs low, and show the agent's spending in your app next to a [revoke](/docs/accounts/access-keys/revocation#revoke-an-access-key) action.

## Agent API payment limits

- The budget caps total spend, not the price of one request, so one expensive request can use the whole day's budget. To cap each request, [handle payments manually](/docs/guide/machine-payments/client#handle-mpp-payments-manually) and check the price before paying, or use `tempo request --max-spend` in a terminal.
- The key's fees count against the budget unless the service sponsors them.
