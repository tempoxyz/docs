# Give an agent a wallet

On Tempo, an agent's wallet is an access key: a key the agent holds that pays from an account, but only within a budget, an expiry, and scopes, the calls it may make. The account's signers, the keys the customer or your approvers hold, set those bounds when they authorize the key, and Tempo enforces them on every transaction, whatever the agent decides to do.

### Authorize the agent's key

Give each agent its own key, generated where it runs, so you can revoke one without stopping the others. Only the key's address leaves the agent:

```ts [agent-key.ts]
import { Account, P256 } from 'viem/tempo'

const privateKey = P256.randomPrivateKey() // store in the agent runtime's secret storage
const agentKey = Account.fromP256(privateKey, { access: address }) // the account's address
const agentKeyAddress = agentKey.accessKeyAddress // send to the signers; save it with the agent's name
```

The signers authorize that address and its bounds in one transaction:

```ts [authorize-agent.ts]
import { parseUnits } from 'viem'
import { Expiry } from 'viem/tempo'
import { client } from './client'

const alphaUsd = '0x20c0000000000000000000000000000000000001'

await client.accessKey.authorizeSync({
  accessKey: { accessKeyAddress: agentKeyAddress, keyType: 'p256' },
  account, // the account, signed by its signers
  expiry: Expiry.days(30),
  limits: [{ token: alphaUsd, limit: parseUnits('50', 6), period: 86_400 }], // 50 AlphaUSD a day
  scopes: [{ address: alphaUsd, selector: 'transferWithMemo(address,uint256,bytes32)' }],
})
```

<span id="set-its-budget-and-scopes" />

Fit all three bounds to the agent's task. Leaving one out removes that check.

- [`limits`](/docs/accounts/access-keys/spending-limits) is the budget, in base units: AlphaUSD has 6 decimals, so `parseUnits('50', 6)` is 50 AlphaUSD. `period: 86_400` renews it daily; leave `period` out for a one-time budget. The key's fees count against it unless a [fee payer](/docs/accounts/fees/fee-sponsorship) covers them.
- [`scopes`](/docs/accounts/access-keys/scopes) lists the only calls the key can make: here, sending AlphaUSD with a memo.
- [`expiry`](/docs/accounts/access-keys/expiry) is when the key stops working.

Never give an agent an [admin access key](/docs/accounts/access-keys/admin-access-keys). It has no budget, scopes, or expiry and can authorize more keys, so the agent could spend the whole balance.

### Let the agent pay

The agent signs with its key and pays from the account's balance. The signers don't approve each payment:

```ts [agent-pay.ts]
import { parseUnits, stringToHex } from 'viem'
import { client } from './client'

await client.token.transferSync({
  account: agentKey,
  amount: parseUnits('2', 6),
  memo: stringToHex('order-1042'), // a memo makes this transferWithMemo, the key's one allowed call
  to: recipient,
  token: alphaUsd,
})
```

Tempo rejects any payment over the remaining budget, outside the scopes, or after the expiry. Read what's left with `client.accessKey.getRemainingLimit`. The signers can [change the limit](/docs/accounts/access-keys/spending-limits#change-a-spending-limit) or [the scopes](/docs/accounts/access-keys/scopes#change-allowed-calls) without replacing the key.

<span id="revoke-it" />

### Revoke the agent's key

When the task ends or the agent misbehaves, the signers revoke the key by its saved address:

```ts [revoke-agent.ts]
import { client } from './client'

await client.accessKey.revokeSync({ account, accessKey: agentKeyAddress })
```

[Revocation](/docs/accounts/access-keys/revocation) is permanent. Once it confirms, Tempo rejects every transaction the key signs, so show the agent's access as removed only then.

## Agent wallet limits

- The budget caps the total, not each payment, so one large payment can use all of it. Cap each payment in the agent's own code; in a terminal, [`tempo request --max-spend`](/docs/cli/request) caps what one command spends.
- An expiry can't be extended. To keep the agent running past it, [authorize a new key](/docs/accounts/access-keys/expiry#renew-an-expiring-key) before it passes.
