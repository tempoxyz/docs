# Set up a company treasury

:::warning
**Not live yet.** Configurable accounts ([TIP-1107](https://tips.sh/1107)) are in early development and run only on Tempo devnet. We're seeking feedback; behavior may change.
:::

Create a treasury account that three approvers control, where any two approve each payment and no one can move funds alone. Tempo checks every approval itself, so neither your app nor a single compromised key can pay without a second approver.

<span id="treasury-model" />

The treasury is one Tempo account: an address that holds the company's stablecoins. Each approver is a signer, a key allowed to approve for the account, with a weight of 1. The threshold of 2 is the total weight each transaction needs. A transaction is a signed request that Tempo executes, such as a payment, and Tempo rejects any transaction whose approvals don't reach the threshold. Each transaction also pays a small fee, which the treasury pays in a stablecoin from its own balance unless a [fee payer](/docs/accounts/fees/fee-sponsorship) sponsors it.

The examples run on Tempo devnet, a test network whose stablecoins have no value. They use a viem `client` on Tempo devnet, `createClient({ chain: tempoDevnet })` from `viem/tempo`, and AlphaUSD at `0x20c0000000000000000000000000000000000001`.

:::::steps

<span id="create-the-treasury-account" />

### Create the treasury

Give each approver a key in a different place, so one breach can't reach two of them: a hardware wallet, a KMS, or an HSM for each team, or the approver's passkey. [Private keys](/docs/accounts/authentication/private-keys) compares key sources.

```ts [treasury.ts]
import { Account } from 'viem/tempo'

const env = (name: string) => process.env[name] as `0x${string}`

const finance = Account.fromSecp256k1(env('FINANCE_SIGNER_KEY'))
const operations = Account.fromSecp256k1(env('OPERATIONS_SIGNER_KEY'))
const controller = env('CONTROLLER_PASSKEY_ADDRESS') // approves on their own device

const owners = [
  { owner: finance.address, weight: 1 },
  { owner: operations.address, weight: 1 },
  { owner: controller, weight: 1 },
]
const threshold = 2

const treasury = Account.fromConfig({ address: 'infer', owners, threshold })
// Save treasury.address, owners, and threshold with your treasury record.
```

`address: 'infer'` derives the treasury's address from its first signers and threshold, so you know it before the treasury sends anything. Fund it by sending stablecoins to that address. The address stays the same when you change signers later, so save it rather than deriving it again.

### Collect approvals

Each approval is a signature over the same transaction, so approvers sign separately, on their own devices, in any order. The first approver starts the payment, and a second approves its hash:

```ts [pay.ts]
import { parseUnits } from 'viem'

const alphaUsd = '0x20c0000000000000000000000000000000000001'

const { receipt } = await client.token.transferSync({
  account: treasury,
  amount: parseUnits('1200', 6), // $1,200 in base units: AlphaUSD has 6 decimals
  owner: finance, // the first approver
  to: vendor,
  token: alphaUsd,
})

await client.sendTransactionSync({ account: treasury, hash: receipt.transactionHash, owner: operations })
```

The payment goes through once the approvals reach the threshold. Tempo rejects signatures beyond it, so stop collecting once two approvers sign. Your app decides how approvers learn there's a payment to review, such as a notification with the payment's recipient and amount. [Collect and verify approvals](/docs/accounts/policies/signing-thresholds#collect-and-verify-approvals) covers checking approvals in a contract or backend.

<span id="treasury-limits" />

## Treasury limits

- An account has 1 to 48 signers, and a transaction carries up to 8 approvals.
- A changed signer list voids approvals collected for the old one. Collect them again.
- `InvalidConfig` means the update didn't start from the treasury's current signers, usually because another update landed first.

When an approver leaves, follow [Offboard an approver](/docs/accounts/guides/teams/offboard-an-approver).
