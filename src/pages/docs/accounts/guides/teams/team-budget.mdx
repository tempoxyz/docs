# Give a team a budget

A team budget lets a team pay from the [company treasury](/docs/accounts/guides/teams/company-treasury) up to a daily limit, without asking the treasury's approvers for each payment. The team gets its own account, where any two of its three members approve a payment, and the treasury's approvers authorize that account once as an [access key](/docs/accounts/access-keys). The team account holds no funds: it pays from the treasury's balance, and Tempo rejects any payment over what's left of the limit.

:::warning
**Configurable accounts aren't live yet.** Accounts with several signers and a threshold ([TIP-1107](https://tips.sh/1107)) work only on the [Tempo Accounts devnet](/docs/accounts/create#connect-to-the-devnet), not on mainnet or testnet, and may still change. This guide uses one.
:::

### Create the team account

Create it [like the treasury](/docs/accounts/guides/teams/company-treasury#create-the-treasury). `member1` to `member3` are keys the members hold themselves, such as passkeys or keys in your KMS.

```ts [team.ts]
import { Account } from 'viem/tempo'

const team = Account.fromConfig({
  address: 'infer',
  owners: [
    { owner: member1, weight: 1 },
    { owner: member2, weight: 1 },
    { owner: member3, weight: 1 },
  ],
  threshold: 2,
})
// Save team.address with the team's record. The treasury authorizes this address.
```

### Authorize it from the treasury

Treasury approvers [authorize](/docs/accounts/access-keys#authorize-an-access-key) the team account's address as an access key once, with approvals that reach the treasury's threshold. Set bounds that match the team's work:

| Bound | Recommended value |
| --- | --- |
| [Spending limit](/docs/accounts/access-keys/spending-limits) | A daily limit per stablecoin, such as 50,000 AlphaUSD |
| [Scopes](/docs/accounts/access-keys/scopes) | Transfers to the team's approved recipients only |
| [Expiry](/docs/accounts/access-keys/expiry) | 90 days, then authorize the team again |

<span id="pay-as-the-team" />

### Track the budget

To pay, two members sign as the team account, which acts as the treasury's access key, and the payment comes from the treasury's balance. viem 2.57.5 has no helper yet for signing as a team account (draft [TIP-1111](https://tips.sh/1111)), so the demo shows that flow. Reading what's left of the daily limit works as for any access key:

```ts [budget.ts]
import { client } from './client'

const { remaining } = await client.accessKey.getRemainingLimit({
  account: treasury.address,
  accessKey: team.address,
  token: alphaUsd,
})
```

`remaining` is in base units: AlphaUSD has 6 decimals, so `1_950_000_000n` is 1,950 AlphaUSD. To end the budget, the treasury's approvers [revoke](/docs/accounts/access-keys/revocation#revoke-an-access-key) the team account.

## Team budget limits

- The budget covers the whole team, not each member. Changing the team's signers keeps the authorization and what the team has already spent.
- Only the team's own signers can spend the budget. Access keys on the team account can't.
- The team can't authorize keys, change the treasury's signers, or count toward the treasury's threshold.
