# Automations

Your backend moves a customer's stablecoins without a per-payment approval, within limits Tempo enforces.

In each guide, the customer's signers authorize one access key for your backend, once. Tempo lets that key pay only the recipients or contracts the customer approved, up to a daily limit, until it expires. Access keys are live on mainnet and testnet with a single-key account, so none of these guides needs a configurable account.

[Access keys](/docs/accounts/access-keys) explains the model. [Use cases](/docs/accounts/use-cases) compares the setups.

## Choose a guide

| Your backend needs to | Guide |
| --- | --- |
| Send payouts to contractors or sellers the customer approved | [Pay out from a backend](/docs/accounts/guides/automations/pay-out-from-a-backend) |
| Move a customer's idle balance into an Earn vault each night | [Sweep idle balances into Earn](/docs/accounts/guides/automations/sweep-into-earn) |
| Top up a card program as the customer spends | [Fund a card program](/docs/accounts/guides/automations/fund-a-card-program) |

For an AI agent that decides what to pay, see [Agents](/docs/accounts/guides/agents).
