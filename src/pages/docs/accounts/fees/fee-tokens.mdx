# Fee tokens

A fee token is the USD stablecoin a transaction pays its network fee in, so an account needs no separate token for fees. Set a default fee token once, and override it on any transaction that should pay in another stablecoin.

<span id="fee-token-limits" />

## Supported fee tokens

For most accounts, use [OUSD](/docs/guide/ousd). Before a transaction runs, Tempo checks its fee token:

- It's a [TIP-20 token](/docs/protocol/tip20/overview), Tempo's token standard, whose currency is USD.
- The account paying the fee holds enough of it to cover the maximum fee: the gas limit times the gas price.
- If the block's validator wants its fees in a different stablecoin, the [Fee AMM](/docs/protocol/fees/spec-fee-amm), Tempo's built-in exchange pools, has enough liquidity to convert it.

If any check fails, the transaction is invalid and isn't included. Tempo doesn't try another token.

<span id="set-an-accounts-default-fee-token" />

## Set a default fee token

The default covers every transaction the account pays the fee for, including ones it sponsors for other accounts as a [fee payer](/docs/accounts/fees/fee-sponsorship). Without one, Tempo follows the [fee token precedence](/docs/accounts/fees#fee-token-precedence), which can fall back to pathUSD, a stablecoin the account might not hold.

```ts [set-fee-token.ts]
const { receipt } = await client.fee.setUserTokenSync({
  token: '0x20c0000000000000000000006a37da5c996874be', // OUSD on Tempo mainnet
})
```

This calls `setUserToken` on the FeeManager, Tempo's built-in fee contract. Read the current default with `client.fee.getUserToken()`.

The default outranks the token being transferred. With OUSD as the default, a transfer of another stablecoin still pays its fee in OUSD, and is invalid if the account's OUSD can't cover it.

## Override the fee token per transaction

Pass `feeToken` to pay one transaction's fee in a different stablecoin. It outranks the default and every other rule, for that transaction only:

```ts [transfer.ts]
import { parseUnits } from 'viem'

await client.token.transferSync({
  amount: parseUnits('25', 6),
  feeToken: usdc, // this transaction's fee token
  to: recipient,
  token: ousd,
})
```

On a sponsored transaction, the account signs with the fee token blank, and the fee payer chooses it.

[Choose a fee token](/docs/guide/payments/pay-fees-in-any-stablecoin) runs a per-transaction fee token in a live demo, and shows both calls in Wagmi, Rust, Python, Go, and Cast.

Specification: [fee token preferences](/docs/protocol/fees/spec-fee#fee-token-preferences).
