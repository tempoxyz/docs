# Set a Fee Token

Sets an account's default fee token from a browser wallet, with no code.

<FeeTokenTool />

## Overview

The tool sends the same `setUserToken` call as [Set a Default Fee Token](/docs/accounts/fees/fee-tokens#set-a-default-fee-token). It works with any browser wallet on Tempo Mainnet or Tempo Testnet.

The account needs a balance only in the stablecoin it sets. The transaction pays its own fee in that stablecoin, so an account that holds only USDC.e can set USDC.e.

## Link to a Network and Stablecoin

The tool opens on the network and stablecoin its link names. The address bar follows your choices, so **Copy link** shares them.

| Parameter | Values |
| --- | --- |
| `network` | `mainnet` or `testnet`. Defaults to `mainnet`. |
| `token` | A listed stablecoin, such as `ousd`, `usdce`, or `pathusd` on mainnet, or a USD TIP-20 address. |

A link opens on its stablecoin even when the account has another fee token. For example, this link opens on USDC.e on mainnet:

```text
https://tempo.xyz/developers/docs/accounts/fees/set-fee-token?network=mainnet&token=usdce
```
