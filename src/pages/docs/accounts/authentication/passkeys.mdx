# Passkeys

A passkey is a WebAuthn key that the customer approves with their face, fingerprint, PIN, or security key. It's the signer only the customer holds, so it keeps the account in their control.

The private key never leaves the customer's authenticator, and Tempo checks each WebAuthn signature on chain. A passkey trusts the customer's device and, for a synced passkey, their passkey provider. No app or wallet provider is involved. Use it for customer approvals, signer changes, and recovery of other signers.

## Passkey authenticators

| Authenticator | How the customer approves |
| --- | --- |
| Apple devices | Face ID or Touch ID |
| Windows | Windows Hello face, fingerprint, or PIN |
| Android | The device's fingerprint, face, or screen lock |
| Security keys | A touch on a key such as YubiKey |

Synced passkeys follow the customer to new devices through iCloud Keychain, Google Password Manager, or a password manager. A security key's passkey stays on that key, so add a second signer for [recovery](/docs/accounts/guides/self-custody#recover-from-a-lost-passkey).

## Open an account with a passkey

<PasskeyAccountDemo />

The demo creates a passkey on Moderato testnet and shows its account address.

```ts [passkey.ts]
import { Account, WebAuthnP256 } from 'viem/tempo'

const passkey = Account.fromWebAuthnP256(await WebAuthnP256.createCredential({ label: 'Acme' }))
const account = Account.fromConfig({ address: 'infer', owners: [passkey] })
```

`account.address` receives stablecoins right away. The first transaction registers the account.

## Passkey signer weights

We recommend a passkey at weight 2 next to a backup key and a recovery provider's key at weight 1 each, at threshold 2. The passkey approves alone, and the two keys together recover it. Keep the backup key with the customer and the recovery key with a separate party, so neither approves alone. See [Signing thresholds](/docs/accounts/security-policies).

To add a passkey to an existing account or back it up with other keys, see [Set up self-custody](/docs/accounts/guides/self-custody). For other methods, see [Signing methods](/docs/accounts/authentication).
