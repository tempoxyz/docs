# Configurable Accounts

This page walks through what's possible and what changes with configurable accounts and the T14 network upgrade.

## Overview

A configurable account is a Tempo account with several signers. Each signer has a weight, and a transaction runs once the weights of its approvers reach the account's threshold, such as any 2 of 3. The signers can change, but the address, balances, and history stay the same.

A [single-key account](/docs/development/single-key-accounts) has one key, and losing that key loses the account. Configurable accounts arrive with the [T14 network upgrade](/docs/protocol/upgrades/t14).

Each demo on this page runs a real account on the Tempo Accounts devnet, with no setup.

## Terms

- **Signer:** A [passkey, device key, or private key](/docs/accounts/authentication) that approves the account's transactions. Viem calls it an owner.
- **Threshold:** The total signer weight a transaction needs, set with each signer's [weight](/docs/accounts/policies/signing-thresholds).
- **Multisig:** A configurable account whose threshold needs more than one signer. It isn't a separate account type.
- **Configuration update:** One transaction that replaces the signers and threshold at the same address.
- **Access key:** A key that pays for the account on its own, within the [limits](/docs/accounts/access-keys) you set.

## Team Multisig

Finance, operations, and a controller each hold a signer, and any two approve each payment. No one moves funds alone. Send a payment with one approver, then with two.

## Multi-Factor Accounts

A user's passkey approves alone, and a backup key and a recovery provider approve together. Losing any one signer doesn't lock the account.

<AccountSandbox preset="multi-factor" variant="compact" />

[Signing Thresholds](/docs/accounts/policies/signing-thresholds#recommended-signer-setups) lists the recommended setups.

## Account Recovery

The remaining signers replace a lost passkey in one configuration update, at the same address. Replace the passkey, then pay with the new one.

## Key Rotation

Swap a key or remove an approver in one update, without moving funds. Rotate the operations key, and the old key stops approving.

## Self-Custodial Wallets

A wallet provider's key and the user's own signers share the account, and the user can leave the provider without moving funds. Move the account from its provider to the user's wallet.

## Account Upgrade

An existing single-key account becomes a configurable account at the same address, keeping its balances. Accounts that don't upgrade keep working unchanged.

<UpgradeAccountDemo />

Build it with [Account Upgrade](/docs/accounts/account-configuration/account-upgrade).

## Admin Access Keys Removed

T14 removes [admin access keys](/docs/accounts/access-keys/admin-access-keys). Tempo rejects new ones, and existing ones keep paying as access keys without limits. To let a second device manage keys, add it as a signer instead.

Single-key accounts and limited access keys need no changes. If you use admin access keys today, [contact us](https://tempo.xyz/contact) to plan the change.

## Build Your Own

Pick a first signer to create an account, then add signers, authorize access keys, and send payments.

Your own app needs an RPC key to reach the devnet. [Contact us](https://tempo.xyz/contact) for one, then follow [Create an Account](/docs/accounts/create#create-a-configurable-account) to create one in code.
