# Configurable Accounts

This page walks through what configurable accounts make possible and what changes with the T14 network upgrade.

## Overview

A configurable account is a Tempo account with several signers. Each signer has a weight, and a transaction runs once the weights of its approvers reach the account's threshold, such as any 2 of 3. The signers can change, but the address, balances, and history stay the same.

A [single-key account](/docs/development/single-key-accounts) has one key, and losing that key loses the account. Configurable accounts arrive with the [T14 network upgrade](/docs/protocol/upgrades/t14).

## Terms

- **Signer:** A [passkey, device key, or private key](/docs/accounts/authentication) that approves the account's transactions. Viem calls it an owner.
- **Threshold:** The total signer weight a transaction needs, set with each signer's [weight](/docs/accounts/policies/signing-thresholds).
- **Multisig:** A configurable account whose threshold needs more than one signer. It isn't a separate account type.
- **Configuration update:** One transaction that replaces the signers and threshold at the same address.
- **Access key:** A key that pays for the account on its own, within the [limits](/docs/accounts/access-keys) you set.

## What Changes With T14

| Change | What it does | Guide |
| --- | --- | --- |
| Team multisig | Any two of three approvers sign each payment, so no one moves funds alone. | [Set Up a Team Multisig](/docs/accounts/custodians/team-multisig) |
| Account recovery | The remaining signers replace a lost passkey or key, at the same address. | [Recover a User's Account](/docs/accounts/apps/recover-an-account) |
| Key rotation and offboarding | Swap a key or remove an approver in one update, without moving funds. | [Configuration Updates](/docs/accounts/account-configuration/configuration-updates) |
| Account upgrade | Adds backup signers to a single-key account, keeping its address and balances. Accounts that don't upgrade keep working unchanged. | [Account Upgrade](/docs/accounts/account-configuration/account-upgrade) |
| Self-custodial wallets with a provider | Your provider's key and the user's passkey approve together, and the user can leave without you. | [Self-Custodial Wallets](/docs/accounts/apps/self-custodial-wallets) |
| A team account as an access key | A team's configurable account acts as another account's access key, approving with its own signers. | [Account Keychain](/docs/development/account-keychain#access-key-types) |
| Admin access keys removed | Tempo rejects new admin access keys. Existing ones keep paying as access keys without limits. | [Admin Access Keys](/docs/accounts/access-keys/admin-access-keys) |

Single-key accounts and limited access keys need no changes. If you use admin access keys to manage a user's other keys, add that device as a signer instead, and [contact us](https://tempo.xyz/contact) to plan the change.

The specifications are [Configurable Accounts](https://tips.sh/1107), [Configurable Account Access Keys](https://tips.sh/1111), [Account Migration and Original-Key Retirement](https://tips.sh/1113), and [Remove Admin Access Keys](https://tips.sh/1137).
