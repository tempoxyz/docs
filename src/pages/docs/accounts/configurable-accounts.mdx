# Configurable Accounts

This page walks through what's possible and what changes with configurable accounts and the T14 network upgrade.

<span id="terms" />

## Overview

A configurable account is a Tempo account with several signers, each with a weight. A transaction runs once its approvers' weights reach the account's threshold, such as any 2 of 3, which makes it a multisig. The signers can change, but the address, balances, and history stay the same.

<span id="admin-access-keys-removed" />

## What Changes With T14

- **Configurable Accounts:** Accounts can have several signers and a threshold, and replace signers at the same address.
- **Single-Key Accounts:** Existing accounts keep working unchanged. Upgrading one to a configurable account is optional.
- **Admin Access Keys:** Tempo rejects new [admin access keys](/docs/accounts/access-keys/admin-access-keys). Existing ones keep paying as access keys without limits, and only an account's own key or its signers manage its access keys.

### Migrate Admin Access Keys

If you use admin access keys to manage a user's other keys, change that before T14:

1. Add the device that held the admin key as a [signer](/docs/accounts/account-configuration/configuration-updates#add-a-signer).
2. Revoke the admin keys you no longer need, since they keep paying without limits.
3. [Contact us](https://tempo.xyz/contact) to plan the change.

Single-key accounts and limited access keys need no changes.

## What You Can Build

- **Team Multisig:** Any two of three approvers sign each payment, so no one moves funds alone. See [Set Up a Team Multisig](/docs/accounts/custodians/team-multisig).
- **Account Recovery:** A backup key and a recovery provider replace a lost passkey at the same address. See [Recover a User's Account](/docs/accounts/apps/recover-an-account).
- **Key Rotation:** Swap a key or remove an approver in one update, without moving funds. See [Configuration Updates](/docs/accounts/account-configuration/configuration-updates).
- **Account Upgrade:** Add backup signers to a single-key account, keeping its address and balances. See [Account Upgrade](/docs/accounts/account-configuration/account-upgrade).
- **Self-Custodial Wallets:** A provider's key and the user's passkey approve together, and the user can leave the provider. See [Set Up a Self-Custodial Wallet](/docs/accounts/apps/self-custodial-wallets).
- **Team Account as an Access Key:** A team's configurable account pays for another account, approving with its own signers. See [Access Keys](/docs/accounts/access-keys).
