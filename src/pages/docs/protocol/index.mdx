## How protocol changes happen

Tempo Improvement Proposals (TIPs) describe protocol changes. A proposal does not establish that a feature is active. Check the [network upgrade timeline](/docs/protocol/upgrades) for testnet and mainnet activation, or read the [upgrade process](/docs/guide/node/upgrade-cadence) for operator guidance.

## Tempo Improvement Proposals

TIPs are grouped below by the network upgrade that includes them, newest first. **Approval alone does not mean a change is live.** Use each upgrade's activation record to check availability on your network.

**Network status as of October 9, 2026:** mainnet is on [T11](/docs/protocol/upgrades/t11); Moderato testnet is on [T12](/docs/protocol/upgrades/t12). T12 mainnet activation is scheduled for **October 13, 2026 at 14:00 UTC**.

This index reconciles the [canonical TIP sources](https://github.com/tempoxyz/tempo/tree/main/tips) with the [network upgrade records](/docs/guide/node/network-upgrades). Proposal status fields can lag activation; the upgrade records determine the network status shown here. Meta TIPs collect additional fixes included in an upgrade.
