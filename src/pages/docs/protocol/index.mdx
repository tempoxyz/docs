# Specifications

Read the rules that govern Tempo accounts, transactions, assets, and settlement. Use the product guides for implementation workflows and these specifications for exact behavior and interfaces.

[View the changelog →](/docs/protocol/upgrades)

## How protocol changes happen

Tempo Improvement Proposals (TIPs) describe proposed protocol changes. Named network upgrades group changes for activation on a particular network; a proposal alone does not establish that a feature is active.

Upgrades activate on Moderato testnet before mainnet. Check the [upgrade's timeline and integration notes](/docs/protocol/upgrades) to determine which behavior applies to your deployment. Node software releases can support a network upgrade or contain maintenance fixes without changing protocol rules.

Read the [upgrade process](/docs/guide/node/upgrade-cadence) for operator rollout guidance, or browse [TIPs](https://tips.sh/) for specifications and rationale.
