# T14 Network Upgrade

T14 is the planned network upgrade that brings configurable accounts to testnet and mainnet.

:::info[T14 status]
T14 is planned and its scope may still change. No activation dates are set. Until T14 activates, configurable accounts run only on the [Tempo Accounts devnet](/docs/accounts/create#connect-to-the-devnet).
:::

## T14 overview

- **Configurable accounts:** an account approved by several signers, each with a weight, once their weights reach a threshold. The address stays the same when signers change. See [Tempo Accounts](/docs/accounts).
- **Configuration updates:** the current signers replace the signer list and threshold in one transaction, at the same address. See [Account configuration](/docs/accounts/account-configuration).
- **Upgrades from single-key accounts:** an existing single-key account becomes a configurable account at the same address. See [Account upgrade](/docs/accounts/account-configuration/account-upgrade).
- **Configurable accounts as access keys:** a team's configurable account can act as another account's access key, approving with its own signers.
