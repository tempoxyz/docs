# T12 Network Upgrade

T12 updates DEX quotes, payment-channel policies, expiring transactions, and precompile validation.

:::info[Upcoming upgrade]
The changes below take effect when T12 activates on your network.
:::

## T12 upgrade overview

- **Accurate DEX quotes.** Quotes use the same per-order fill math and rounding as swaps for an identical state snapshot. [TIP-1088](https://github.com/tempoxyz/tempo/blob/main/tips/tip-1088.md).
- **Policy-aware payment channels.** Recipient-restricted tokens can use channels with policy checks on the logical payer-to-payee payment. [TIP-1095](https://github.com/tempoxyz/tempo/blob/main/tips/tip-1095.md).
- **Expiring nonce discriminators.** Distinct `nonce` values give otherwise identical transactions different hashes. [TIP-1106](https://github.com/tempoxyz/tempo/blob/main/tips/tip-1106.md).
- **Trailing-byte support.** Precompile calls accept trailing bytes after valid ABI arguments again. [TIP-1116](https://github.com/tempoxyz/tempo/blob/main/tips/tip-1116.md).

## Operator impact

Upgrade validator, RPC, and indexer nodes to the T12-compatible release before activation on each network.

## Integration impact

- **DEX integrations:** recheck gas budgets for quotes and `getTickLevel()`. Read tick liquidity through `getTickLevel()` or active orders; the stored `totalLiquidity` aggregate becomes stale.
- **Channel indexers:** correlate channel events with token transfers to identify the payer.
- **Transaction builders and indexers:** preserve explicitly supplied nonce values and treat them as identifiers. Enable nonzero values after activation.
- **Precompile integrations:** retest affected reads, gas estimation, and transactions with the calldata your integration sends.
