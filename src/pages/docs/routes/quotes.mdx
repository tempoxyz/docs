# Quotes and fees

Quote the exact payment before requesting a signature or showing deposit instructions. The supported route directory identifies possible paths; the quote gives terms for the selected amount and recipient.

## Choose which amount to fix

For connected-wallet transfers, use `GET /v1/routes/transfers/quote`. Select `exactSource` to fix the amount sent or `exactDestination` to fix the amount received. Express `amount` in the base units of the token selected by that mode.

For deposit addresses, use `GET /v1/routes/deposit-addresses/quote` with the source chain, source token, destination token, and amount. Check the [endpoint reference](/docs/api/routes/deposit-addresses) for the supported parameters.

## Show the payment terms

Present the source asset and amount, destination asset and amount, minimum destination amount where returned, and fees. Keep the network visible for both assets; a token symbol alone does not identify the route.

`destinationAmount` includes route deductions. The `fees` array lists separately charged fees, so an empty array does not establish a fee-free route.

A quote does not create or reserve a transfer. Review the terms returned when you create the transfer as well, before asking the wallet to sign its action.

## Refresh expired quotes

For transfers, read `quote.expiresAt`. If the quote expires before submission, obtain fresh terms rather than signing an expired action. Show changed terms to the user before continuing.
