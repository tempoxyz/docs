## Set up the Routes API

:::::steps

<span id="routes-api-key-scopes" />

### Create a Routes API key

Create a key in [Tempo Console](https://tempo.xyz/console/?to=/:org/api-keys) with the scopes your flow needs. Keep it on your backend; it authenticates your application and doesn't sign transactions.

| Scope | Allows |
| --- | --- |
| `routes:read` | Quotes, and transfer and deposit status reads |
| `routes:write` | Creating transfers and deposit addresses, and registering source transactions |
| `data:read` | Reading the [route directory](/docs/routes/networks) with your key, which applies your organization's access policy |

<span id="configure-the-client" />

### Configure the client

Set `TEMPO_API_KEY` in your environment. TypeScript uses Node.js with built-in `fetch`. Python uses `requests`. cURL examples require `curl` and `jq`.

::::code-group

```ts [TypeScript (fetch)]
const api = 'https://api.tempo.xyz/v1'
const headers = {
  'tempo-api-key': process.env.TEMPO_API_KEY!,
  'Content-Type': 'application/json',
}
```

```python [Python (requests)]
import os
import requests

api = "https://api.tempo.xyz/v1"
headers = {
    "tempo-api-key": os.environ["TEMPO_API_KEY"],
    "Content-Type": "application/json",
}
```

```bash [cURL (API)]
# Set TEMPO_API_KEY in your terminal's environment before running requests.
curl --fail-with-body 'https://api.tempo.xyz/v1/routes' \
  --header "tempo-api-key: $TEMPO_API_KEY"
```

### Create a transfer or a deposit address

Create a [transfer](/docs/routes/transfers) when your user's wallet signs the source calls. Create a [deposit address](/docs/routes/deposits) when the sender pays from any wallet or exchange.

Create requests require an `idempotency-key` header. Assign one key per operation, such as one payment or one customer's deposit address, and store it with that record before sending the request:

::::code-group

```ts [TypeScript (fetch)]
const requestKey = crypto.randomUUID() // Persist with your payment record.
```

```python [Python (requests)]
import uuid

requestKey = str(uuid.uuid4())  # Persist with your payment record.
```

```bash [cURL (API)]
# Choose and retain one key per operation, including across retries.
ROUTE_REQUEST_KEY="my-payment-001"
```

::::


Reuse the key when you retry the same request with unchanged inputs. Matching requests replay the successful response for 24 hours. A request with changed inputs conflicts.
