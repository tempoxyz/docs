# Deposit funds

Start with a funded [Tempo account](/docs/accounts) and a [vault](/docs/earn/vaults) that accepts its stablecoin. Use the Earn API to inspect the vault, then its provider's documented contract interface to submit the deposit.

## Deposit into a vault

:::::steps

### Check the asset and access requirements

Save the vault address and network together. Match the account's token to the accepted asset and confirm the account's eligibility. Read `capabilities` and `state.depositsPaused` before enabling the deposit action.

### Prepare the deposit

Confirm the contract interface, deployment, and required token approvals with the provider or Tempo. Show the asset, amount, and destination vault before the account signs the deposit.

A deposit is a contract interaction. Transferring stablecoins directly to the vault address does not establish a position. The Earn read API does not submit deposits or withdrawals.

### Submit and verify the position

Use the account's signer to sign and submit the required contract calls through the supported interface. After execution, verify the resulting share balance. Save the transaction hash, deposited amount, and shares received for reconciliation.

Read `GET /v1/earn/vaults/{vaultId}/positions/{address}` to display the resulting position.

:::::

## Display the earning balance

Follow [Balances and earnings](/docs/earn/balances) to show position value, earnings, and rate measurement windows. Make [withdrawal behavior](/docs/earn/withdraw) visible before accepting the deposit.

## Track private Earn activity

For a [Zone](/docs/zones) integration, check `capabilities.privateRouting` and the vault's configured Zone routes. Zone-routed positions use Zone withdrawals rather than the direct account approval flow.

Use `GET /v1/earn/transactions/{senderTag}` to track private Earn execution and return delivery. Show returned funds as available once delivery completes. See the [Earn transaction reference](/docs/api/earn#getearntransaction) for the status fields.

Account position listing supports private Zones; earnings data is currently unavailable for those positions.
