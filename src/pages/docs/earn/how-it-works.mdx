# How Earn works

When your application deposits stablecoins into a vault, the account receives shares representing its position. Use the shares' current asset value to display an earning balance, and the vault's withdrawal interface to return stablecoins to the account.

| Component | Role |
| --- | --- |
| **Vault** | Accepts deposits and accounts for positions. |
| **Vault shares** | Units representing an account's position in the vault. Check the selected vault's share token and contract interface. |
| **Engine** | Connects the vault to a lending market, managed strategy, or liquidity pool. |

A share is not necessarily worth one stablecoin. Its value changes with the underlying strategy's returns, losses, and fees. An account's **position value** is the asset value of all its shares; **earnings** are returns over a period, separate from deposits and withdrawals.

The [Earn API](/docs/api/earn) exposes the vault's engine, share token, accepted asset, accounting state, and supported operations.

## Keep value and liquidity separate

A position's value can change with returns, losses, and fees. It is not necessarily the amount that can be withdrawn immediately. Read the vault's supported withdrawal methods and current terms before showing funds as available to withdraw.

A vault's `verified` flag identifies a curated listing, not a guarantee of return or a description of the strategy's risk. [Choose a vault](/docs/earn/vaults) based on its accepted asset, access rules, strategy, and withdrawal behavior.

Continue with [Deposit](/docs/earn/integrate), then [show balances and earnings](/docs/earn/balances). If you operate a yield strategy, see [Connect a strategy](/docs/earn/providers).
