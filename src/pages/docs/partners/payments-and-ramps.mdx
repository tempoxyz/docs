# Payments & ramps

Find providers for stablecoin issuance, fiat funding, payouts, FX, and payment orchestration. Follow each provider's documentation for its supported integration.

For your application account flow, start with [Accounts](/docs/accounts). To build directly with TIP-20 tokens, use the [stablecoin issuance guides](/docs/guide/issuance). For movement between chains, see [Bridges](/docs/partners/bridges).

<span id="brale" />

## <span className={`partner-logo partner-logo--brale ${partnerLogo().className + ' ' + partnerLogoBrale().className}`} aria-hidden="true" />Brale Stablecoin API

Issue and manage stablecoins, transfer funds, and connect fiat funding and payouts through [Brale's Stablecoin API](https://docs.brale.xyz/).

[API documentation](https://docs.brale.xyz/) · [Create an account](https://app.brale.xyz/buy/signup/)

<span id="bridge" />

## <span className={`partner-logo partner-logo--bridge ${partnerLogo().className + ' ' + partnerLogoBridge().className}`} aria-hidden="true" />Bridge Orchestration & FX

Move money between bank accounts and stablecoin wallets with [Bridge Orchestration & FX](https://www.withbridge.com/product/orchestration). Use virtual accounts for incoming funds and transfers for payouts.

[Tempo integration guide](https://apidocs.bridge.xyz/get-started/guides/move-money/tempo-integration-guide) · [Virtual accounts](https://apidocs.bridge.xyz/get-started/guides/move-money/virtualaccounts)

For other Bridge products, see [Wallets](/docs/partners/wallets#bridge-wallets), [Cards](/docs/partners/cards#bridge-cards), or [Open Issuance](https://www.withbridge.com/product/issuance) for launching a stablecoin.

## <span className={`partner-logo partner-logo--coins-ph ${partnerLogo().className + ' ' + partnerLogoCoinsPh().className}`} aria-hidden="true" />Coins.ph

[Coins.ph](https://www.coins.ph/en-ph/business) provides regulated payment and stablecoin infrastructure for businesses operating in the Philippines. Its APIs support PHP collections and disbursements, cross-border payments, virtual accounts, institutional trading, and fiat-to-stablecoin on-ramps and off-ramps.

Explore the [Coins.ph API documentation](https://docs.coins.ph/rest-api/) or [contact the Coins.ph business team](https://www.coins.ph/en-ph/business) to get started.

<span id="hercle" />

## <span className={`partner-logo partner-logo--hercle ${partnerLogo().className + ' ' + partnerLogoHercle().className}`} aria-hidden="true" />Hercle Transfer

Use [Hercle Transfer](https://www.hercle.com/transfer/) for institutional cross-border payments, fiat-to-stablecoin conversion, and settlement.

[Check supported corridors](https://www.hercle.com/corridor-checker/) · [Discuss an integration](https://www.hercle.com/contact/)

<span id="moonpay" />

## <span className={`partner-logo partner-logo--moonpay ${partnerLogo().className + ' ' + partnerLogoMoonpay().className}`} aria-hidden="true" />MoonPay Ramps

Embed fiat purchases and cash-outs with [MoonPay Ramps](https://www.moonpay.com/business/ramps). Integrate its hosted widget into a web or mobile application.

[On-ramp integration guide](https://dev.moonpay.com/widget/on-ramp/overview) · [Developer documentation](https://dev.moonpay.com/)

<span id="mt-pelerin" />

## <span className={`partner-logo partner-logo--mt-pelerin ${partnerLogo().className + ' ' + partnerLogoMtPelerin().className}`} aria-hidden="true" />Mt Pelerin on- and off-ramps

Embed buy, sell, and swap flows with [Mt Pelerin](https://www.mtpelerin.com/), which lists Tempo among its supported networks. Use its integration guide to configure a hosted flow for the asset and payment method you need.

[Integration guide](https://developers.mtpelerin.com/integration-guides/getting-started) · [Bridge Wallet](/docs/partners/wallets#bridge-wallet)

<span id="rio" />

## <span className={`partner-logo partner-logo--rio ${partnerLogo().className + ' ' + partnerLogoRio().className}`} aria-hidden="true" />Rio Stablecoin FX

Convert between fiat currencies and stablecoins with [Rio Stablecoin FX](https://www.rio.trade/stablecoin-fx). Contact Rio through the product page to confirm currency coverage and integration access.
