# Block explorers: using the Tempo Explorer

Inspect transactions, blocks, accounts, and contracts with an explorer, or use debugging tools to investigate execution.

When implementing payment verification, follow [receiving stablecoin payments](/docs/guide/payments/accept-a-payment#verify-stablecoin-payments). Use [data and analytics providers](/docs/partners/data-and-oracles) when you need programmatic queries or indexed history.

## <span className={`partner-logo partner-logo--tempo-explorer ${partnerLogo().className + ' ' + partnerLogoTempoExplorer().className}`} aria-hidden="true" />Tempo Explorer

Tempo's official Mainnet block explorer is available at [explore.tempo.xyz](https://explore.tempo.xyz). View transactions, blocks, accounts, and token activity on the Tempo network. Testnet block explorer is available at [explore.testnet.tempo.xyz](https://explore.testnet.tempo.xyz). For more connection information, see [Connect to the Network](/docs/quickstart/connection-details).

## <span className={`partner-logo partner-logo--tenderly ${partnerLogo().className + ' ' + partnerLogoTenderly().className}`} aria-hidden="true" />Tenderly

[Tenderly](https://tenderly.co) provides error tracking, EVM tracing, and offchain transaction simulation for Tempo contracts. Use it to analyze reverts and inspect gas usage before sending a transaction.

Enable Tempo in the [Tenderly Dashboard](https://dashboard.tenderly.co/).

Find additional tooling and account libraries in the [developer tools directory](/docs/partners/developer-tools).
