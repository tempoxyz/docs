## Connect providers to your Tempo integration

Use [Accounts](/docs/accounts) for wallet connections, deposits, and payment controls. Follow [network configuration](/docs/quickstart/connection-details) when connecting an RPC provider, and [EVM compatibility](/docs/quickstart/evm-compatibility) when adapting an existing application.

For Tempo’s own clients, CLI, and API reference, use [APIs & SDKs](/docs/tools). Provider support can differ by network, asset, and Tempo transaction feature; check the provider’s integration guide for the capabilities your application uses.

## Try a provider integration

- [Fund an account with OUSD](/docs/guide/ousd): find token addresses and funding paths.
- [Bridge with Bungee](/docs/guide/bridge-bungee): request a deposit quote, execute it, and track delivery.
- [Bridge with Relay](/docs/guide/bridge-relay): discover supported tokens, request a quote, and track the transfer.
- [Bridge with LayerZero](/docs/guide/bridge-layerzero): use Stargate pools or token-specific OFT adapters.

For a provider introduction or a new integration, [contact the Tempo team](/docs/partners/join).
