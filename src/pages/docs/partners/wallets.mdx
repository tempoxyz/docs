# Wallets

Choose how users connect accounts and how signing keys are managed. The providers below cover embedded wallets, custody, external wallets, and agent wallets.

Start with [Accounts](/docs/accounts) for Tempo Wallet and payment workflows. If you are adding Tempo to an existing wallet, use the [wallet integration guide](/docs/quickstart/wallet-developers) alongside your provider's documentation.

Jump to [embedded wallets](#embedded), [custody and institutional providers](#custodial--institutional), [self-custodial wallets](#self-custodial), or [agent wallets](#agentic).

For account abstraction providers and programmable wallet frameworks, see [Smart accounts](/docs/partners/smart-accounts).

## Embedded

### <span className={`partner-logo partner-logo--blockradar ${partnerLogo().className + ' ' + partnerLogoBlockradar().className}`} aria-hidden="true" />Blockradar
[Blockradar](https://blockradar.co) provides non-custodial wallet infrastructure purpose-built for fintechs running stablecoin payments. The platform focuses on real financial use cases, from merchant settlement to cross-border payouts, with tools designed for payments, compliance, treasury operations, and multi-chain liquidity. Explore the full platform in the [Blockradar Docs](https://docs.blockradar.co/).

**Wallet and Payment Operations:** Through one unified API, teams can issue wallets for users, merchants, or treasury; accept fiat inflows through virtual accounts; enable gasless stablecoin transactions; apply AML checks automatically; consolidate balances through configurable sweeps; and handle cross-chain movement using swap and bridge. Fintechs can start building with the Blockradar API or [Blockradar Dashboard](https://dashboard.blockradar.co/). For advanced flows or high-volume programs, fintechs can [book a demo](https://www.blockradar.co/contact) to walk through production architectures.

### <span className={`partner-logo partner-logo--para ${partnerLogo().className + ' ' + partnerLogoPara().className}`} aria-hidden="true" />Para

It provides flexible login methods, secure MPC-backed wallets, fast authentication, and infrastructure for automating onchain activity. Para [supports Tempo](https://blog.getpara.com/tempo-para/) for wallet creation and payment flows.

Get started by signing up through the [Para Dev Portal](https://developer.getpara.com/) and following the quickstart in the [Para docs](https://docs.getpara.com/v2/introduction/welcome).

### <span className={`partner-logo partner-logo--privy ${partnerLogo().className + ' ' + partnerLogoPrivy().className}`} aria-hidden="true" />Privy

[Privy](https://www.privy.io/) builds secure key management and embedded wallets so any developer can easily build secure, scalable wallets into their app. Easily spin up self-custodial wallets for users, manage your treasury wallets and more.

Privy's Tempo integration supports native transaction features such as batched calls and fee-token selection. Privy's standard EVM `sponsor: true` option is not available for Tempo Transactions; follow its [Tempo transaction guide](https://docs.privy.io/wallets/using-wallets/tempo/send-a-transaction) for supported signing and sponsorship paths.

[Create an Ethereum-type wallet](https://docs.privy.io/wallets/wallets/create/create-a-wallet#param-chain-type-1) in Privy. For Tempo mainnet, the CAIP-2 identifier is `eip155:4217`; use the [Tempo-specific transaction instructions](https://docs.privy.io/wallets/using-wallets/tempo/send-a-transaction) when adding batching, memos, or fee-token selection.

:::tip
Check out the [Tempo + Privy guide](https://docs.privy.io/wallets/using-wallets/tempo/send-a-transaction) and Privy's [example](https://github.com/privy-io/examples/tree/main/examples/privy-next-tempo) peer-to-peer payments app that uses Tempo transaction memos.
:::

### <span className={`partner-logo partner-logo--turnkey ${partnerLogo().className + ' ' + partnerLogoTurnkey().className}`} aria-hidden="true" />Turnkey

[Turnkey](https://www.turnkey.com) provides programmable key management and non-custodial wallet infrastructure for applications that need granular signing policies and automated transaction flows. With Turnkey, developers can securely sign Tempo Transactions, automate wallet operations, and build custom logic around how keys are used.

Turnkey also supports sponsor-style workflows, enabling gasless or subsidized transaction flows through configurable signing policies.

[Create your Turnkey account](https://app.turnkey.com/dashboard) and follow the [Turnkey Embedded Wallet Kit guide](https://docs.turnkey.com/sdks/react/getting-started) to integrate embedded wallets into your Tempo app.

:::tip
Turnkey has a [`with-tempo`](https://github.com/tkhq/sdk/tree/main/examples/chain-integrations/with-tempo) example in their SDK to get you started quickly.
:::

## Custodial & Institutional

### <span className={`partner-logo partner-logo--bridge ${partnerLogo().className + ' ' + partnerLogoBridge().className}`} aria-hidden="true" />Bridge Wallets

Create hosted stablecoin wallets, read balances, and transfer funds with Bridge Wallets. Connect them to Bridge Orchestration for bank funding or Bridge Cards for spending.

[Wallet product](https://www.withbridge.com/product/wallets) · [Wallet documentation](https://apidocs.bridge.xyz/get-started/guides/wallets/overview) · [Tempo integration guide](https://apidocs.bridge.xyz/get-started/guides/move-money/tempo-integration-guide)

### <span className={`partner-logo partner-logo--bitgo ${partnerLogo().className + ' ' + partnerLogoBitgo().className}`} aria-hidden="true" />BitGo

[BitGo](https://www.bitgo.com) provides institutional-grade custody, trading, and wallet infrastructure. BitGo supports Tempo with both custodial and self-custody wallet solutions, enabling enterprises to securely store, manage, and transact with Tempo-based assets under robust security and compliance controls. BitGo is a  qualified custodian in the United States and globally [licensed and regulated](https://www.bitgo.com/company/licenses/).

Get started through the [BitGo platform](https://www.bitgo.com) or explore their [developer docs](https://developers.bitgo.com/).

### <span className={`partner-logo partner-logo--coinbase ${partnerLogo().className + ' ' + partnerLogoCoinbase().className}`} aria-hidden="true" />Coinbase

Eligible [Coinbase Prime](https://www.coinbase.com/prime) clients can access custody support for Tempo, with availability varying by asset and contracting entity.

Coinbase also supports Tempo for retail and exchange trading and transfers, including in its iOS and Android apps. For supported assets and regions, customers can select Tempo as the network when sending or receiving. Check the available networks for the specific asset in Coinbase before transferring. See [Coinbase trading and transfers](/docs/partners/exchanges#coinbase) for more context.

## Agentic

### <span className={`partner-logo partner-logo--enact ${partnerLogo().className + ' ' + partnerLogoEnact().className}`} aria-hidden="true" />Enact

[Enact](https://www.enact.finance/) provides programmable wallet infrastructure for teams and AI agents that need granular onchain controls. Set your policy once (spending limits, multisig thresholds, approval windows, automation rules) and let agents execute against it autonomously, with every action verifiable onchain. Enact never holds your funds; it enforces the logic you define.

Get started with the [Enact CLI](https://docs.enact.finance/) or the [Enact app](https://app.enact.finance/) to create a self-custodial passkey wallet, add signers, and deploy your first onchain policy.

### Sponge

[Sponge](https://paysponge.com) provides financial infrastructure for AI agents, enabling them to hold, send, and swap crypto autonomously on Tempo. With Sponge, developers can give their agents wallets with configurable spending controls, allowlists, and audit logging, along with first-class support for Claude and other AI frameworks via MCP and SDK.

Get started on the [Sponge platform](https://paysponge.com) and explore the [Sponge docs](https://paysponge.com/docs).
