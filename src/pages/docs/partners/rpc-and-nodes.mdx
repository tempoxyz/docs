# Node providers

Choose a hosted RPC endpoint or managed node service for your application. Use [network connection details](/docs/quickstart/connection-details) to select the correct network and [JSON-RPC reference](/docs/protocol/rpc) to implement requests.

To operate your own infrastructure, follow [Run a node](/docs/guide/node).

## <span className={`partner-logo partner-logo--alchemy ${partnerLogo().className + ' ' + partnerLogoAlchemy().className}`} aria-hidden="true" />Alchemy

[Alchemy](https://www.alchemy.com/rpc/tempo) provides Tempo mainnet and testnet RPC endpoints for reading chain data and submitting transactions.

Sign up through the [Alchemy dashboard](https://dashboard.alchemy.com/?utm_source=chain_partner&utm_medium=referral&utm_campaign=tempo) and visit the [Alchemy docs](https://www.alchemy.com/docs/node#tldr) to start building.

## <span className={`partner-logo partner-logo--conduit ${partnerLogo().className + ' ' + partnerLogoConduit().className}`} aria-hidden="true" />Conduit

[Conduit](https://conduit.xyz) provides production-grade blockchain infrastructure and developer tooling for teams building on Tempo. Their RPC stack delivers the performance and reliability needed to build financial applications at scale.

Access [Conduit](https://hub.conduit.xyz/tempo-testnet) or read the [Tempo RPC Quickstart](https://docs.conduit.xyz/rpc-nodes/getting-started/tempo-rpc-quickstart) to get started.

## <span className={`partner-logo partner-logo--drpc ${partnerLogo().className + ' ' + partnerLogoDrpc().className}`} aria-hidden="true" />dRPC

[dRPC](https://drpc.org/chainlist/tempo-mainnet-rpc) provides managed Tempo RPC endpoints through NodeCloud, with routing, analytics, and API-key controls. Check dRPC for current plans and pricing.

Get started by visiting the [dRPC chain list](https://drpc.org/chainlist), and learn more about NodeCloud on the [dRPC NodeCloud page](https://drpc.org/nodecloud-multichain-rpc-management).
