# Node providers

Choose a hosted RPC endpoint or managed node service for your application. Use [network connection details](/docs/quickstart/connection-details) to select the correct network and [JSON-RPC reference](/docs/protocol/rpc) to implement requests.

To operate your own infrastructure, follow [Run a node](/docs/guide/node).

## Verify the endpoint's network

Replace `<TEMPO_HTTP_URL>` with your provider's HTTP endpoint. Keep authenticated URLs out of source control and public logs.

```bash [Terminal]
curl --fail --silent --show-error '<TEMPO_HTTP_URL>' \
  -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"eth_chainId","params":[]}'
```

Expect `result: "0x1079"` for mainnet (`4217`) or `result: "0xa5bf"` for Moderato (`42431`). Method support still varies by provider.

## <span className={`partner-logo partner-logo--alchemy ${partnerLogo().className + ' ' + partnerLogoAlchemy().className}`} aria-hidden="true" />Alchemy

[Alchemy](https://www.alchemy.com/rpc/tempo) provides HTTP and WebSocket RPC endpoints for Tempo mainnet and Moderato. Create an app in the [dashboard](https://dashboard.alchemy.com/?utm_source=chain_partner&utm_medium=referral&utm_campaign=tempo), select the network, and follow its [Tempo quickstart](https://www.alchemy.com/docs/reference/tempo-api-quickstart).

Alchemy's indexed APIs, webhooks, and Gas Manager have their own chain support lists. Its native-balance example doesn't return a spendable stablecoin balance; use [TIP-20 balance reads](/docs/guide/payments/accept-a-payment#read-balances).

## <span className={`partner-logo partner-logo--drpc ${partnerLogo().className + ' ' + partnerLogoDrpc().className}`} aria-hidden="true" />dRPC

## <span className={`partner-logo partner-logo--quicknode ${partnerLogo().className + ' ' + partnerLogoQuicknode().className}`} aria-hidden="true" />QuickNode

[QuickNode](https://www.quicknode.com/chains/tempo) provides HTTP and WebSocket Tempo RPC endpoints. Follow the [Tempo quickstart](https://www.quicknode.com/docs/tempo/quickstart), then check the historical, Debug, or Trace methods you need in its [API overview](https://www.quicknode.com/docs/tempo/api-overview). Use HTTP POST for responses that exceed [WebSocket size limits](https://www.quicknode.com/docs/tempo/endpoints).

The API overview lists testnet chain ID `42429`, not current Moderato (`42431`). Run the [network check](#verify-the-endpoints-network) before using a QuickNode testnet endpoint.
