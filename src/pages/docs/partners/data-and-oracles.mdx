# Data

Choose an indexer, analytics platform, or oracle for the data your application needs. The directory covers account activity, historical chain data, market data, and monitoring.

For Tempo's hosted interfaces, start with the [Tempo API](/docs/api) for payment activity or the [Indexer API](/docs/api/indexer-api) for SQL queries. Use [explorers and debugging tools](/docs/partners/explorers-and-debugging) to inspect individual transactions.

For payment ledgers, use [Reconcile payments](/docs/resources/guides/payment-reconciliation) to connect indexed records to your application. It includes Goldsky and Allium setup paths.

## <span className={`partner-logo partner-logo--allium ${partnerLogo().className + ' ' + partnerLogoAllium().className}`} aria-hidden="true" />Allium

[Allium](https://www.allium.so) indexes Tempo chain records and stablecoin transfers for SQL analysis. Use the [Allium reporting workflow](/docs/resources/guides/payment-reconciliation#allium) for saved-query runs, amount precision, and reconciliation reports.

Get access through the [Allium App](https://app.allium.so/join) and read the [Allium docs](https://docs.allium.so/) and [developer overview](https://docs.allium.so/api/developer/overview).

:::tip
Allium has a [ready-to-use recipe](https://github.com/Allium-Science/allium-recipes/tree/main/tempo) for querying Tempo data with SQL.
:::

## <span className={`partner-logo partner-logo--artemis ${partnerLogo().className + ' ' + partnerLogoArtemis().className}`} aria-hidden="true" />Artemis

[Artemis](https://about.artemis.ai/) provides an analytics terminal for onchain activity across stablecoins, assets, and networks, including flows, liquidity, and token performance.

Artemis has an analytics page for [Tempo Testnet](https://app.artemisanalytics.com/asset/tempo_moderato) and a cross-chain [Stablecoins dashboard](https://app.artemisanalytics.com/stablecoins).

## <span className={`partner-logo partner-logo--chainlink ${partnerLogo().className + ' ' + partnerLogoChainlink().className}`} aria-hidden="true" />Chainlink

[Chainlink](https://chain.link) provides oracles, market data, and cross-chain messaging.

Chainlink supports Tempo through:

- **Price Feeds:** Chainlink Price Feeds provide decentralized market data onchain for lending markets, FX, tokenized assets, stablecoins, and risk-management applications. View the live feeds and contract addresses in the [Chainlink Price Feed directory](https://docs.chain.link/data-feeds/price-feeds/addresses?network=tempo).
- **Cross-Chain Interoperability Protocol (CCIP):** Sends messages and tokens across chains.  
See the [Chainlink CCIP docs](https://docs.chain.link/ccip).
- **Data Streams:** Delivers low-latency market data offchain that applications pull on demand and verify onchain.  
See the [Data Streams contract on Tempo](https://explore.tempo.xyz/address/0xcE73c8ad08CBDEaCa6078BF0627C8fe0a9a536E7?tab=contract).

See the [Chainlink Developer Docs](https://docs.chain.link/).

## Chronicle

[Chronicle](https://chroniclelabs.org/) is an oracle provider that started within MakerDAO in 2017. It supports Tempo through:

- **DeFi Price Feeds:** Price oracles for lending, stablecoins, and other onchain financial applications.
- **Proof of Asset:** Cryptographic attestations of reserves, collateral, and asset backing for tokenized assets.

See the [Chronicle Docs](https://docs.chroniclelabs.org/).

## <span className={`partner-logo partner-logo--codex ${partnerLogo().className + ' ' + partnerLogoCodex().className}`} aria-hidden="true" />Codex

[Codex](https://www.codex.io) provides a GraphQL API for token prices, holders, trading pairs, and onchain activity, including Tempo data.

Use the [Codex documentation](https://docs.codex.io), [API explorer](https://docs.codex.io/explore), or [TypeScript SDK](https://github.com/Codex-Data/sdk).

## <span className={`partner-logo partner-logo--coingecko ${partnerLogo().className + ' ' + partnerLogoCoingecko().className}`} aria-hidden="true" />CoinGecko

[CoinGecko](https://www.coingecko.com) provides market data, including prices, trading volume, market capitalization, and token metadata for Tempo tokens.

Get started with the [CoinGecko API](https://docs.coingecko.com/reference/introduction).

## <span className={`partner-logo partner-logo--dune ${partnerLogo().className + ' ' + partnerLogoDune().className}`} aria-hidden="true" />Dune

[Dune](https://dune.com) provides SQL-based blockchain analytics, dashboards, and query APIs. Its [data catalog](https://docs.dune.com/data-catalog/overview) lists the available networks and datasets.

Dune [retired the Sim API on August 1, 2026](https://dune.com/blog/sunsetting-sim). For Tempo payment activity, use the [Tempo API](/docs/api) or choose another provider in this directory.

## <span className={`partner-logo partner-logo--envio ${partnerLogo().className + ' ' + partnerLogoEnvio().className}`} aria-hidden="true" />Envio

[Envio](https://envio.dev) builds custom blockchain APIs and analytics, including on Tempo mainnet (chain ID 4217):

- **[HyperIndex](https://docs.envio.dev/docs/HyperIndex/overview):** Choose the contracts and events to track and write TypeScript handlers that shape the data. HyperIndex handles reorgs and serves the result as a GraphQL API. Run it yourself or deploy to Envio Cloud.
- **[HyperSync](https://docs.envio.dev/docs/HyperSync/overview):** Query logs, transactions and blocks, filtered on the server and returned with only the fields you need, for analytics, backfills and data pipelines.
- **[HyperRPC](https://docs.envio.dev/docs/HyperRPC/overview-hyperrpc):** A read-only JSON-RPC endpoint built on HyperSync for data-heavy reads such as `eth_getLogs`. Existing tools work without code changes.

Start with the [HyperIndex quickstart](https://docs.envio.dev/docs/HyperIndex/quickstart). Tempo endpoints are on the [HyperSync](https://docs.envio.dev/docs/HyperSync/hypersync-supported-networks) and [HyperRPC](https://docs.envio.dev/docs/HyperRPC/hyperrpc-supported-networks) supported networks pages.

## <span className={`partner-logo partner-logo--goldsky ${partnerLogo().className + ' ' + partnerLogoGoldsky().className}`} aria-hidden="true" />Goldsky

[Goldsky](https://goldsky.com/chains/tempo) supports Tempo mainnet and Moderato testnet with subgraph indexing and data pipelines:

- **[Subgraphs](https://docs.goldsky.com/subgraphs/):** Backwards-compatible subgraph indexing that handles reorgs and RPC failures.
- **[Turbo Pipelines](https://goldsky.com/chains/tempo):** Stream chain data to databases or message queues. Turbo Pipelines succeeds Goldsky Mirror.

Start on the [Goldsky Tempo page](https://goldsky.com/chains/tempo).

## <span className={`partner-logo partner-logo--moralis ${partnerLogo().className + ' ' + partnerLogoMoralis().className}`} aria-hidden="true" />Moralis

[Moralis](https://moralis.com) supports Tempo mainnet across its Data API, Streams, Datashare, and Data Feeds:

- **[Data API](https://docs.moralis.com/data-api/supported-chains):** Wallet balances, transaction history, net worth, and profitability; token metadata, transfers, owners, and prices; NFTs by wallet and collection; blocks, transactions, and internal transactions; and labelled entities. DeFi positions and NFT trades, sale prices, and floor prices are currently not available for Tempo.
- **[Streams](https://docs.moralis.com/streams/supported-chains):** Realtime webhooks for wallet, token and NFT activity, contract events, internal transactions, and transaction data, confirmed after 30 blocks.
- **[Data Feeds](https://docs.moralis.com/data-feeds/overview):** Index Tempo into your own infrastructure with no indexing layer to build or run. Backfill from genesis, tail the chain head in realtime, or both, with automatic reorg correction. Covers raw blocks, transactions and event logs, plus decoded token transfers with balances, NFT transfers, swaps, prices, and metadata. Ready-made templates handle wallet transactions, balances, holders, swaps, OHLCV, and NFTs. Data lands in ClickHouse, Postgres, or MySQL, streams through Kafka, RabbitMQ, or SQS, or can be read over REST or Arrow Flight.
- **[Datashare](https://docs.moralis.com/datashare/supported-chains):** Bulk historical exports of Tempo token transfers, NFT transfers, and swaps.

Pass `tempo` or `0x1079` as the Data API `chain` value (or in `chains` on multi-chain endpoints). Streams accepts only the hex chain ID `0x1079`.

Create an API key in the [Moralis dashboard](https://admin.moralis.com) and see the [Tempo release notes](https://docs.moralis.com/changelog#tempo-is-now-supported) for the full feature list.

## <span className={`partner-logo partner-logo--range ${partnerLogo().className + ' ' + partnerLogoRange().className}`} aria-hidden="true" />Range

[Range](https://www.range.org) runs the Stablecoin Explorer, which traces stablecoin flows across 100+ chains, including Tempo. It shows a transfer's full cross-chain lifecycle, bridge routes, verified entities, risk signals, and sanctions-list checks.

Explore Tempo activity in the [Stablecoin Explorer](https://explorer.money/transactions?dn=tempo-testnet&sc=INTRACHAIN&sn=tempo-testnet).

## <span className={`partner-logo partner-logo--redstone ${partnerLogo().className + ' ' + partnerLogoRedstone().className}`} aria-hidden="true" />RedStone

[RedStone](https://redstone.finance) provides push and pull price feeds for lending, FX, and stablecoin applications on Tempo.

See the [Tempo push feeds](https://app.redstone.finance/push-feeds?networks=tempo&testnets=true) and the [RedStone docs](https://docs.redstone.finance/).

## <span className={`partner-logo partner-logo--sonarx ${partnerLogo().className + ' ' + partnerLogoSonarx().className}`} aria-hidden="true" />SonarX

[SonarX](https://www.sonarx.com) provides historical and real-time onchain data with SOC 2-certified controls.

SonarX covers Tempo from genesis, with a Full Historical Stream Dataset and a Real-Time Dataset. Data is available via Snowflake, Databricks, BigQuery, Kafka streams, real-time APIs, or custom file drops.

Request a data trial on the [SonarX platform](https://www.sonarx.com/trial) and explore the [SonarX docs](https://docs.sonarx.com/).

## <span className={`partner-logo partner-logo--sqd ${partnerLogo().className + ' ' + partnerLogoSqd().className}`} aria-hidden="true" />SQD

[SQD](https://sqd.ai) is a decentralized query engine and indexing toolkit. Use the Squid SDK to build custom Tempo indexers served from the SQD Network.

Get started with the [SQD docs](https://docs.sqd.ai/) and deploy indexers via [SQD Cloud](https://app.subsquid.io/).

## <span className={`partner-logo partner-logo--zerion ${partnerLogo().className + ' ' + partnerLogoZerion().className}`} aria-hidden="true" />Zerion

Use [Zerion](https://zerion.io/api) for token balances and transaction history. Its [chain coverage matrix](https://zerion.io/api/chains) lists these products for Tempo, with DeFi and NFT data unavailable. Filter wallet requests with `filter[chain_ids]=tempo`; that API identifier differs from the numeric EVM chain ID.

Create an API key in the [Zerion dashboard](https://dashboard.zerion.io/) and follow its [authentication](https://developers.zerion.io/authentication) and [pagination](https://developers.zerion.io/pagination-and-filtering) instructions.
