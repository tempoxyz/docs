# Smart accounts

Choose a provider for account abstraction or programmable smart wallets when your application needs the provider's account model.

[Tempo Transactions](/docs/guide/tempo-transaction) already provide native batching, fee sponsorship, and access keys. For Tempo-specific transaction and balance handling, use the [wallet integration guide](/docs/quickstart/wallet-developers).

## <span className={`partner-logo partner-logo--pimlico ${partnerLogo().className + ' ' + partnerLogoPimlico().className}`} aria-hidden="true" />Pimlico

[Pimlico](https://www.pimlico.io) provides ERC-4337 bundlers and paymasters. Tempo has no native gas token and charges network fees in stablecoins, so check Pimlico's Tempo EntryPoint and fee handling before reusing a generic EVM paymaster example.

Get started on the [Pimlico dashboard](https://dashboard.pimlico.io/) and explore the [Pimlico docs](https://docs.pimlico.io/).

<span id="safe-coming-soon" />

## <span className={`partner-logo partner-logo--safe ${partnerLogo().className + ' ' + partnerLogoSafe().className}`} aria-hidden="true" />Safe

[Safe](https://safe.global) provides smart contract accounts with multiple owners and signature thresholds. Its transaction service documents support for [Tempo](https://docs.safe.global/core-api/transaction-service-reference/tempo) and [Moderato testnet](https://docs.safe.global/core-api/transaction-service-reference/tempo-moderato).

## <span className={`partner-logo partner-logo--zerodev ${partnerLogo().className + ' ' + partnerLogoZerodev().className}`} aria-hidden="true" />ZeroDev

[ZeroDev](https://zerodev.app) lists Tempo in its [supported chains](https://docs.zerodev.app/api-and-toolings/faqs/chains). Its smart account platform provides account creation, signing, and sponsorship tools.

Create a project in the [ZeroDev dashboard](https://dashboard.zerodev.app) and follow the [SDK quickstart](https://docs.zerodev.app/sdk/getting-started/quickstart) to integrate smart accounts into your Tempo application.
