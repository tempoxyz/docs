Move stablecoins between Tempo and supported networks. Accept deposits from external wallets or make a transfer your application can authorize.

## How Routes works

A route connects a source network and token to a destination network and token. Routes prepares the funding instructions or source-chain calls, then tracks delivery to the recipient. A successful source transaction starts the route; your app confirms completion at the destination.

For payments that stay on Tempo, use [Send payments](/docs/guide/payments/send-a-payment) or [Swap stablecoins](/docs/guide/stablecoin-dex/executing-swaps) instead.

## Build a Routes integration

Each page in this section covers one step. Read them in order:

1. [Try a route](/docs/routes/test) in the browser to see every API call from quote to delivery. Without an API key, the demo quotes listed routes and previews 1:1 delivery where a route supports it.
2. [Set up API access](/docs/routes/api-setup): create a key and request Routes access in Tempo Console.
3. Pick a pair and funding method from [Supported routes](/docs/routes/networks).
4. Read [Quotes and fees](/docs/routes/quotes) to choose the fixed amount and show the payment terms.
5. Build the flow: [Accept deposits](/docs/routes/deposits) or [Make a transfer](/docs/routes/transfers).
6. [Track delivery](/docs/routes/delivery) to completion or refund before you credit a balance.

To run a flow from a terminal, use the [deposit address](/docs/routes/examples/deposits) or [transfer](/docs/routes/examples/transfers) cURL example.

## Use funds after delivery

After funds arrive on Tempo, you can deposit them into [Earn](/docs/earn/integrate) or a [Zone](/docs/zones/deposit). Those are separate operations; direct Routes transfers into vaults or Zones are not implemented.

For bank funding and payouts, see [Payments & ramps](/docs/partners/payments-and-ramps).
