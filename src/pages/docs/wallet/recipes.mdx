# `tempo wallet` recipes

Use these recipes after [signing in to Tempo Wallet](/docs/cli/wallet#sign-in). For the first paid request, follow [Pay with the CLI](/docs/guide/machine-payments/agent).

<span id="tempo-wallet-agent-pattern" />
<span id="tempo-wallet-is-agent-ready-by-design" />

## Let an agent pay for services

Set up your agent with the [prompt on the CLI overview](/docs/cli#set-up-your-agent). It installs two skills in skill-enabled agents such as Claude Code, Amp, and Codex:

| Skill | Description |
| --- | --- |
| `tempo-wallet` | Readiness checks, balances, service discovery, and session and funding actions. |
| `tempo-request` | Paid HTTP requests with payment preview (`--dry-run`) and execution. |

Tempo Wallet uses mainnet for live payments. Check the network and balance before authorizing spending, and set both limits:

- **Per command:** `tempo request --max-spend` caps one command's payment spending.
- **Per account:** access-key limits apply separately to the signing key. See [Set up an agent wallet](/docs/accounts/guides/agent-wallet) for authorization and revocation.

Service discovery returns endpoint metadata, and `--dry-run` reads the current payment terms without paying. Neither replaces handling the service's result or errors. For the commands, see [agent and script mode](/docs/cli/wallet#agent-and-script-mode).

## Find and pay for a service

Search with `tempo wallet services --search <QUERY>` and inspect the chosen service with `tempo wallet services <SERVICE_ID>`. Use its endpoint and schema in [`tempo request`](/docs/cli/request); preview with `--dry-run` and set `--max-spend` when paying.

<span id="tempo-wallet-session-management" />

## Reconcile and close payment sessions

```bash [Terminal]
tempo wallet sessions list
tempo wallet sessions sync
tempo wallet sessions close --dry-run --all
tempo wallet sessions close --orphaned
tempo wallet sessions close --finalize
```

`sync` reconciles local records with onchain state. Inspect the close preview before closing sessions. `--orphaned` targets orphaned onchain channels; `--finalize` completes channels already pending close.

## Recover the wallet connection

Run `tempo wallet whoami` to inspect readiness and balances. If the access key is stale, run `tempo wallet refresh`. If you're signed out, run `tempo wallet login`.

For a request schema error, inspect `tempo wallet services <SERVICE_ID>`. For insufficient funds, [add funds](/docs/cli/wallet#add-funds). Add `-t` for machine-readable output in scripts.
