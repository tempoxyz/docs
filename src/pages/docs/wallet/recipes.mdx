# Tempo Wallet CLI recipes

Use these recipes after [connecting Tempo Wallet](/docs/cli/wallet#authenticate-with-tempo-wallet-cli). For the first paid request, follow [Pay with the CLI](/docs/guide/machine-payments/agent).

## Find and pay for a service

Search with `tempo wallet services --search <query>` and inspect the chosen service with `tempo wallet services <SERVICE_ID>`. Use its endpoint and schema in [`tempo request`](/docs/cli/request); preview with `--dry-run` and set `--max-spend` when paying.

<span id="tempo-wallet-request-execution" />

## Pay a captured challenge with credits

Check that the service supports MPP Credits and that the separate credits balance covers the request. Capture the challenge without paying, then preview and execute the credit payment:

```bash
tempo wallet -t whoami --credits
headers="$(mktemp)"
tempo request -t --dry-run -D "$headers" \
  --json '{"input":"hello"}' <SERVICE_ENDPOINT_URL>
tempo wallet -t transfer --credits --dry-run --mpp-challenge-file "$headers"
tempo wallet -t transfer --credits --mpp-challenge-file "$headers"
```

Replace the URL and payload with the service's request schema. Credits are separate from token balances and apply only to eligible one-time charges.

<span id="tempo-wallet-session-management" />

## Reconcile and close payment sessions

```bash
tempo wallet sessions list
tempo wallet sessions sync
tempo wallet sessions close --dry-run --all
tempo wallet sessions close --orphaned
tempo wallet sessions close --finalize
```

`sync` reconciles local records with onchain state. Inspect the close preview before closing sessions. `--orphaned` targets sessions whose counterparty is unreachable; `--finalize` completes channels already pending close.

## Recover the wallet connection

Use `tempo wallet whoami` to inspect readiness and balances. If the access key is stale, run `tempo wallet refresh`. If authentication is missing, run `tempo wallet login`.

For a request schema error, inspect `tempo wallet services <SERVICE_ID>`. For insufficient funds, use [wallet funding](/docs/cli/wallet#add-wallet-funds). Add `-t` for machine-readable output in scripts.
