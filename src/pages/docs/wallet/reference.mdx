# Tempo Wallet CLI reference

Use the [wallet command reference](/docs/cli/wallet#tempo-wallet-cli-command-reference) for `tempo wallet` and the [request reference](/docs/cli/request) for `tempo request`.

## `tempo wallet`

### Wallet auth commands

[Connect, refresh, or disconnect a wallet](/docs/cli/wallet#wallet-authentication-commands).

### Wallet key commands

[List and revoke access keys](/docs/cli/wallet#wallet-key-commands).

### Wallet funding commands

[Fund the wallet or transfer tokens](/docs/cli/wallet#wallet-funding-commands).

### Wallet service commands

[Find services and inspect request schemas](/docs/cli/wallet#wallet-service-discovery-commands).

### Wallet session commands

[List, reconcile, and close payment sessions](/docs/cli/wallet#wallet-session-commands).

### Agent setup and diagnostics

[Inspect wallet state and shell completion options](/docs/cli/wallet#advanced-wallet-commands).

## `tempo request`

[Make HTTP requests with MPP payment handling](/docs/cli/request). The reference includes payment previews, spend caps, headers, and request bodies.

## Tempo Wallet global flags

Use [agent and script mode](/docs/cli/wallet#agent-and-script-mode) for machine-readable output, or run `tempo wallet --help` and `tempo request --help` for the flags supported by your installed version.

## Tempo Wallet source

Source code is available in [`tempoxyz/wallet-cli`](https://github.com/tempoxyz/wallet-cli).
