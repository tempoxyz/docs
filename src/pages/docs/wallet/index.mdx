# Tempo Wallet CLI

Use Tempo Wallet from a terminal, script, or agent. `tempo wallet` manages the account connection, balances, access keys, and payment sessions. `tempo request` makes paid HTTP requests.

## Install Tempo Wallet CLI

Follow the [CLI installation guide](/docs/cli/wallet#download-the-tempo-wallet-cli) to install the launcher and wallet extension.

## Authenticate with Tempo Wallet CLI

[Connect your wallet](/docs/cli/wallet#authenticate-with-tempo-wallet-cli), then check its network and balance with `tempo wallet whoami`. Tempo Wallet uses mainnet for live payments; use Moderato only for explicitly configured testnet workflows.

## Discover and call a paid API

[Pay with the CLI](/docs/guide/machine-payments/agent) walks through finding a service, inspecting the request schema, previewing the price, and paying for the request.

## Scripting and agents

Use [Tempo Wallet CLI with agents](/docs/wallet/use-with-agents) for agent skills and command output. Use [Give an agent access](/docs/accounts/agents) for the account authorization model.
