# Tempo EVM

Tempo is a blockchain for payments. Tempo EVM is its Ethereum-compatible execution environment: use Solidity contracts, Ethereum JSON-RPC, and familiar tools like Foundry, Viem, and Wagmi to build with stablecoins.

[Send your first test payment →](/get-started/quickstart) · [RPC endpoints and chain IDs →](/docs/quickstart/connection-details)

</DocsProductOverview>

Build wallets, payment applications, and financial services on Tempo EVM. It combines Ethereum’s smart contract model with infrastructure designed for moving money: stablecoin fees, fast finality, and dedicated capacity for eligible payments. Use it to accept customer deposits, send payouts, issue stablecoins, or build your own onchain application.

Accounts, tokens, and transactions come with payment capabilities built in. Give customers passkey-based accounts, cover their fees, and automate payments with limited signing permissions. Issue tokens with configurable controls and exchange stablecoins through shared onchain liquidity. Start with these native capabilities, then use Solidity to add the logic your application needs.

Start with a transfer or contract call, then add the capabilities your application needs. Standard EVM transactions work for basic transfers and calls; use [Tempo Transactions](/docs/guide/tempo-transaction) for features such as batching, fee sponsorship, and access keys.
