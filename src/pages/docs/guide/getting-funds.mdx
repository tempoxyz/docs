# Fund an account

Choose a funding path for the network and integration you are building. Tempo Wallet uses mainnet and real funds; the Moderato faucet supplies separate test tokens.

| You want to | Start with |
| --- | --- |
| Test a payment or integration | [Get testnet funds](#testnet-funds) |
| Try funding an account | [Tempo Wallet](#tempo-wallet) |
| Add cross-network funding to your application | [Tempo Routes](/docs/routes) |
| Integrate a specific bridge provider | [Bridge integrations](#bridge) |

## Tempo Wallet

[Tempo Wallet](https://wallet.tempo.xyz) is Tempo's web-based passkey wallet. You can onramp with fiat or bridge from other chains using the flow below.

### With the CLI

After [setting up Tempo Wallet in the CLI](/docs/cli/wallet), run:

```bash
tempo wallet fund
```

### With an agent

Paste this into your agent to set up Tempo Wallet and add funds:

:::code-group
```bash [Claude Code]
claude -p "Read https://tempo.xyz/SKILL.md and fund my Tempo Wallet"
```
```bash [Amp]
amp --execute "Read https://tempo.xyz/SKILL.md and fund my Tempo Wallet"
```
```bash [Codex CLI]
codex exec "Read https://tempo.xyz/SKILL.md and fund my Tempo Wallet"
```
:::

## Get OUSD

See [OUSD on Tempo](/docs/guide/ousd) for minting, redemption, and swap options. Check the token contract address and network when adding an asset to your application.

## Add funding to your application

Use [Tempo Routes](/docs/routes) to quote a cross-network transfer or create a deposit address for customers who send funds independently. Track destination delivery before crediting the payment in your application.

<span id="bridge" />

## Bridge integrations

If you integrate a bridge directly, follow its quote, submission, and delivery flow:

- [LayerZero (Stargate)](/docs/guide/bridge-layerzero)
- [Bungee](/docs/guide/bridge-bungee)
- [Relay](/docs/guide/bridge-relay)

See [bridge providers](/docs/ecosystem/bridges) for the directory. Check the output asset as well as the network: USDC sent through Stargate arrives on Tempo as USDC.e.

## Testnet funds

For development and testing, use the [Tempo Faucet](/docs/quickstart/faucet).

The faucet provides `OUSD`, `pathUSD`, `alphaUSD`, `betaUSD`, and `thetaUSD` test stablecoins.
