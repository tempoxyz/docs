# Fund an account

Choose a funding path for the network and integration you are building. Tempo Wallet uses mainnet and real funds; the Moderato faucet supplies separate test tokens.

## Add money with Tempo Wallet

[Tempo Wallet](https://wallet.tempo.xyz) takes deposits from other chains, such as Base, Ethereum, and Solana. Connect below, select **Add funds**, and choose a funding method in the wallet. The wallet shows the available methods, amount, and any fees before you confirm.

This demo opens the funding flow on Moderato testnet, where Tempo's funding page offers the faucet first. In your app on mainnet, the same page takes real deposits.

## Open funding with the Accounts SDK

Use the [Accounts SDK](https://accounts.tempo.xyz) to open Tempo's funding page from an **Add funds** button. Tempo handles the funding flow; your application signs the user in and calls `accounts.funding.open`.

:::::steps

### Install the Accounts SDK

```bash
pnpm add accounts@alpha viem
```

### Add a funding button

This React example signs the user in with Tempo and opens funding for their Tempo Account on mainnet:

```tsx [AddFundsButton.tsx]
import { Accounts } from 'accounts'
import { useState } from 'react'

const accounts = Accounts.create()

export function AddFundsButton() {
  const [pending, setPending] = useState(false)
  const [error, setError] = useState<string>()

  // Each click opens one Tempo page, since a second popup has no user gesture left.
  async function addFunds() {
    setPending(true)
    setError(undefined)
    try {
      // The funding page needs a session. Without one, this click signs in, and the next adds funds.
      if (!(await accounts.session.get())) {
        await accounts.dialog.signIn()
        return
      }
      const result = await accounts.funding.open()
      if (result?.status === 'received') {
        // Refresh balances. See "Confirm funds have arrived".
      }
    } catch (cause) {
      setError(cause instanceof Error ? cause.message : 'Could not open funding.')
    } finally {
      setPending(false)
    }
  }

  return (
    <div>
      <button type="button" disabled={pending} onClick={addFunds}>
        {pending ? 'Check Tempo…' : 'Add funds'}
      </button>
      {error && <p role="alert">{error}</p>}
    </div>
  )
}
```

Call `funding.open` from the click handler, since the browser blocks a popup opened outside a user gesture. You can prefill `amount` as a human-readable string, such as `'50'`, and `token` as a supported token symbol, such as `'USDC.e'`. The user reviews and confirms the funding request on Tempo's funding page.

### Confirm funds have arrived

A resolved `funding.open` call doesn't mean the account is funded. Fiat funding can complete asynchronously, after the funding page closes. Refresh [balances and activity](/docs/guide/payments/accept-a-payment#read-balances), and [verify incoming transfers](/docs/guide/payments/accept-a-payment) before crediting funds in your application's records.

## Get OUSD

See [OUSD on Tempo](/docs/guide/ousd) for minting, redemption, and swap options. Check the token contract address and network when adding an asset to your application.

## Add funding to your application

Use [Tempo Routes](/docs/routes) to quote a cross-network transfer or create a deposit address for customers who send funds independently. Track destination delivery before crediting the payment in your application.

## Bridge integrations

If you integrate a bridge directly, follow its quote, submission, and delivery flow:

- [LayerZero (Stargate)](/docs/guide/bridge-layerzero)
- [Bungee](/docs/guide/bridge-bungee)
- [Relay](/docs/guide/bridge-relay)

See [bridge providers](/docs/partners/bridges) for the directory. Check the output asset as well as the network: USDC sent through Stargate arrives on Tempo as USDC.e.

## Testnet funds

For development and testing, use the [Tempo Faucet](/docs/quickstart/faucet).

The faucet provides `OUSD`, `pathUSD`, `alphaUSD`, `betaUSD`, and `thetaUSD` test stablecoins.
