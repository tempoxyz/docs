# Fund an account

Choose a funding path for the network and integration you are building. Tempo Wallet uses mainnet and real funds; the Moderato faucet supplies separate test tokens.

## Add money with Tempo Wallet

[Tempo Wallet](https://wallet.tempo.xyz) includes a fiat onramp and funding from other chains. Connect below, select **Add funds**, and choose a funding method in the wallet. The wallet shows the available methods, amount, and any fees before you confirm.

This demo opens the funding flow for **Tempo Mainnet**, using real funds. For test tokens, use the [Moderato faucet](/docs/quickstart/faucet).

### With the CLI

After [setting up Tempo Wallet in the CLI](/docs/cli/wallet), run:

```bash
tempo wallet fund
```

## Open funding with the Accounts SDK

Use the Accounts SDK to open Tempo Wallet's funding interface from an **Add funds** button. The wallet handles the funding flow; your application connects the account and requests `wallet_deposit`.

:::::steps

### Install the Accounts SDK

```bash
pnpm add --save-exact accounts@0.18.4 viem
```

### Add a funding button

This React example connects Tempo Wallet and opens funding for the selected account on mainnet:

```tsx [AddFundsButton.tsx]
import { Provider } from 'accounts'
import { useState } from 'react'
import { numberToHex } from 'viem'
import { tempo } from 'viem/chains'

const provider = Provider.create({ chains: [tempo] })

export function AddFundsButton() {
  const [pending, setPending] = useState(false)
  const [error, setError] = useState<string>()

  async function addFunds() {
    setPending(true)
    setError(undefined)
    try {
      const [address] = await provider.request({ method: 'eth_requestAccounts' })
      if (!address) throw new Error('Connect a Tempo Wallet account first.')
      await provider.request({
        method: 'wallet_deposit',
        params: [{ address, chainId: numberToHex(tempo.id) }],
      })
    } catch (cause) {
      setError(cause instanceof Error ? cause.message : 'Could not open funding.')
    } finally {
      setPending(false)
    }
  }

  return (
    <div>
      <button type="button" disabled={pending} onClick={addFunds}>
        {pending ? 'Check Tempo Wallet…' : 'Add funds'}
      </button>
      {error && <p role="alert">{error}</p>}
    </div>
  )
}
```

Omit `intent` to let the user choose a funding method. To prefer Apple Pay where available, add `intent: 'applePay'` to the parameter object. `intent: 'crypto'` prefers funding with crypto. These are preferences, not guarantees that a method is available to every user.

You can also prefill `amount` as a human-readable string, such as `'50'`, and `token` as a supported token symbol or contract address. The user reviews and confirms the funding request in the wallet.

### Confirm funds have arrived

A resolved `wallet_deposit` request does not prove the account was funded. Fiat funding can complete asynchronously, and the response's `receipts` field may be absent. Refresh [balances and activity](/docs/accounts/balances), and [verify incoming transfers](/docs/guide/payments/accept-a-payment) before crediting funds in your application's records.

## Get OUSD

See [OUSD on Tempo](/docs/guide/ousd) for minting, redemption, and swap options. Check the token contract address and network when adding an asset to your application.

## Add funding to your application

Use [Tempo Routes](/docs/routes) to quote a cross-network transfer or create a deposit address for customers who send funds independently. Track destination delivery before crediting the payment in your application.

## Bridge integrations

If you integrate a bridge directly, follow its quote, submission, and delivery flow:

- [LayerZero (Stargate)](/docs/guide/bridge-layerzero)
- [Bungee](/docs/guide/bridge-bungee)
- [Relay](/docs/guide/bridge-relay)

See [bridge providers](/docs/partners/bridges) for the directory. Check the output asset as well as the network: USDC sent through Stargate arrives on Tempo as USDC.e.

## Testnet funds

For development and testing, use the [Tempo Faucet](/docs/quickstart/faucet).

The faucet provides `OUSD`, `pathUSD`, `alphaUSD`, `betaUSD`, and `thetaUSD` test stablecoins.
