# Integrate stablecoin payments

Send stablecoins, collect deposits, and confirm payments in your application. If you are still deciding where funds should live and who signs, start with [Choose an account model](/docs/accounts/integration).

<span id="core-payment-flows" />
<span id="build-the-payment-flow" />

## Send and receive payments

| Task | Guide |
| --- | --- |
| Fund an account | [Choose a funding path](/docs/guide/getting-funds). |
| Send stablecoins | [Send payments](/docs/guide/payments/send-a-payment), including references and batches. |
| Collect and reconcile payments | [Receive payments](/docs/guide/payments/accept-a-payment), verify delivery, and record each payment once. |
| Identify customer deposits | [Customer deposit addresses](/docs/guide/payments/virtual-addresses) attribute payments into a shared account. |
| Move funds between networks | [Routes](/docs/routes) connects Tempo with other networks. |

## Configure payment behavior

- [Sponsor fees](/docs/guide/payments/sponsor-user-fees) or [choose a fee token](/docs/guide/payments/pay-fees-in-any-stablecoin).
- [Send independent payments in parallel](/docs/guide/payments/send-parallel-transactions) when each payment needs its own receipt.
- [Configure receive policies](/docs/guide/payments/configure-receive-policies) to choose which tokens and senders an account accepts.
