# Payment references

Attach a 32-byte transfer memo to a [TIP-20 payment](/get-started/stablecoins) to identify an invoice, order, or customer record. Store the reference with your payment record, then match it to confirmed transfer events.

<span id="keep-memos-under-32-bytes" />

## Encode a payment reference

Use a short, opaque ID such as `INV-12345`. Memos are public transaction data; keep customer details in your application.

Use the same encoding when sending a reference and searching for it. This helper encodes a UTF-8 string and pads it on the right with zero bytes to fit the `bytes32` field:

```ts [payment-reference.ts]
import { toHex } from 'viem'

export function encodePaymentReference(reference: string) {
  if (new TextEncoder().encode(reference).length > 32) {
    throw new Error('Payment references must fit in 32 UTF-8 bytes')
  }
  return toHex(reference, { size: 32 })
}
```

The limit is **32 bytes**, not 32 characters. `toHex` throws if the input exceeds the requested size; it does not truncate it. For a longer reference, keep the full value in your database and put a short lookup ID in the memo.

:::code-group

```ts [send-payment.ts]
import { getAddress, parseUnits } from 'viem'
import { encodePaymentReference } from './payment-reference'
import { client } from './viem.config'

const recipient = process.env.TEMPO_RECIPIENT
if (!recipient) throw new Error('Set TEMPO_RECIPIENT')

const { receipt } = await client.token.transferSync({
  token: '0x20c0000000000000000000000000000000000001',
  to: getAddress(recipient),
  amount: parseUnits('10', 6),
  memo: encodePaymentReference('INV-12345'),
})

console.log(receipt.transactionHash)
```

:::

Passing `memo` makes the SDK call `transferWithMemo`. For a browser integration, pass the same value to `Hooks.token.useTransferSync` in your [payment action](/docs/guide/payments/send-a-payment#add-a-payment-action-in-the-browser).

## Find payments by reference

The `TransferWithMemo` event indexes `memo`, so you can query the token contract for a specific reference. Set `TEMPO_RECIPIENT` to your receiving account and `TEMPO_FROM_BLOCK` to the first block in the range you want to inspect.

```ts [find-payment.ts]
import { getAddress } from 'viem'
import { tempoModerato } from 'viem/chains'
import { Abis, createClient } from 'viem/tempo'
import { encodePaymentReference } from './payment-reference'

const recipient = process.env.TEMPO_RECIPIENT
const fromBlock = process.env.TEMPO_FROM_BLOCK
if (!recipient || !fromBlock) {
  throw new Error('Set TEMPO_RECIPIENT and TEMPO_FROM_BLOCK')
}

const client = createClient({ chain: tempoModerato })
const logs = await client.getContractEvents({
  address: '0x20c0000000000000000000000000000000000001',
  abi: Abis.tip20,
  eventName: 'TransferWithMemo',
  args: {
    to: getAddress(recipient),
    memo: encodePaymentReference('INV-12345'),
  },
  fromBlock: BigInt(fromBlock),
  toBlock: 'latest',
})

console.log(logs)
```

A memo match identifies a candidate payment. [Verify the token, recipient, amount, and receipt](/docs/guide/payments/accept-a-payment#reconcile-payments-with-memos) before crediting it. Store the transaction hash and log index so replaying events cannot credit the same transfer twice.

## Choose a reference for your workflow

For customer deposits, assign a short customer ID and ask the sender to include it. If the sender cannot supply a memo, use [customer deposit addresses](/docs/guide/payments/virtual-addresses) instead.

### Payroll batch payments

Encode a distinct payment reference for each call in a [batch payment](/docs/guide/payments/send-a-payment#batch-payment-transactions). Store that reference with the corresponding payroll record so you can reconcile each transfer, even though the batch shares one transaction hash.

<span id="refund-address-in-memo" />

### Link refunds to the original payment

Use an original payment ID or a separate refund ID as the memo. Keep the refund destination in the payment record and verify it before submitting the refund. An Ethereum-style address written as text takes 42 bytes and cannot fit in this 32-byte field.
