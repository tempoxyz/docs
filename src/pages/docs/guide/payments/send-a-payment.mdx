# Send payments

Send stablecoins between Tempo accounts and verify delivery. Use a payment reference when you need to match a transfer to an invoice or order.

The examples use AlphaUSD on Moderato testnet. [Create and fund a test account](/get-started/quickstart), then choose a recipient you control.

For complete files and more languages, see [single transfers](/docs/guide/payments/send-a-payment/examples#send-a-payment), [payment references](/docs/guide/payments/send-a-payment/examples#add-a-payment-reference), or [batches](/docs/guide/payments/send-a-payment/examples#batch-payments).

## Send a payment

Use the [CLI, Viem, and Wagmi setup](/docs/accounts/examples#choose-your-tools) with a funded test account. It defines the signer, `client`, `recipient`, and `alphaUsd`; the Python setup supplies `w3` and `transaction_options()`. All amounts use base units: `10_000_000` is ten AlphaUSD. Wagmi hooks belong inside a React component; call the named handlers from buttons and show their pending and error states.
::::code-group

```ts [Viem]
const { receipt } = await client.token.transferSync({
  token: alphaUsd, to: recipient, amount: 10_000_000n,
})
console.log(receipt.transactionHash)
```

```bash [CLI]
cast erc20 transfer "$ALPHA_USD" "$TEMPO_RECIPIENT" 10000000 \
  --tempo.fee-token "$ALPHA_USD" \
  --rpc-url "$TEMPO_RPC_URL" --private-key "$TEMPO_PRIVATE_KEY"
```

```tsx [Wagmi]
import { Hooks } from 'wagmi/tempo'
const { mutate: transfer, data, isPending, error } = Hooks.token.useTransferSync()
const sendPayment = () => transfer({
  token: alphaUsd, to: recipient, amount: 10_000_000n,
})
```

```python [Python]
tx = TempoTransaction.create(
    **transaction_options(),
    calls=(TIP20(alpha_usd).transfer(to=recipient, amount=10_000_000),),
)
signed_tx = tx.sign(private_key)
tx_hash = w3.eth.send_raw_transaction(signed_tx.encode())
```

```bash [cURL (RPC)]
curl --fail-with-body https://rpc.moderato.tempo.xyz \
  -H "Content-Type: application/json" \
  --data '{"jsonrpc":"2.0","id":1,"method":"eth_sendRawTransaction","params":["'"$SIGNED_TRANSACTION"'"]}'
```

::::

Viem and Wagmi sign and wait for the receipt. Python signs and submits; wait for its receipt below. cURL **only submits an already-signed transaction**: set `SIGNED_TRANSACTION` to the encoded hex bytes from your signer, as shown in [Python setup](/docs/accounts/examples#python-client). The hosted API does not sign a payment for you.

### Add a payment reference

Use a memo to carry an invoice or order identifier. Encode it as a 32-byte value and save the same identifier in your payment record.

::::code-group

```ts [Viem]
const { receipt } = await client.token.transferSync({
  token: alphaUsd, to: recipient, amount: 10_000_000n,
  memo: toHex('invoice-001', { size: 32 }),
})
```

```bash [CLI]
cast send "$ALPHA_USD" 'transferWithMemo(address,uint256,bytes32)' \
  "$TEMPO_RECIPIENT" 10000000 "$(cast format-bytes32-string invoice-001)" \
  --tempo.fee-token "$ALPHA_USD" \
  --rpc-url "$TEMPO_RPC_URL" --private-key "$TEMPO_PRIVATE_KEY"
```

```tsx [Wagmi]
import { Hooks } from 'wagmi/tempo'
import { toHex } from 'viem'
const { mutate: transfer, data, isPending, error } = Hooks.token.useTransferSync()
const sendPayment = () => transfer({
  token: alphaUsd, to: recipient, amount: 10_000_000n,
  memo: toHex('invoice-001', { size: 32 }),
})
```

```python [Python]
memo = b"invoice-001".ljust(32, b"\0")
call = TIP20(alpha_usd).transfer_with_memo(
    to=recipient, amount=10_000_000, memo=memo,
)
tx = TempoTransaction.create(**transaction_options(), calls=(call,))
signed_tx = tx.sign(private_key)
tx_hash = w3.eth.send_raw_transaction(signed_tx.encode())
```

::::

See [Payment references](/docs/guide/payments/transfer-memos) for encoding rules and reconciliation.

## Batch payments

Send several payments as calls in one transaction. If a call reverts, the whole batch reverts. For independent receipts, use [parallel transactions](/docs/guide/payments/send-parallel-transactions).

::::code-group

```ts [Viem]
const calls = [10_000_000n, 20_000_000n].map((amount) =>
  Actions.token.transfer.call({ token: alphaUsd, to: recipient, amount }),
)
const hash = await client.sendTransaction({ calls })
const receipt = await client.waitForTransactionReceipt({ hash })
```

```bash [CLI]
cast batch-send \
  --call "$ALPHA_USD::transfer(address,uint256):$TEMPO_RECIPIENT,10000000" \
  --call "$ALPHA_USD::transfer(address,uint256):$TEMPO_RECIPIENT,20000000" \
  --tempo.fee-token "$ALPHA_USD" \
  --rpc-url "$TEMPO_RPC_URL" --private-key "$TEMPO_PRIVATE_KEY"
```

```tsx [Wagmi]
import { useSendTransactionSync } from 'wagmi'
import { Actions } from 'viem/tempo'
const { mutate: send, data: receipt, isPending, error } = useSendTransactionSync()
const sendBatch = () => send({ calls: [10_000_000n, 20_000_000n].map((amount) =>
  Actions.token.transfer.call({ token: alphaUsd, to: recipient, amount }),
) })
```

```python [Python]
calls = tuple(TIP20(alpha_usd).transfer(to=recipient, amount=amount)
              for amount in (10_000_000, 20_000_000))
tx = TempoTransaction.create(**transaction_options(), calls=calls)
signed_tx = tx.sign(private_key)
tx_hash = w3.eth.send_raw_transaction(signed_tx.encode())
```

::::

Use your own list of recipients and amounts. Confirm every expected transfer in the receipt before marking the batch delivered.

## Pay fees

The Viem and CLI examples select AlphaUSD for transaction fees. Wallet-connected Wagmi requests use the wallet's fee settings. Keep enough of the fee token in addition to the payment amount.

- [Choose a fee token](/docs/guide/payments/pay-fees-in-any-stablecoin) when the sender pays.
- [Sponsor fees](/docs/guide/payments/sponsor-user-fees) when your application pays for its customers.

Choosing a fee token does not convert the payment itself. Use [Routes](/docs/routes) for supported cross-network transfers and [Exchange](/docs/guide/stablecoin-dex) for onchain swaps.

## Confirm delivery

Use the transaction hash as `PAYMENT_TX_HASH` (CLI), `paymentHash` (Wagmi), or `tx_hash` (Python). Viem's synchronous helper already returned `receipt`; the Wagmi transfer exposes `data?.receipt`. Use the API tool below to inspect a transaction by its hash and network.

::::code-group

```ts [Viem]
if (receipt.status !== 'success') throw new Error('Transaction failed')
console.log(receipt.transactionHash)
```

```bash [CLI]
cast receipt "$PAYMENT_TX_HASH" --rpc-url "$TEMPO_RPC_URL"
```

```tsx [Wagmi]
import { useWaitForTransactionReceipt } from 'wagmi'
const { data: receipt, isPending, error } = useWaitForTransactionReceipt({
  hash: paymentHash,
})
const succeeded = receipt?.status === 'success'
```

```python [Python]
receipt = w3.eth.wait_for_transaction_receipt(tx_hash)
if receipt["status"] != 1:
    raise RuntimeError("Transaction failed")
print(receipt["transactionHash"].hex())
```

::::

<OpenApi.Playground operationId="getReceipt" anchors={false} />

Check the transaction status, then match the token contract, recipient, and amount in the receipt's `Transfer` events. A successful transaction alone is not proof that the intended recipient received funds; a receive policy can redirect funds to `ReceivePolicyGuard` instead of the recipient.

Use the [verification example](/docs/guide/payments/accept-a-payment/examples#verify-an-invoice) to connect confirmed transfers to application records. Save the network, transaction hash, and transfer log index so a replay cannot credit the same payment twice.

For a browser integration, show [pending and failed payment states](/docs/guide/payments/send-a-payment/browser#payment-states).
