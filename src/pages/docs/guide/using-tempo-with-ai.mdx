# Build with AI

Give your coding agent access to Tempo documentation. Install the Tempo Docs plugin in Codex or Claude Code, or connect another editor to the MCP server.

<span id="install-tempo-plugins" />

<span id="install-the-tempo-docs-plugin" />

## Connect your coding agent

The Tempo Docs plugin connects your agent to the read-only Tempo MCP server and installs a documentation skill and editor metadata. Tempo publishes plugins from the public [`tempoxyz/plugins`](https://github.com/tempoxyz/plugins) repository.

Run both commands for your client in your computer's terminal:

:::code-group
```bash [Codex]
codex plugin marketplace add tempoxyz/plugins --ref main
codex plugin add docs@tempo
```

```bash [Claude Code]
claude plugin marketplace add tempoxyz/plugins
claude plugin install docs@tempo
```
:::

<details>
<summary>Already using the old Tempo plugin marketplace?</summary>

If you previously installed Tempo plugins from `tempoxyz/docs`, remove the existing `tempo`
marketplace once, then add `tempoxyz/plugins`:

```bash
codex plugin marketplace remove tempo
codex plugin marketplace add tempoxyz/plugins --ref main
codex plugin add docs@tempo
```
</details>

For Cursor, Amp, and other clients, connect to the MCP server below. If your agent supports skills, you can also [install the Docs skill](#docs-skill).

## Start a project

After installation, start a new conversation in your project and give the agent a concrete task. For example:

```text
Use Tempo's docs to build a TypeScript example that sends a stablecoin payment on Moderato testnet with a memo. Include wallet funding and verify delivery to the intended recipient.
```

Use the [testnet faucet](/docs/quickstart/faucet) for test funds and [Quickstart](/get-started/quickstart) to review the implementation.

### Choose a starting page

Ask your agent to read the guide for the integration you are building before writing code:

| Task | Start with |
| --- | --- |
| Choose a product or send a first test payment | [Get Started](/get-started) |
| Create accounts, read balances, send or receive payments | [Accounts](/docs/accounts) |
| Find a vault, deposit, or withdraw | [Earn](/docs/earn) |
| Move funds between Tempo and other networks | [Routes](/docs/routes) |
| Work with private balances, deposits, and withdrawals | [Zones](/docs/zones) |
| Pay for an API or charge for your service | [Machine Payments](/docs/agents) |
| Work with transactions, tokens, contracts, or nodes | [Tempo EVM](/docs/development) |
| Choose a client, CLI, or API reference | [APIs & SDKs](/docs/tools) |
| Find wallet, bridge, data, or infrastructure providers | [Partners](/docs/partners) |

Read each product's overview for its current availability and access requirements. Earn and Routes are in beta; Zones is in limited preview.

The hosted MCP reads published documentation. It cannot see your local edits or preview deployment. For a preview, give your agent that preview's Markdown URL. If MCP results use older page names or omit a section, read `/llms.txt` and `/SKILL.md` from the docs site you are using, then fetch the relevant page directly.

### MCP tools

The MCP endpoint exposes these tools to connected agents:

| Tool | Purpose | Required arguments |
| --- | --- | --- |
| `search` | Search docs. | `query` |
| `find_pages` | Find matching page URLs from a source index. | `source`, `query` |
| `read_page` | Read one cleaned documentation page. | `source` plus `path` or `url` |
| `code` | Run multi-step documentation lookups. | `code` |

#### MCP feedback

MCP clients can also post feedback directly to `https://tempo.xyz/developers/api/feedback`:

```json
{
  "source": "mcp",
  "sentiment": "negative",
  "message": "The read_page result for /docs/guide/payments/send-a-payment is missing fee-token setup.",
  "toolName": "read_page",
  "relatedResource": "/docs/guide/payments/send-a-payment",
  "client": "codex"
}
```

### Add paid tools

Mercator adds paid API discovery and execution to your agent. Follow the [Mercator guide](/docs/guide/mercator) to authorize your client and verify the connection after installation:

```bash
curl -fsSL https://mercator.sh/install.sh | sh
```

To install the plugin directly from the Tempo marketplace, add the public `tempoxyz/plugins` source and select `mercator@tempo`:

:::code-group
```bash [Codex]
codex plugin marketplace add tempoxyz/plugins --ref main
codex plugin add mercator@tempo
```

```bash [Claude]
claude plugin marketplace add tempoxyz/plugins
claude plugin install mercator@tempo --scope user --yes
```
:::

### Use skills and Markdown

#### Docs skill

Install the Tempo Docs skill to give AI coding agents access to Tempo documentation, related documentation sources, and examples:

```bash
npx skills add tempoxyz/plugins --skill docs
```

Ask your agent to use the Docs skill for Tempo integration tasks. The [published docs skill](https://tempo.xyz/developers/SKILL.md) contains the current documentation map; the plugin bundles a copy that is updated separately.

#### Read docs as Markdown

Append `.md` to a documentation page URL to read its Markdown:

```text
https://tempo.xyz/developers/get-started.md
```

For broader context, use the [`llms.txt`](https://llmstxt.org/) files at the documentation root:

| URL | Contents |
| --- | --- |
| [`/llms.txt`](https://tempo.xyz/developers/llms.txt) | Concise index of all pages with titles and descriptions |
| [`/llms-full.txt`](https://tempo.xyz/developers/llms-full.txt) | Complete documentation in a single file |
