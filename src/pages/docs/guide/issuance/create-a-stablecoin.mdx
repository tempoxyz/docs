# How to create a TIP-20 stablecoin

Create a stablecoin using [TIP-20 Tokens](/docs/protocol/tip20/overview). Set its name and symbol, and choose the administrator that manages its roles and supply. The examples use Moderato testnet.

## Create a token from your backend

Use the [funded test account and Viem client](/docs/guide/payments/send-a-payment#send-from-your-backend) from the payment guide. The connected account becomes the token administrator.

```ts [create-token.ts]
import { client } from './viem.config'

const { token, receipt } = await client.token.createSync({
  name: 'Demo USD',
  symbol: 'DEMO',
  currency: 'USD',
})

console.log({ token, transactionHash: receipt.transactionHash })
```

Creation deploys the token; follow [Mint stablecoins](/docs/guide/issuance/mint-stablecoins) to grant the issuer role and mint supply. The browser walkthrough below implements the same creation operation with Wagmi.

### Add stablecoin deployment logic

Now that we have some input fields, we need to add some logic to handle the submission of the form to create the stablecoin.

After this step, your users will be able to create a stablecoin by clicking the "Create" button!

Tokens can also carry an optional on-chain [`logoURI`](/docs/protocol/tip20/spec#logo-uri) that wallets and explorers read directly from the token contract. It's set on the token contract and is independent of this creation flow; for the recommended format, use a square, rasterized PNG or WebP. The URI string, not the image, is limited to 256 bytes and must use the `https`, `http`, `ipfs`, or `data` scheme.

:::warning
The `currency` field is **immutable** after token creation and affects fee payment eligibility, DEX routing, and quote token pairing. See [Currency Declaration](/docs/protocol/tip20/overview#currency-declaration) for guidelines on choosing the right value. **Only `USD` stablecoins can be used to pay transaction fees on Tempo.**
:::

            name, // [!code ++]
            symbol, // [!code ++]
            currency: 'USD', // [!code ++]
          }) // [!code ++]
        }}
      >
        <input type="text" name="name" placeholder="demoUSD" required />
        <input type="text" name="symbol" placeholder="DEMO" required />

          Create
        </button>

}

### Add stablecoin creation success state

Now that users can submit the form and create a stablecoin, let's add a basic success state to display 
the name of the stablecoin and a link to the transaction receipt.

:::code-group

```tsx twoslash [CreateStablecoin.tsx]
import { Hooks } from 'wagmi/tempo' 

// @noErrors
export function CreateStablecoin() {
  const create = Hooks.token.useCreateSync() 

  return (
    <div>
      <form
        onSubmit={(event) => {
          event.preventDefault()
          const formData = new FormData(event.target as HTMLFormElement)
          const name = formData.get('name') as string
          const symbol = formData.get('symbol') as string
          create.mutate({ 
            name, 
            symbol, 
            currency: 'USD', 
          }) 
        }}
      >
        <input type="text" name="name" placeholder="demoUSD" required />
        <input type="text" name="symbol" placeholder="DEMO" required />
        <button type="submit" disabled={create.isPending}>
          {create.isPending ? 'Creating…' : 'Create'}
        </button>
      </form>

      {create.error && <p role="alert">{create.error.message}</p>}
      {create.data && ( // [!code ++]
        <div> {/* [!code ++] */}
          {create.data.name} created successfully! {/* [!code ++] */}
          <a href={`https://explore.testnet.tempo.xyz/tx/${create.data.receipt.transactionHash}`}> {/* [!code ++] */}
            View receipt {/* [!code ++] */}
          </a> {/* [!code ++] */}
        </div> {/* [!code ++] */}
      )} {/* [!code ++] */}
    </div>
  )
}
```

## Stablecoin creation best practices

### Stablecoin creation loading state

Disable the form's submit button while `create.isPending` is true. The complete form above uses the same `useCreateSync` mutation for submission and pending state.

### Stablecoin creation error handling

Display `create.error.message` beside the form when creation fails. Keep the form available so the user can correct the inputs and retry.
