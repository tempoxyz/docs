# Use Tempo Transactions

Use Tempo Transactions to submit payments and contract calls with the signing method, fee payer, and permissions your application needs. The examples below show each capability through Tempo SDKs.

For a complete payment flow, start with [Send a payment](/docs/guide/payments/send-a-payment). For transaction encoding and validation rules, see the [transaction specification](/docs/protocol/transactions/spec-tempo-transaction).

<span id="integration-guides" />

## Choose an SDK

| Language or tool | Integration guide |

| Go | [tempo-go](/docs/sdk/go) |
| Python | [pytempo](/docs/sdk/python) |
| Solidity | [Foundry](/docs/sdk/foundry) |

## Choose a transaction capability

| Your application needs to | Use |
| --- | --- |
| Select the stablecoin used for fees | [Fee tokens](#configurable-fee-tokens) |
| Pay a customer's transaction fees | [Fee sponsorship](#fee-sponsorship) |
| Execute several calls atomically | [Batch calls](#batch-calls) |
| Delegate signing with defined permissions | [Access keys](#access-keys) |
| Submit separate transactions concurrently | [Concurrent transactions](#concurrent-transactions) |
| Avoid managing sequential nonces | [Expiring nonces](#expiring-nonces) |
| Maintain separate ordered transaction streams | [2D nonces](#2d-nonces) |
| Bound when a transaction may be included | [Validity windows](#validity-windows) |
