# Pay with the CLI

Use `tempo request` to call a paid API from a terminal, script, or agent. The CLI handles the MPP challenge and payment retry.

<span id="install-the-tempo-cli" />
<span id="log-in-to-tempo-wallet" />

First [install the CLI and connect Tempo Wallet](/docs/cli/wallet#download-the-tempo-wallet-cli). Confirm the wallet's network and balance with `tempo wallet whoami`; paid requests use real funds unless the service and wallet are explicitly configured for testnet.

:::::steps

<span id="discover-mpp-services" />

### Find a service

Search by task, then inspect a service's endpoint, HTTP method, and request schema:

```bash
tempo wallet services --search image
tempo wallet services <SERVICE_ID>
```

<span id="preview-the-mpp-request-cost" />

### Preview the request cost

The following example uses an image-generation endpoint. Check the service details for current models, schemas, and availability before running it.

```bash
tempo request --dry-run -X POST \
  --json '{"prompt":"a sunset over the ocean"}' \
  https://fal.mpp.tempo.xyz/fal-ai/flux/dev
```

`--dry-run` requests the payment terms without paying.

<span id="make-an-mpp-paid-request" />

### Pay for the request

After reviewing the price, run the request:

```bash
tempo request -X POST \
  --json '{"prompt":"a sunset over the ocean"}' \
  https://fal.mpp.tempo.xyz/fal-ai/flux/dev
```

Use [`--max-spend`](/docs/cli/request#tempo-request-flags) to cap payment spending for the command. Check the service response for the result or job ID.
