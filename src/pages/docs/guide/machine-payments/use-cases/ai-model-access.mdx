# Pay for model inference

Send a model request to an MPP endpoint and pay for the requested inference. Choose the model and pricing from the service’s current catalog.

Set up [Tempo Wallet CLI](/docs/cli/wallet) before running the example. These are paid service requests; check the wallet network and balance before proceeding.

<span id="ai-model-services-you-can-pay-for" />

## Find an inference service

Use the current directory to inspect endpoints, schemas, and availability:

```bash
tempo wallet services --search inference
tempo wallet services <SERVICE_ID>
```

<span id="try-paid-ai-model-access-with-tempo" />

## Preview the example request

Use the service details to confirm the example URL and payload. Preview its payment terms:

```bash
tempo request --dry-run https://openai.mpp.tempo.xyz/v1/chat/completions \
  --json '{"model": "gpt-4o", "messages": [{"role": "user", "content": "Hello"}]}'
```

After reviewing the price, run the command without `--dry-run` to make the paid request. Add [`--max-spend`](/docs/cli/request#tempo-request-flags) to cap spending.

## Read the model response

Check the response for generated content, usage, and any finish or error status. For metered or streaming inference, use a [payment session](/docs/guide/machine-payments/pay-as-you-go) supported by the endpoint; the price and supported models depend on the service.

For application code, use [Pay for services](/docs/guide/machine-payments/client). For discovery through MCP or the catalog API, use [Find services](/docs/guide/machine-payments/discover-services).
