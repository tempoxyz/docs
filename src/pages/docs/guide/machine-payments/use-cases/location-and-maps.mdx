# Look up location data

Pay an MPP endpoint to look up an address. This example submits a geocoding request.

Set up [Tempo Wallet CLI](/docs/cli/wallet) before running the example. These are paid service requests; check the wallet network and balance before proceeding.

<span id="location-data-services-you-can-pay-for" />

## Find a geocoding service

Use the current directory to inspect endpoints, schemas, and availability:

```bash
tempo wallet services --search geocoding
tempo wallet services <SERVICE_ID>
```

<span id="try-google-maps-with-tempo-payments" />

## Preview the example request

Use the service details to confirm the example URL and payload. Preview its payment terms:

```bash
tempo request --dry-run https://googlemaps.mpp.tempo.xyz/maps/api/geocode/json \
  --json '{"address": "1600 Amphitheatre Parkway, Mountain View, CA"}'
```

After reviewing the price, run the command without `--dry-run` to make the paid request. Add [`--max-spend`](/docs/cli/request#tempo-request-flags) to cap spending.

## Choose the matching location

Handle multiple matches and no-match results before using coordinates in your application. Keep the returned address and location together so you can identify which result was selected.

For application code, use [Pay for services](/docs/guide/machine-payments/client). For discovery through MCP or the catalog API, use [Find services](/docs/guide/machine-payments/discover-services).
