# Stablecoin DEX

Swap stablecoins on Tempo through the onchain orderbook. Request a quote, set an output limit, and submit the swap in your application.

[Quote tokens](/docs/protocol/exchange/quote-tokens) explain how trading pairs connect through pathUSD. [DEX balances](/docs/protocol/exchange/exchange-balance) describe funds held in the exchange separately from an account's token balance.
