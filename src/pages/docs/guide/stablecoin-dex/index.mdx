# Stablecoin DEX

Swap stablecoins on Tempo through the onchain orderbook, or provide liquidity by placing orders. Use [Routes](/docs/routes) when you need to move funds between networks.

:::info[Interactive walkthrough]
Try the [swap walkthrough](/docs/guide/stablecoin-dex/executing-swaps) with a test wallet, then build the swap form in your application.
:::

<span id="swap-or-provide-liquidity" />

## Swap stablecoins

Choose the input and output tokens, request a quote, and set the minimum output your application accepts. This example swaps one AlphaUSD for BetaUSD, two test stablecoins on Moderato testnet. The pair needs available liquidity.

The example reuses the clients and values from [Network examples](/docs/network/examples). Viem imports `client`, `alphaUsd`, and `betaUsd` from `network.config.ts`. The CLI uses the `DEX`, `TOKEN` (AlphaUSD), `BETA_TOKEN`, and `RPC_URL` shell variables. Python imports from `network_config.py`.

:::::steps

### Get a quote

Ask the DEX how much BetaUSD one AlphaUSD buys. The amounts are integers in base units, and these stablecoins have six decimals, so `1000000` is one AlphaUSD. `quoteSwapExactAmountIn` takes the input token, output token, and input amount.

::::code-group

```ts [Viem]
// [!include ~/snippets/network-exchange.ts:quote]
```

```bash [CLI]
QUOTE=$(cast call "$DEX" \
  'quoteSwapExactAmountIn(address,address,uint128)(uint128)' \
  "$TOKEN" "$BETA_TOKEN" 1000000 --rpc-url "$RPC_URL" --json | jq -r '.[0]')
```

```ts [Wagmi]
// [!include ~/snippets/network-wagmi.ts:quote]
```

```python [Python]
from network_config import ALPHA_USD, BETA_USD, dex

quote = dex.functions.quoteSwapExactAmountIn(
    ALPHA_USD, BETA_USD, 1_000_000
).call()
```

::::

<span id="approve-the-input-token" />

The DEX needs no separate `approve` before the swap. [Implicit approval](/docs/protocol/tip20/spec#implicit-approvals-for-listed-precompiles) lets listed protocol contracts, including the DEX, pull [TIP-20 tokens](/docs/protocol/tip20/overview), Tempo's stablecoin standard, from the caller. The pull still checks the balance, the token's [transfer policy](/docs/protocol/tip403/overview), and any [access key](/docs/development/account-keychain) spending limit.

### Submit the swap

Set `minAmountOut` to the lowest output you accept. It's `min_amount_out` in Python and the fourth argument in the CLI. This example accepts at most 0.5% less than the quote. A quote doesn't reserve liquidity, so the DEX reverts the swap if it can't meet `minAmountOut`.

The CLI pays the network fee in AlphaUSD with `--tempo.fee-token`, and `--interactive` prompts for the signing key. The Python script continues from the quote step.

::::code-group

```ts [Viem]
// [!include ~/snippets/network-exchange.ts:swap]
```

```bash [CLI]
MIN_OUT=$((QUOTE * 995 / 1000))
cast send "$DEX" 'swapExactAmountIn(address,address,uint128,uint128)' \
  "$TOKEN" "$BETA_TOKEN" 1000000 "$MIN_OUT" \
  --rpc-url "$RPC_URL" --tempo.fee-token "$TOKEN" --interactive
```

```ts [Wagmi]
// [!include ~/snippets/network-wagmi.ts:swap]
```

```python [Python]
from pytempo.contracts import StablecoinDEX
from network_config import make_transaction, submit

call = StablecoinDEX.swap_exact_amount_in(
    token_in=ALPHA_USD, token_out=BETA_USD,
    amount_in=1_000_000, min_amount_out=quote * 995 // 1000,
)
receipt = submit(make_transaction((call,)))
print(receipt["transactionHash"].hex())
```

::::

:::::

For direct HTTP submission, [sign locally and broadcast through JSON-RPC](/docs/network/transactions#sign-and-submit). Each stablecoin on the DEX pairs against one [quote token](/docs/protocol/exchange/quote-tokens), another stablecoin it chooses. That gives one path between any two stablecoins.

## Provide liquidity

Place a limit order, a buy or sell order that waits on the orderbook until someone trades at your price. A flip order is a limit order that switches between buying and selling each time it fills, so it keeps providing liquidity. The [liquidity guide](/docs/guide/stablecoin-dex/providing-liquidity) covers order funding, placement, querying, and cancellation with a working demo.

The [Fee AMM](/docs/protocol/fees/fee-amm) is a separate protocol pool, not part of the DEX. It converts the stablecoin a user pays network fees in into the token the validator prefers. Use [Provide fee liquidity](/docs/guide/stablecoin-dex/managing-fee-liquidity) to supply it.

## Account and exchange balances

The DEX records its own balance for each account and token, separate from the tokens at the account's address. Order fills credit proceeds to this DEX balance. Swaps and orders spend it before pulling any shortfall from the account. Read [DEX balances](/docs/protocol/exchange/exchange-balance) before showing available funds or reconciling orders. The [DEX specification](/docs/protocol/exchange/spec) defines order, swap, and settlement behavior.
