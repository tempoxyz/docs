# Send Within a Zone

Send `OUSD` test tokens between accounts in Zone A without leaving the Zone.

## Overview

A Zone transfer moves `OUSD` test tokens between accounts in **Zone A**. It uses the [testnet sandbox](/docs/guide/private-zones#testnet-compatibility), which differs from current deployments. The sandbox supports direct token transfers inside the Zone, so funds don't pass through Tempo.

## Code Example

This snippet assumes a signed-in `rootClient` on Tempo and a derived `zoneAClient`. It uses the sandbox's TIP-20 token interface.

This code covers the core Zone transfer call. Use the demo to watch the Zone balance update.

```ts
import { parseUnits, type Address } from 'viem'

const transferAmount = parseUnits('25', 6)
const demoRecipient = '0xbeefcafe54750903ac1c8909323af7beb21ea2cb' as Address

await zoneAClient.zone.signAuthorizationToken({ zoneId: 6 })

const { receipt } = await zoneAClient.token.transferSync({
  account: rootClient.account,
  amount: transferAmount,
  feeToken: ousd,
  to: demoRecipient,
  token: ousd,
})
```

## Transfer Settlement

The transfer stays inside Zone A. It doesn't create a deposit or withdrawal on Tempo, so it leaves no public bridge record. Each account reads its updated balance through its own authenticated Zone RPC connection.
