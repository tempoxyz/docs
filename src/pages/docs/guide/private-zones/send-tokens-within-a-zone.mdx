## Code example

This snippet assumes you already have a signed-in `rootClient` on the public chain and a derived `zoneAClient`.

This example uses the earlier testnet deployment's TIP-20 token interface. The current initial permissioned Zone runtime disables direct `transfer`, `transferFrom`, and memo variants; this code does not apply to that runtime. See the [testnet compatibility notes](/docs/guide/private-zones#testnet-compatibility).

It shows the core zone transfer path; use the demo above when you want to watch the updated zone balance.

```ts
import { parseUnits, type Address } from 'viem'

const transferAmount = parseUnits('25', 6)
const demoRecipient = '0xbeefcafe54750903ac1c8909323af7beb21ea2cb' as Address

await zoneAClient.zone.signAuthorizationToken()

const { receipt } = await zoneAClient.token.transferSync({
  account: rootClient.account,
  amount: transferAmount,
  feeToken: ousd,
  to: demoRecipient,
  token: ousd,
})
```
