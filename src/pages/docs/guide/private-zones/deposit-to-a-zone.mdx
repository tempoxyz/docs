# Deposit OUSD

Move `OUSD` test tokens from public Tempo into a private balance on Zone A.

## Overview

This guide deposits `OUSD` test tokens from public Tempo into **Zone A**. It uses the [testnet sandbox](/docs/guide/private-zones#testnet-compatibility), which differs from current deployments. You submit a deposit on Tempo, then wait for the Zone to credit the net amount after fees.

<ZoneDiagram
  name="deposit"
  alt="A public account signs a plaintext or encrypted deposit, the Zone A portal locks OUSD, and Zone A later imports the deposit and credits the private balance."
/>

The portal (`ZonePortal`) on Tempo accepts the deposit. Reading the resulting balance needs an [authorization token](/docs/zones/connect#authorize-access), which scopes Zone RPC reads to your account.

## Code Examples

These snippets assume a signed-in `rootClient` on Tempo and the usual token and Zone constants in scope.

Use the plaintext flow when revealing the recipient and memo is acceptable. Use the encrypted flow to hide those fields from public observers on Tempo.

<Tabs stateKey="zone-deposit-mode">
  <Tab title="Plaintext">

```ts
import { parseUnits } from 'viem'

const depositAmount = parseUnits('100', 6)

const { receipt } = await rootClient.zone.depositSync({
  account: rootClient.account,
  amount: depositAmount,
  token: ousd,
  zoneId: ZONE_A.id,
})

console.log(receipt.blockNumber)
```

  </Tab>
  <Tab title="Encrypted">

```ts
import { parseUnits } from 'viem'

const depositAmount = parseUnits('100', 6)

const { receipt } = await rootClient.zone.encryptedDepositSync({ // [!code focus]
  account: rootClient.account,
  amount: depositAmount,
  token: ousd,
  zoneId: ZONE_A.id,
})

console.log(receipt.blockNumber)
```

## Deposit Settlement

A deposit settles in two phases. The Tempo receipt confirms that the portal accepted the deposit. The Zone balance changes later, when the Zone sequencer [imports the deposit](/docs/protocol/zones/bridging#deposits).

The Zone mints `amount - depositFee`, not the full amount you passed to `deposit(...)`. The portal deducts the [deposit fee](/docs/protocol/zones/execution#deposit-fees) in the deposited token. To land a specific net amount in the Zone, add the deposit fee first.
