Let an agent or application pay for services, or accept payments for your own API. The Machine Payments Protocol (MPP) includes payment in the service request.

## Accept payments for an API

Start with the [server quickstart](/docs/guide/machine-payments/server), then choose how your service charges:

- **[Per request](/docs/guide/machine-payments/one-time-payments):** collect a one-time payment for an API call or resource.
- **[By usage](/docs/guide/machine-payments/pay-as-you-go):** use a payment session for metered service usage.
- **[While streaming](/docs/guide/machine-payments/streamed-payments):** collect payments as a streaming response is delivered.
