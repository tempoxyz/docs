## Build with the Machine Payments Protocol

[MPP](https://mpp.dev) lets clients pay for services as part of a request. Use the [Tempo MPP guide](/docs/guide/machine-payments) to understand the payment flow, then choose the integration you need:

- [Client quickstart](/docs/guide/machine-payments/client) — handle payment requests in your application.
- [One-time payments](/docs/guide/machine-payments/one-time-payments) — charge for an individual request.
- [Pay-as-you-go payments](/docs/guide/machine-payments/pay-as-you-go) — charge for metered usage through a session.
- [Discover MPP services](/docs/guide/machine-payments/discover-services) — find APIs through the service directory and MCP server.
