## How Tempo differs from Ethereum

- **Fees use stablecoins.** There is no native gas token. Choose a supported USD-denominated TIP-20 token or [sponsor the fee](/docs/network/fees).
- **Transactions support payment workflows.** Use [atomic batches, access keys, and independent nonces](/docs/guide/tempo-transaction) through Tempo SDKs.
- **Tokens have payment features.** [TIP-20 Tokens](/docs/network/tokens) support transfer memos, issuance roles, and transfer policies.
- **Execution has some differences.** Review [EVM differences](/docs/quickstart/evm-compatibility) before porting a wallet or contract, especially native-balance checks and gas estimates.

For exact behavior, read the [protocol specifications](/docs/protocol). Track changes in [network upgrades](/docs/protocol/upgrades), or inspect Tempo's [source code](https://github.com/tempoxyz/tempo).
