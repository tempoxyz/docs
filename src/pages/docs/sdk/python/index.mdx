# Tempo Python SDK: installing and using it

Tempo distributes a Python SDK as a [web3.py](https://web3py.readthedocs.io/) extension. The SDK adds native support for Tempo Transactions, including call batching, fee sponsorship, and access key management.

The Tempo Python SDK can be used to perform common operations with the chain, such as: sending Tempo Transactions, batching multiple calls, fee sponsorship, and more.

::::steps

## Install the Python SDK

To install the Tempo Python SDK:

```bash [pip]
python -m pip install pytempo==0.7.0
```

:::tip
The SDK requires Python 3.10 or higher and web3.py 7.0+.
:::

## Create a Python client

To interact with Tempo, create a web3.py client connected to a Tempo node:

```python [main.py]
from web3 import Web3

w3 = Web3(Web3.HTTPProvider("https://rpc.moderato.tempo.xyz")) # [!code hl]

block_number = w3.eth.block_number
print(f"Connected to Tempo at block {block_number}")
```

## Send a Tempo transaction with Python

These examples use Moderato testnet (`42431`). The script below sends 1 AlphaUSD, a TIP-20 test stablecoin, to a newly generated address. It funds the sender from the testnet [faucet](/docs/quickstart/faucet) first, so any new key works. Create a test key and set `PRIVATE_KEY`:

```bash [Terminal]
export PRIVATE_KEY=$(python -c "from eth_account import Account; print(Account.create().key.to_0x_hex())")
```

Estimate gas for every transaction instead of hard-coding a limit. A new account's first transaction pays to create the account, and a transfer to a new address pays to create its balance, so a first transfer needs more than 500,000 gas. See [state creation costs](/docs/quickstart/evm-compatibility#state-creation-costs).

Build and send a transaction using the `TempoTransaction` class:

```python [main.py]
import os
from eth_account import Account
from web3 import Web3
from pytempo import TempoTransaction # [!code hl]
from pytempo.contracts import ALPHA_USD, TIP20

w3 = Web3(Web3.HTTPProvider("https://rpc.moderato.tempo.xyz"))
private_key = os.environ["PRIVATE_KEY"]
account = Account.from_key(private_key)
recipient = Account.create().address  # replace with your recipient's address

# Testnet only: fund the sender with test stablecoins from the faucet.
funding = w3.provider.make_request("tempo_fundAddress", [account.address])
for funding_tx in funding.get("result", []):
    w3.eth.wait_for_transaction_receipt(funding_tx)

transfer = TIP20(ALPHA_USD).transfer(to=recipient, amount=1_000_000)  # 1 AlphaUSD

# Estimate gas for the calls the transaction makes.
draft = TempoTransaction.create(calls=(transfer,))
gas_limit = w3.eth.estimate_gas(draft.to_estimate_gas_request(account.address)) # [!code hl]

# [!code hl:8]
tx = TempoTransaction.create(
    chain_id=w3.eth.chain_id,
    gas_limit=gas_limit,
    max_fee_per_gas=w3.eth.gas_price * 2,
    max_priority_fee_per_gas=w3.eth.gas_price,
    nonce=w3.eth.get_transaction_count(account.address),
    calls=(transfer,),
)

signed_tx = tx.sign(private_key) # [!code hl]
tx_hash = w3.eth.send_raw_transaction(signed_tx.encode()) # [!code hl]
receipt = w3.eth.wait_for_transaction_receipt(tx_hash)
balance = TIP20(ALPHA_USD).balance_of(w3, account=recipient)
print(f"Transaction hash: {tx_hash.to_0x_hex()} (status {receipt.status})")
print(f"Recipient balance: {balance / 10**6} AlphaUSD")
```

## Python SDK examples

These examples reuse `w3`, `account`, `private_key`, and `recipient` from `main.py`, and estimate gas the same way.

### Send a token transfer with Python

Send a TIP-20 token transfer using pytempo's typed contract helpers:

```python [transfer.py]
from pytempo import TempoTransaction
from pytempo.contracts import TIP20, ALPHA_USD

transfer = TIP20(ALPHA_USD).transfer( # [!code hl]
    to=recipient, # [!code hl]
    amount=100_000_000, # 100 tokens (6 decimals) # [!code hl]
) # [!code hl]
draft = TempoTransaction.create(calls=(transfer,))

tx = TempoTransaction.create(
    chain_id=42431,
    gas_limit=w3.eth.estimate_gas(draft.to_estimate_gas_request(account.address)),
    max_fee_per_gas=w3.eth.gas_price * 2,
    max_priority_fee_per_gas=w3.eth.gas_price,
    nonce=w3.eth.get_transaction_count(account.address),
    calls=(transfer,),
)
```

### Pay fees in a stablecoin with Python

Choose a supported USD-denominated TIP-20 token for transaction fees. Tempo has no native gas token:

```python [fee_token.py]
from pytempo import TempoTransaction, Call
from pytempo.contracts import ALPHA_USD

call = Call.create(to=recipient)
draft = TempoTransaction.create(calls=(call,))

tx = TempoTransaction.create(
    chain_id=42431,
    gas_limit=w3.eth.estimate_gas(draft.to_estimate_gas_request(account.address)),
    max_fee_per_gas=w3.eth.gas_price * 2,
    max_priority_fee_per_gas=w3.eth.gas_price,
    nonce=w3.eth.get_transaction_count(account.address),
    fee_token=ALPHA_USD, # [!code hl]
    calls=(call,),
)
```

### Batch multiple calls with Python

Execute multiple operations atomically in a single transaction. `to_estimate_gas_request` covers only the first call, so estimate a batch with every call in the request:

```python [batch.py]
from eth_account import Account
from web3 import Web3
from pytempo import TempoTransaction
from pytempo.contracts import TIP20, ALPHA_USD

token = TIP20(ALPHA_USD)
calls = (
    token.transfer(to=recipient, amount=100_000_000), # [!code hl]
    token.transfer(to=Account.create().address, amount=50_000_000), # [!code hl]
    token.transfer(to=Account.create().address, amount=25_000_000), # [!code hl]
)

gas_limit = w3.eth.estimate_gas({
    "from": account.address,
    "calls": [
        {"to": Web3.to_checksum_address(bytes(c.to)), "data": "0x" + c.data.hex(), "value": hex(c.value)}
        for c in calls
    ],
})

tx = TempoTransaction.create(
    chain_id=42431,
    gas_limit=gas_limit,
    max_fee_per_gas=w3.eth.gas_price * 2,
    max_priority_fee_per_gas=w3.eth.gas_price,
    nonce=w3.eth.get_transaction_count(account.address),
    calls=calls,
)

signed_tx = tx.sign(private_key)
tx_hash = w3.eth.send_raw_transaction(signed_tx.encode())
```

### Parallel Transactions (2D Nonces)

Send multiple transactions concurrently using different nonce keys:

```python [parallel.py]
from pytempo import TempoTransaction
from pytempo.contracts import TIP20, ALPHA_USD

call1 = TIP20(ALPHA_USD).transfer(to=recipient, amount=1_000_000)
call2 = TIP20(ALPHA_USD).transfer(to=recipient, amount=2_000_000)

# The first transaction on a new nonce key pays to create it: include the key.
def estimate_gas(call, nonce_key):
    request = TempoTransaction.create(calls=(call,)).to_estimate_gas_request(account.address)
    return w3.eth.estimate_gas({**request, "nonceKey": hex(nonce_key)})

tx1 = TempoTransaction.create(
    chain_id=42431,
    gas_limit=estimate_gas(call1, nonce_key=1),
    max_fee_per_gas=w3.eth.gas_price * 2,
    max_priority_fee_per_gas=w3.eth.gas_price,
    nonce_key=1, # Sequence A // [!code hl]
    nonce=0,
    calls=(call1,),
)

tx2 = TempoTransaction.create(
    chain_id=42431,
    gas_limit=estimate_gas(call2, nonce_key=2),
    max_fee_per_gas=w3.eth.gas_price * 2,
    max_priority_fee_per_gas=w3.eth.gas_price,
    nonce_key=2, # Sequence B (parallel) // [!code hl]
    nonce=0,
    calls=(call2,),
)

# Submit independent nonce sequences; each has its own result
signed_tx1 = tx1.sign(private_key)
signed_tx2 = tx2.sign(private_key)
w3.eth.send_raw_transaction(signed_tx1.encode())
w3.eth.send_raw_transaction(signed_tx2.encode())
```

### Fee sponsorship with Python

Have another account pay for transaction fees:

```python [fee_payer.py]
from eth_account import Account
from pytempo import TempoTransaction, Call

# A user with no stablecoins signs; the account from main.py pays the fees.
user = Account.create()
call = Call.create(to=recipient)
draft = TempoTransaction.create(calls=(call,))

tx = TempoTransaction.create(
    chain_id=42431,
    gas_limit=w3.eth.estimate_gas(draft.to_estimate_gas_request(user.address)),
    max_fee_per_gas=w3.eth.gas_price * 2,
    max_priority_fee_per_gas=w3.eth.gas_price,
    nonce=w3.eth.get_transaction_count(user.address),
    awaiting_fee_payer=True, # [!code hl]
    calls=(call,),
)

signed_by_user = tx.sign(user.key.to_0x_hex())
final_tx = signed_by_user.sign(private_key, for_fee_payer=True) # [!code hl]
w3.eth.send_raw_transaction(final_tx.encode())
```

### Transaction validity windows in Python

Set a time window during which the transaction is valid:

```python [validity.py]
import time
from pytempo import TempoTransaction, Call

now = int(time.time())
call = Call.create(to=recipient)
draft = TempoTransaction.create(calls=(call,))

tx = TempoTransaction.create(
    chain_id=42431,
    gas_limit=w3.eth.estimate_gas(draft.to_estimate_gas_request(account.address)),
    max_fee_per_gas=w3.eth.gas_price * 2,
    max_priority_fee_per_gas=w3.eth.gas_price,
    nonce=w3.eth.get_transaction_count(account.address),
    valid_after=now, # [!code hl]
    valid_before=now + 3600, # 1 hour from now // [!code hl]
    calls=(call,),
)
```

## Account Keychain in the Python SDK

`expiry=None` maps to the maximum uint64 timestamp for a non-expiring key. Passing `0` expires the key immediately and is rejected by authorization. The call builders below return unsigned calls: choose one, include it in a transaction, sign, submit, and wait for its receipt.

The `AccountKeychain` class provides typed helpers for Tempo's [Account Keychain precompile](/docs/protocol/transactions/AccountKeychain), enabling access key management directly from Python.

:::info
Enhanced access key features — periodic spending limits and call scoping — require the [T3 network upgrade](/docs/protocol/upgrades/t3).
:::

```python [keychain.py]
from pytempo import (
    TempoTransaction, Call,
    KeyRestrictions, SignatureType, TokenLimit, CallScope,
)
from pytempo.contracts import AccountKeychain, ALPHA_USD
from web3 import Web3

w3 = Web3(Web3.HTTPProvider("https://rpc.moderato.tempo.xyz"))

# Authorize a new access key (secp256k1, no expiry):
call = AccountKeychain.authorize_key(
    key_id="<ACCESS_KEY_ADDRESS>",
    signature_type=SignatureType.SECP256K1,
    restrictions=KeyRestrictions(expiry=None),
)
draft = TempoTransaction.create(calls=(call,))
tx = TempoTransaction.create(
    chain_id=w3.eth.chain_id,
    gas_limit=w3.eth.estimate_gas(draft.to_estimate_gas_request(account.address)),
    max_fee_per_gas=w3.eth.gas_price * 2,
    max_priority_fee_per_gas=w3.eth.gas_price,
    nonce=w3.eth.get_transaction_count(account.address),
    calls=(call,),
)

# Authorize with a spending limit:
call = AccountKeychain.authorize_key(
    key_id="<ACCESS_KEY_ADDRESS>",
    signature_type=SignatureType.SECP256K1,
    restrictions=KeyRestrictions(
        expiry=None,
        limits=[TokenLimit(token=ALPHA_USD, limit=1_000_000)],
    ),
)

# Authorize with call scopes (restrict to specific contracts/functions):
call = AccountKeychain.authorize_key(
    key_id="<ACCESS_KEY_ADDRESS>",
    signature_type=SignatureType.SECP256K1,
    restrictions=KeyRestrictions(
        expiry=None,
        allowed_calls=[
            CallScope.transfer(target=ALPHA_USD),
            CallScope.approve(target=ALPHA_USD),
        ],
    ),
)

# Full example: 24h expiry + spending limit + call scope:
import time
expiry = int(time.time()) + 86400
call = AccountKeychain.authorize_key(
    key_id="<ACCESS_KEY_ADDRESS>",
    signature_type=SignatureType.SECP256K1,
    restrictions=KeyRestrictions(
        expiry=expiry,
        limits=[TokenLimit(token=ALPHA_USD, limit=1_000_000)],
        allowed_calls=[CallScope.transfer(target=ALPHA_USD)],
    ),
)

# Revoke an access key (permanent, cannot be re-authorized):
call = AccountKeychain.revoke_key(key_id="<ACCESS_KEY_ADDRESS>")

# Update spending limit for a key-token pair:
call = AccountKeychain.update_spending_limit(
    key_id="<ACCESS_KEY_ADDRESS>",
    token=str(ALPHA_USD),
    new_limit=2_000_000,
)

# Replace all call scopes for a key:
call = AccountKeychain.set_allowed_calls(
    key_id="<ACCESS_KEY_ADDRESS>",
    scopes=[
        CallScope.transfer(target=ALPHA_USD),
        CallScope.unrestricted(target="<CONTRACT_ADDRESS>"),
    ],
)

# Remove a target contract from allowed call list:
call = AccountKeychain.remove_allowed_calls(
    key_id="<ACCESS_KEY_ADDRESS>",
    target="<TARGET_ADDRESS>",
)

# Query key info (read-only):
key_info = AccountKeychain.get_key(
    w3,
    account_address="<ACCOUNT_ADDRESS>",
    key_id="<ACCESS_KEY_ADDRESS>",
)
print(key_info)
# {'signature_type': 0, 'key_id': '0x...', 'expiry': 1893456000, ...}

# Query remaining spending limit and when the current period ends:
remaining = AccountKeychain.get_remaining_limit_with_period(
    w3,
    account_address="<ACCOUNT_ADDRESS>",
    key_id="<ACCESS_KEY_ADDRESS>",
    token_address=str(ALPHA_USD),
)
print(f"Remaining: {remaining['remaining']}, period ends: {remaining['period_end']}")
```

### Sign with an access key in Python

Use `sign_access_key` to sign a transaction as an access key holder:

```python [access_key_sign.py]
from pytempo import TempoTransaction, Call

call = Call.create(to="<CONTRACT_ADDRESS>")
draft = TempoTransaction.create(calls=(call,))
gas_request = draft.to_estimate_gas_request( # [!code hl]
    "<ROOT_ACCOUNT_ADDRESS>", key_id="<ACCESS_KEY_ADDRESS>", # [!code hl]
) # [!code hl]

tx = TempoTransaction.create(
    chain_id=w3.eth.chain_id,
    gas_limit=w3.eth.estimate_gas(gas_request),
    max_fee_per_gas=w3.eth.gas_price * 2,
    max_priority_fee_per_gas=w3.eth.gas_price,
    nonce=w3.eth.get_transaction_count("<ROOT_ACCOUNT_ADDRESS>"),
    calls=(call,),
)

signed_tx = tx.sign_access_key( # [!code hl]
    access_key_private_key="<ACCESS_KEY_PRIVATE_KEY>", # [!code hl]
    root_account="<ROOT_ACCOUNT_ADDRESS>", # [!code hl]
) # [!code hl]
tx_hash = w3.eth.send_raw_transaction(signed_tx.encode())
```
