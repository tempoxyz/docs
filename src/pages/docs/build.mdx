# Stablecoins

Start with the [quickstart](/get-started/quickstart) to send a test payment. Use [Accounts](/docs/accounts) to build payment flows, or [Tempo EVM](/docs/development) for interactive walkthroughs and chain integration.

<span id="core-build-paths" />

## Build with stablecoins

- [Accounts](/docs/accounts) covers sending, receiving, and reconciling payments.
- [Routes](/docs/routes) covers moving funds between Tempo and other networks.
- [Stablecoin exchange](/docs/guide/stablecoin-dex) covers swaps and liquidity on Tempo.
- [Issue stablecoins](/docs/guide/issuance) covers token creation, supply, and permissions for issuers.

<span id="production-essentials" />

## Add payment controls

Use [Send payments](/docs/guide/payments/send-a-payment) to choose fee sponsorship, a fee token, batch payments, or receive policies. For reconciliation, choose [payment references](/docs/guide/payments/transfer-memos) or [customer deposit addresses](/docs/guide/payments/virtual-addresses).

## Connect and fund your application

Follow [Fund an account](/docs/guide/getting-funds) for funding options. Use [APIs & SDKs](/docs/tools) for clients and references, or [Partners](/docs/partners) for integration partners.
