# Stablecoins

Start with [Stablecoins on Tempo](/get-started/stablecoins) to understand TIP-20 Tokens, then use [Accounts](/docs/accounts) and [Payments](/docs/payments) to build your integration.

<span id="core-build-paths" />

## Build with stablecoins

- [Payments](/docs/payments) covers sending, receiving, and reconciling payments.
- [Routes](/docs/routes) covers moving funds between Tempo and other networks.
- [Stablecoin exchange](/docs/guide/stablecoin-dex) covers swaps and liquidity on Tempo.
- [Issue stablecoins](/docs/guide/issuance) covers token creation, supply, and permissions for issuers.

<span id="production-essentials" />

## Add payment controls

Use the [Payments overview](/docs/payments#choose-how-payments-are-submitted) to choose fee sponsorship, a fee token, batch payments, or receive policies. For reconciliation, choose [payment references](/docs/guide/payments/transfer-memos) or [customer deposit addresses](/docs/guide/payments/virtual-addresses).

## Connect and fund your application

Follow [Fund an account](/docs/guide/getting-funds) for funding options. Use [Developer Resources](/docs/development) for SDKs, network configuration, API references, and integration partners.
