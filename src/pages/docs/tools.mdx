# APIs and SDKs

[Developer Resources](/docs/development) is the starting point for Tempo SDKs, APIs, development tools, and integration partners.

## Build with SDKs

Use [Tempo SDKs](/docs/sdk) for application code, the [Tempo CLI](/docs/cli) for terminal commands, and the [Tempo API](/docs/api) for hosted services and indexed data. For paid HTTP requests, start with [Pay with the CLI](/docs/guide/machine-payments/agent).
