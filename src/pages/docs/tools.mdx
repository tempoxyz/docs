## CLI

The [Tempo CLI](/docs/cli) supports wallet operations, paid HTTP requests, and node operations. Choose the command for your task:

- [Wallet CLI](/docs/cli/wallet): fund an account, read balances, and manage access.
- [`tempo request`](/docs/cli/request): make HTTP requests with MPP payments.
- [`tempo node`](/docs/cli/node): run and sync a node.

For contract deployment and debugging, use [Foundry's `forge` and `cast`](/docs/sdk/foundry).

Use [Tempo Console](https://console.tempo.xyz/) to manage API access or [Tempo Wallet](https://wallet.tempo.xyz/) to connect an account. [MPP](https://mpp.dev/) documents the payment protocol; [Mercator](https://mercator.sh/) helps agents find paid services.
