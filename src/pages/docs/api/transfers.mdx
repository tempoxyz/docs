# Read token transfers

Read the token movements produced by Tempo transactions. A transfer record identifies the token, sender, recipient, and amount, and links to its transaction through `transactionHash`.

Choose an endpoint below for request and response fields. The [transaction and transfer model](/docs/api/transactions-and-transfers) explains how the records relate.

To create a payment, follow [Send a payment](/docs/guide/payments/send-a-payment). To reconcile incoming payments, follow [Receive a payment](/docs/guide/payments/accept-a-payment).
