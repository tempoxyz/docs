# Routes API

Move stablecoins between Tempo and other networks from your backend. Quote a route, create a transfer or a deposit address, and track it until the funds are delivered.

:::warning
Routes is in beta. [Contact Tempo](https://tempo.com/contact) to discuss access and the routes your application needs.
:::

## Choose a flow

| Flow | Use when | Endpoints |
| --- | --- | --- |
| [Transfer](/docs/routes/transfers) | Your user's wallet signs the source transaction. | `GET /v1/routes/transfers/quote`, `POST /v1/routes/transfers`, `GET /v1/routes/transfers/{id}` |
| [Deposit address](/docs/routes/deposits) | The sender pays from any wallet or exchange. | `GET /v1/routes/deposit-addresses/quote`, `POST /v2/routes/deposit-addresses`, `GET /v1/routes/deposits` |

Create requests require an `idempotency-key` header. [Set up Routes](/docs/routes/api-setup) walks through your first quote and create call.

## Authentication

Send an API key in the `tempo-api-key` header from your backend. See [Authentication](/docs/api/authentication) for the other supported credentials.

| Scope | Allows |
| --- | --- |
| `routes:read` | Quotes, and transfer and deposit status reads |
| `routes:write` | Creating transfers and deposit addresses, and registering source transactions |
| `data:read` | Reading the route directory with your key, which applies your organization's access policy |

`routes:write` requires approval for your organization. Request access from Routes in [Tempo Console](https://tempo.com/console).
