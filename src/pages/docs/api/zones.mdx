# Zones

Use the hosted Tempo API to read deposit outcomes by queue hash and parent-chain withdrawal outcomes by sender tag. These REST endpoints require an API key with `data:read` and matching Zone read or write access. They're separate from the [account-authenticated zone RPC](/docs/protocol/zones/rpc).

:::info
For the current Zone runtime, `senderTag` includes a per-withdrawal `fallbackNonce`, so withdrawals in one transaction can have different tags; older runtimes may share a tag. Use the tag emitted for your withdrawal.

`zoneStatus: completed` means the portal’s accepted Tempo checkpoint has reached the withdrawal’s parent-chain block. It doesn't confirm refund delivery, and execution-proof verification depends on the [active verifier](/docs/protocol/zones/proving).

`POST /v1/routes/transfers/zone` isn't implemented and returns HTTP `501`.
:::
