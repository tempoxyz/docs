# `tempo request`

A curl-compatible HTTP client that handles [Machine Payments Protocol](https://mpp.dev/overview) negotiation transparently. When a server responds with [`402 Payment Required`](https://mpp.dev/protocol/http-402), `tempo request` reads the [challenge](https://mpp.dev/protocol/challenges), authorizes payment using the configured method, then retries with the [credential](https://mpp.dev/protocol/credentials) in one command.

For the wallet-backed flow, run [`tempo wallet login`](/docs/cli/wallet#sign-in) first. A `--dry-run` preview can read payment terms without logging in. Use [`tempo wallet services`](/docs/cli/wallet#discover-services) before calling paid endpoints so agents and scripts use registered URLs, methods, pricing, and request schemas instead of guessing.

<span id="tempo-request-usage" />

## Usage

```bash [Terminal]
tempo request [FLAGS] <URL>
```

```bash [Terminal]
tempo request --dry-run <URL>
tempo request --max-spend <AMOUNT> <URL>
tempo request -X POST --json '<BODY>' <URL>
tempo request -H '<HEADER>: <VALUE>' <URL>
```

<span id="tempo-request-examples" />

## Examples

Preview the cost before paying:

```bash [Terminal]
tempo request --dry-run -X POST \
  --json '{"prompt":"a sunset over the ocean"}' \
  https://fal.mpp.tempo.xyz/fal-ai/flux/dev
```

Make the paid request:

```bash [Terminal]
tempo request -X POST \
  --json '{"prompt":"a sunset over the ocean"}' \
  https://fal.mpp.tempo.xyz/fal-ai/flux/dev
```

Capture headers for an agent-controlled MPP Credits flow:

```bash [Terminal]
headers="$(mktemp)"
tempo request -t --dry-run -D "$headers" -X POST \
  --json '{"input":"hello"}' \
  <SERVICE_URL>/<ENDPOINT_PATH>
```

Find the right URL and request schema first with [`tempo wallet services`](/docs/cli/wallet#discover-services).

<span id="tempo-request-flags" />

## Flags

| Flag | Description |
| --- | --- |
| `-X <METHOD>` | HTTP method, such as `GET` or `POST`. |
| `--json <BODY>` | Send a JSON body. Implies `-X POST`. |
| `-H <HEADER>` | Add a custom header. |
| `--dry-run` | Request payment terms without paying. |
| `--max-spend <AMOUNT>` | Set a hard cap on cumulative payment spend. |
| `-D, --dump-header <FILE>` | Write response headers to a file, useful for inspecting MPP challenges. |
| `-t, --toon-output` | Print compact, machine-readable output for scripts and agents. |
