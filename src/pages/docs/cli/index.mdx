# Tempo CLI

The `tempo` binary works with the Tempo API, Tempo Wallet, paid HTTP requests, and Tempo nodes from your terminal.

<span id="install-the-tempo-cli" />

## Install

```bash [Terminal]
curl -fsSL https://tempo.xyz/install | bash
```

The launcher installs each command's extension the first time you run it. Run `tempoup` to update, and `tempo --version` to check the installed version.

<span id="tempo-cli-commands" />

## Commands

| Command | Use it for |
| --- | --- |
| [`tempo api`](/docs/cli/api) | Signing in to the Tempo API, creating API keys, and calling any endpoint. |
| [`tempo wallet`](/docs/cli/wallet) | Using Tempo Wallet: balances, funding, access keys, service discovery, and payment sessions. |
| [`tempo request`](/docs/cli/request) | Making HTTP requests that pay automatically with [MPP](https://mpp.dev/overview). |
| [`tempo download`](/docs/cli/download) | Downloading chain snapshots for a faster initial node sync. |
| [`tempo node`](/docs/cli/node) | Running a Tempo RPC or validator node. |

## Set up your agent

Paste this into your AI agent to set up Tempo Wallet CLI and start making paid requests:

:::code-group
```bash [Claude Code]
claude -p "Read https://tempo.xyz/SKILL.md and set up tempo"
```
```bash [Amp]
amp --execute "Read https://tempo.xyz/SKILL.md and set up tempo"
```
```bash [Codex CLI]
codex exec "Read https://tempo.xyz/SKILL.md and set up tempo"
```
:::

See [Let an agent pay for services](/docs/wallet/recipes#let-an-agent-pay-for-services) for the installed skills and spending limits.

## Common flags

Run any command with `--help` to see its flags. Wallet and request extensions also provide `--schema` for JSON command schemas and `--format toon` for compact output. Preview paid requests with `--dry-run` and cap them with `--max-spend`; these payment flags do not apply to node commands.
