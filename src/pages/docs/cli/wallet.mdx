# `tempo wallet`

`tempo wallet` is the command-line way to use [Tempo Wallet](https://wallet.tempo.xyz) from scripts, terminals, and AI agents. Use it to sign in, manage balances and access keys, discover [MPP](https://mpp.dev/overview) services, fund token or credit balances, and manage payment sessions. Use [`tempo request`](/docs/cli/request) when you want the CLI to make the paid HTTP call.

<span id="download-the-tempo-wallet-cli" />

[Install the Tempo CLI](/docs/cli#install) first. The launcher installs the wallet and request extensions the first time you run them.

## Usage

```bash [Terminal]
tempo wallet <COMMAND> [FLAGS]
```

<span id="authenticate-with-tempo-wallet-cli" />

## Sign in

```bash [Terminal]
tempo wallet login
tempo wallet whoami
```

`login` opens a browser flow to connect your [Tempo Wallet](https://wallet.tempo.xyz). If you don't have one, the flow creates it. When `whoami` reports `ready=true`, the wallet is configured for [`tempo request`](/docs/cli/request). Check the balance and preview the request to confirm it can cover the payment.

- On a remote host where the browser is on another device, run `tempo wallet login --no-browser`.
- Run `tempo wallet refresh` to refresh a stale access key without signing out.
- Run `tempo wallet logout --yes` to disconnect.

## Balances and credits

```bash [Terminal]
tempo wallet whoami
tempo wallet whoami --credits
```

`whoami` shows your address, token balances, key state, and optional MPP Credits balance. Credits are separate from token balances and only apply to eligible one-time MPP charges.

<span id="manage-access-keys" />

## Access keys

```bash [Terminal]
tempo wallet keys
tempo wallet revoke <ACCESS_KEY_ADDRESS> --dry-run
tempo wallet revoke <ACCESS_KEY_ADDRESS>
```

Each wallet can have multiple access keys with independent spending limits. Use access-key limits to constrain account spending, and revoke keys that are no longer needed. These keys authorize transactions; they are separate from [Tempo API keys](/docs/api/authentication).

<span id="add-wallet-funds" />

## Add funds

```bash [Terminal]
tempo wallet fund
tempo wallet fund --credits
tempo wallet fund --crypto
```

On testnet, the default flow opens the faucet. On mainnet, it opens available funding options. `--crypto` opens direct crypto funding. `--credits` opens MPP Credits purchase for eligible one-time services.

Transfer tokens to another address:

```bash [Terminal]
tempo wallet transfer <AMOUNT> <TOKEN> <TO_ADDRESS> --dry-run
tempo wallet transfer <AMOUNT> <TOKEN> <TO_ADDRESS>
```

Check the network and balance with `tempo wallet whoami` before funding. For more options, see [Fund an account](/docs/guide/getting-funds).

## Discover services

```bash [Terminal]
tempo wallet services
tempo wallet services --search <QUERY>
tempo wallet services <SERVICE_ID>
```

The [Machine Payments Protocol](https://mpp.dev/overview) (MPP) lets HTTP endpoints accept payments inline. The service directory indexes MPP-registered providers. Each entry shows endpoint URLs, HTTP methods, pricing, whether credits are supported, and request schemas. Use it to find the exact URL and payload for [`tempo request`](/docs/cli/request).

Agents that support MCP can also use the read-only services MCP server at `https://mpp.dev/mcp/services`. See [Find services](/docs/guide/machine-payments/discover-services) for MCP setup, JSON-RPC examples, and the public catalog API.

<span id="manage-payment-sessions" />

## Payment sessions

When you use [pay-as-you-go](/docs/guide/machine-payments/pay-as-you-go) services, MPP opens a [session](https://mpp.dev/payment-methods/tempo/session): a payment channel where your wallet deposits funds into a reserve contract, then pays per request with signed [vouchers](https://mpp.dev/protocol/credentials). Vouchers are exchanged offchain; opening, funding, settling, and closing a channel are onchain operations.

`tempo wallet` tracks session state locally:

```bash [Terminal]
tempo wallet sessions list
tempo wallet sessions sync
tempo wallet sessions close --all
tempo wallet sessions close --orphaned
tempo wallet sessions close --finalize
```

`sync` reconciles local records with onchain state. `close --orphaned` targets orphaned onchain channels. `close --finalize` finalizes channels already pending close. Add `--dry-run` to any close command to preview it first.

## Agent and script mode

Add `-t` for compact, machine-readable [TOON](https://toonformat.dev/) output. Preview paid requests with `--dry-run` and cap them with `--max-spend`:

```bash [Terminal]
tempo wallet -t whoami
tempo wallet -t services --search <QUERY>
tempo wallet -t services <SERVICE_ID>
tempo request -t --dry-run -X POST --json '{"input":"hello"}' <SERVICE_URL>/<ENDPOINT_PATH>
tempo request -t --max-spend 1.00 -X POST --json '{"input":"hello"}' <SERVICE_URL>/<ENDPOINT_PATH>
```

If a service supports MPP Credits, capture the challenge first, then pay with credits:

```bash [Terminal]
headers="$(mktemp)"
tempo request -t --dry-run -D "$headers" -X POST --json '{"input":"hello"}' <SERVICE_URL>/<ENDPOINT_PATH>
tempo wallet -t transfer --credits --dry-run --mpp-challenge-file "$headers"
tempo wallet -t transfer --credits --mpp-challenge-file "$headers"
```

See [Recipes](/docs/wallet/recipes) for complete flows, including agent setup.

## Commands

| Command | Description |
| --- | --- |
| `tempo wallet login` | Connect or create a wallet through browser sign-in. |
| `tempo wallet logout` | Disconnect and clear local credentials. |
| `tempo wallet refresh` | Refresh the current access key. |
| `tempo wallet whoami` | Print readiness, address, balances, and key state. |
| `tempo wallet keys` | List access keys and their spending limits. |
| `tempo wallet revoke <ACCESS_KEY_ADDRESS>` | Revoke an access key. |
| `tempo wallet fund` | Fund the wallet: the faucet on testnet, funding options on mainnet. |
| `tempo wallet transfer <AMOUNT> <TOKEN> <TO_ADDRESS>` | Transfer tokens to another address. |
| `tempo wallet services [<SERVICE_ID>]` | List registered services, or show one service's endpoints, methods, and request schemas. |
| `tempo wallet sessions list` | List active payment sessions. |
| `tempo wallet sessions sync` | Reconcile local sessions with onchain state. |
| `tempo wallet sessions close` | Close payment sessions. |
| `tempo wallet debug` | Collect debug info for support. |
| `tempo wallet completions <SHELL>` | Generate shell completions. |

## Flags

### All commands

| Flag | Description |
| --- | --- |
| `-t` | Print compact, machine-readable [TOON](https://toonformat.dev/) output. |
| `--help` | Show the command's flags. |

### `tempo wallet login`

| Flag | Description |
| --- | --- |
| `--no-browser` | Print the sign-in URL instead of opening a browser, for remote hosts. |

### `tempo wallet logout`

| Flag | Description |
| --- | --- |
| `--yes` | Skip the confirmation prompt. |

### `tempo wallet whoami`

| Flag | Description |
| --- | --- |
| `--credits` | Include the MPP Credits balance. |

### `tempo wallet revoke`

| Flag | Description |
| --- | --- |
| `--dry-run` | Preview the revocation without submitting it. |

### `tempo wallet fund`

| Flag | Description |
| --- | --- |
| `--crypto` | Open direct crypto funding. |
| `--credits` | Buy MPP Credits for eligible one-time services. |

### `tempo wallet transfer`

| Flag | Description |
| --- | --- |
| `--dry-run` | Preview the transfer without submitting it. |
| `--credits` | Pay with MPP Credits instead of tokens. |
| `--mpp-challenge-file <FILE>` | Pay the MPP challenge in this headers file, captured with `tempo request -D`. |

### `tempo wallet services`

| Flag | Description |
| --- | --- |
| `--search <QUERY>` | Filter services by keyword. |

### `tempo wallet sessions close`

| Flag | Description |
| --- | --- |
| `--all` | Close all sessions. |
| `--orphaned` | Close orphaned onchain channels. |
| `--finalize` | Finalize channels already pending close. |
| `--cooperative <URL>` | Request a cooperative close from the service. |
| `--dry-run` | Preview the close without submitting it. |
