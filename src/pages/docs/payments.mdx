Payments are part of [Accounts](/docs/accounts). Start with the [quickstart](/get-started/quickstart) for your first test payment, or [create an account](/docs/accounts/create) for your application.

## Match payments to customers and invoices

Choose the payment reference that fits your application:

- **[Payment references](/docs/guide/payments/transfer-memos)** use a 32-byte transfer memo to identify a payment. Use a memo to match a transfer to an invoice, order, or other record.
- **[Customer deposit addresses](/docs/guide/payments/virtual-addresses)** give each customer a distinct virtual address. Deposits credit one registered account, while transfer events preserve the address needed to identify the customer.

These deposit addresses receive TIP-20 payments on Tempo. To receive funds from another network, use [Routes deposit addresses](/docs/routes/deposits).

## Choose how payments are submitted

| Your application needs to… | Use |
| --- | --- |
| Cover fees for the sender | [Sponsor fees](/docs/guide/payments/sponsor-user-fees) |
| Select the stablecoin used for fees | [Choose a fee token](/docs/guide/payments/pay-fees-in-any-stablecoin) |
| Send several payments in one transaction | [Batch payments](/docs/guide/payments/send-a-payment#batch-payment-transactions) |
| Submit independent transactions at the same time | [Send payments in parallel](/docs/guide/payments/send-parallel-transactions) |
| Limit which tokens and senders an account accepts | [Control incoming payments](/docs/guide/payments/configure-receive-policies) |

## Pay for services and accept API payments

[Machine payments](/docs/agents) use the Machine Payments Protocol (MPP) to include payment in a service request. Use [Mercator](/docs/guide/mercator) to give an agent access to paid tools, or integrate MPP into a [client](/docs/guide/machine-payments/client) or [API](/docs/guide/machine-payments/server).

To authorize an agent to spend from an account, start with [Give an agent access](/docs/accounts/agents).
