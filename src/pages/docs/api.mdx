# API reference

Use the Tempo API to read balances and activity, track payments, and integrate Earn, Routes, and Zones. Start with a public request, then choose the access method your application needs.

:::warning
The Tempo API is under active development. Endpoints may change. Check the [versioning policy](/docs/api/versioning-policy) before integrating.
:::

<span id="start-with-the-tempo-api" />

## Make a request

The API uses `https://api.tempo.xyz/v1`. Most read endpoints support public access:

```bash
curl 'https://api.tempo.xyz/v1/blocks'
```

## API access

| Access | Use it for |
| --- | --- |
| Public | Trying the API and low-volume reads without credentials. |
| [API key](/docs/api/authentication) | Application requests with a dedicated quota. |
| [MPP](/docs/api/authentication#mpp-paying-per-request) | Paying per request without an API key. |

Create projects and API keys in [Tempo Console](https://console.tempo.xyz/?to=/:org/api-keys). The [console guide](/docs/api/console) covers environments, keys, billing, and team access. Keep API keys on your backend; they authenticate API requests and do not sign account transactions.

## Webhooks

Use [webhooks](/docs/api/webhooks) for event callbacks to your backend. For payment reconciliation, use the [transaction and receipt](/docs/api/transactions) together with [account activity](/docs/api/activities). See [Transactions and transfers](/docs/api/transactions-and-transfers) for the difference between execution and token movement.
