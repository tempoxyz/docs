## Make a request

The API uses `https://api.tempo.xyz/v1`. Most reads work without a key at the [public rate limit](/docs/api/rate-limits):

```bash [Terminal]
curl 'https://api.tempo.xyz/v1/blocks'
```

For your own quota, create an API key in [Tempo Console](https://console.tempo.xyz/?to=/:org/api-keys) and send it in the `tempo-api-key` header. Keep it on your backend. [Authentication](/docs/api/authentication) covers keys, scopes, and paying per request with MPP.

To reconcile a payment, read its [transaction and receipt](/docs/api/transactions) and the [account activity](/docs/api/activities).
