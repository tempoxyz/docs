# Allium on Tempo

Allium indexes Tempo chain records and curated stablecoin datasets for SQL analysis. Use the Allium App to explore transactions and transfers, or its Explorer API to run saved queries for application reporting. Start with the [Tempo data catalog](https://docs.allium.so/historical-data/supported-blockchains/evm/tempo) and define the assets, addresses, and reporting period your question needs.

## Choose the Tempo records for your report

| Dataset | What it helps establish |
| --- | --- |
| Raw blocks, transactions, logs, and traces | Chain activity and execution evidence, including the transaction's receipt status. |
| Stablecoin transfers | Token movement by contract, sender, recipient, and date, with transaction hashes and log indexes. |
| Other curated tables | Additional asset, market, or protocol views where the Tempo catalog documents coverage. |

A raw transaction and a stablecoin transfer represent different parts of a payment. One transaction can produce several transfer events. The transaction's `value` field is not the stablecoin amount; use the appropriate transfer records and token contract.

The [stablecoin transfer schema](https://docs.allium.so/historical-data/supported-blockchains/evm/tempo/stablecoins/transfers) distinguishes raw amounts, normalized amounts, and USD valuations. Use the documented string amount fields when preserving numeric precision. Treat a USD valuation separately from the token quantity in your ledger.

## Prepare a repeatable Allium query

:::::steps

### Confirm dataset access and reporting scope

Use an Allium account with access to the intended Tempo tables. Identify the network, token contracts, addresses, time range, and unit of analysis before calculating totals. Check dataset freshness and coverage against the decision the report supports.

### Explore the results in the Allium App

Follow [Run a basic query](https://docs.allium.so/app/run-queries/basic-query) to write SQL and view results as a table or chart. Inspect individual records before relying on aggregates. Preserve the query definition and filters alongside the result.

### Track each programmatic query run

The [Explorer query workflow](https://docs.allium.so/api/explorer/query-workflow) uses an API key and saved query ID. Save the returned `run_id`, poll that run's status, and retrieve its completed results. Keep failures and incomplete runs distinct from a successful query returning zero rows.

:::::

## Preserve payment attribution and completeness

Onchain transfers do not by themselves identify revenue, customer payments, active users, or the business purpose of a movement. Define how internal transfers, conversion legs, and provider movements fit your metric so one business payment is not counted repeatedly.

Connect each relevant event to its network, token contract, transaction hash, and log index. Use [payment references](/docs/guide/payments/transfer-memos) or your offchain records for business attribution. Keep missing attribution visible rather than assigning an unsupported customer or treating the missing value as zero activity.

A report is bounded by the datasets, assets, addresses, dates, and refresh state queried. No rows can mean no activity within those bounds; it does not establish complete absence of activity outside them. Record those limits with the result.

## Connect reporting to payment verification

Use [Receive payments](/docs/guide/payments/accept-a-payment) for delivery checks and [payment reconciliation](/docs/resources/guides/payment-reconciliation) for the application records. A matching memo, changed balance, or successful transaction alone is insufficient to close an invoice.

For direct application access to Tempo payment activity, also review the [Tempo API](/docs/api) and [Indexer API](/docs/api/indexer-api). Choose the interface that supplies the records and refresh behavior your workflow needs.

## Allium questions

### What Tempo data can I query?

The Tempo catalog lists raw chain records and curated tables, including stablecoin transfers. Inspect each table's schema and your account's access before selecting it for a report.

### Can I use saved query results in my application?

Yes. The Explorer API runs a saved query, reports its status, and returns results. Track the specific run ID so the application uses the result associated with its request.

### Does stablecoin transfer volume equal payment volume?

Not automatically. Transfers can include internal movements and multiple legs of one workflow. Apply an explicit metric definition and business attribution before describing the result as payments or revenue.
