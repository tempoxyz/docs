# Partner integration guides

Use these guides to plan an integration with a Tempo ecosystem provider. Each guide explains the provider's role, documented capabilities, access requirements, and operating considerations, then links to its official implementation instructions.

Start with the component your application needs. For a broader provider directory, see [Partners](/docs/partners). For account setup and payment implementation, start with [Accounts](/docs/accounts) or [Send payments](/docs/guide/payments/send-a-payment).

## Wallet and custody integrations

Choose how customers authenticate, who manages signing keys, and how your application requests a payment. The [wallet selection guide](/docs/resources/guides/embedded-wallets) helps compare these responsibilities.

| Provider | Integration focus |
| --- | --- |

| [Dynamic on Tempo](/docs/resources/partners/dynamic) | Customer authentication, embedded wallets, and Tempo SDK integration. |

## Confirm the provider's integration scope

Check the network, exact token contract, SDK or API, account permissions, and environment for the operation you need. A provider's general Tempo support does not establish that every product exposes every native transaction feature. Keep provider access, onchain settlement, and bank delivery as separate parts of the integration.
