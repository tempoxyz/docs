## Implement native payment features

These features are built into [TIP-20 tokens](/docs/protocol/tip20/overview), Tempo's native token standard for stablecoins. Each guide shows how to implement one:

- [Sponsor user fees](/docs/guide/payments/sponsor-user-fees): let a fee payer, such as your backend, pay the network fee for a user's transaction, and authorize that sponsorship.
- [Payment references](/docs/guide/payments/transfer-memos): attach a 32-byte memo, such as an invoice ID, and match a confirmed transfer to your ledger.
- [Mint and burn TIP-20 tokens](/docs/guide/issuance/mint-stablecoins): manage your stablecoin's supply and distinguish token events from issuer funding and redemption.
