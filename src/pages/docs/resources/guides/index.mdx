## Implement native payment features

Each feature has an implementation guide:

- [Sponsor user fees](/docs/guide/payments/sponsor-user-fees): define who pays the network fee and how sponsorship is authorized.
- [Payment references](/docs/guide/payments/transfer-memos): attach an opaque reference and match a confirmed transfer to your ledger.
- [Mint and burn TIP-20 tokens](/docs/guide/issuance/mint-stablecoins): manage token supply and distinguish token events from issuer funding and redemption.
