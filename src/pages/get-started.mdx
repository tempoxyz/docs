# Get Started

Set up your coding agent, fund a test wallet, and send your first stablecoin payment on Tempo’s Moderato testnet.

[Set up your agent →](#set-up-your-coding-agent)

</DocsProductOverview>

## Send your first test payment

:::::steps

### Set up your coding agent

Install the [Tempo Docs plugin](/docs/guide/using-tempo-with-ai#install-tempo-plugins) to give your agent documentation and MCP tools. The [AI setup guide](/docs/guide/using-tempo-with-ai) also covers other editors and MCP clients.

Start with this task:

```text
Use Tempo's docs to build a TypeScript example that sends a stablecoin payment on Moderato testnet with a memo. Include wallet funding and verify delivery to the intended recipient.
```

### Connect a test wallet

Use the [network connection details](/docs/quickstart/connection-details) to configure your wallet or client for Moderato. Keep this testnet configuration separate from Tempo Mainnet, which uses production funds.

### Get test stablecoins

Open the [testnet faucet](/docs/quickstart/faucet) and connect your test wallet or enter its address. The faucet funds the wallet with test stablecoins for development.

### Send and verify a payment

Follow [Send your first payment](/docs/guide/payments/send-a-payment) to try a transfer and inspect the implementation. Add a memo if you need a payment reference, and confirm that the intended recipient receives the transfer.

:::::
