:::warning
**T14 removes admin access keys.** From the [T14 network upgrade](/docs/protocol/upgrades/t14), Tempo rejects new admin access keys, and only an account's own key or its signers manage its access keys. An admin key authorized before T14 keeps paying as an access key without limits, so revoke any you no longer need. To let a second device manage keys, [add it as a signer](/docs/accounts/account-configuration/configuration-updates#add-a-signer) instead, as the [Remove Admin Access Keys](https://tips.sh/1137) specification describes.
:::
